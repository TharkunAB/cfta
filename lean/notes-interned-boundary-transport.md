# Boundary transport with captured probe aliases

`InternedCallbackTransport.callback_observations` derives two properties
from actual complete full-Syntax callback calls. The results agree on
EmptyNode. A bare first local maps to the selected second reference.
The name map may send other captured references to that same target.
The theorem does not require reverse bare-local reflection.

`InternedBoundaryTransport.union_filter_clear` uses this forward relation
for original flattened alternatives. If the first actual union and root
filter return no forbidden boundary, the corresponding target operation
also returns no forbidden boundary. The target sentinel must be allowed.
A captured reference can equal that sentinel. The target filter can delete
that additional alternative without invalidating the theorem.

This is a local constructor law. The full nested induction must still
derive the paired alternative relation through dynamic recursive requests.
The joint fresh-body-to-probes boundary theorem remains open.
