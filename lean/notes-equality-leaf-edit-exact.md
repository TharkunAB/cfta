# Recursive simultaneous leaf edits

`EqualityLeafProjectionEditExact.raw_transport` proves complete occurrence
correspondence for simultaneous edits with finite raw leaf targets. Every
selected path must end at a leaf domain or an absent endpoint. Original
ancestor rows may contain duplicate or dead alternatives.

The actual finite-target worker runs first. The proof then executes its
ordered row requests on retained original rows in a later cache. Structural
recursion gives representations for changed strict child occurrences.
Resident edge normalization identifies the reconstructed parent with the
already returned complete source record. The proof includes canonical
parents that are `EmptyNode`. It assumes no whole-worker or whole-pass law.

`compiled_raw_edit` first compiles the original occurrence tree. It then
runs the worker and derives a finite later cache with its exact changed
occurrence representation. Raw initial guard syntax remains in the leaf
carrier. Local intersection behavior comes from actual global identity
and Cartesian source constructors.

The finite-target worker builds each selected leaf target. The Haskell
closure retains a physical target value. Connecting those closures requires
an explicit adapter: once the physical target has a closed leaf
representation, its compilation is allocation-free. The present theorem
does not identify proof preparation with the runtime request sequence.
