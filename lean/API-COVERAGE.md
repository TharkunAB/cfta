## Error and boundary ledger

Errors are not accepted terms and must not be counted as such. A successful
finite empty denotation differs from an unsupported operation or an unknown
solver result. The actual facade sometimes represents an empty generator as
`Left EmptyGenerator`, while reference enumeration returns an empty list.

| Error family | Concrete source cases and required interpretation |
| --- | --- |
| Empty and weighting | `EmptyGenerator`, `EmptyRanked`, nonpositive weights, insufficient weighted tickets. Reject invalid sampler domains; preserve a separate mathematical empty language. |
| Rank/value selection | Negative rank, rank beyond cardinality, `TermNotInLanguage`. No invalid rank may decode. Callback bounds remain caller obligations for indexed sources. |
| Availability | Opaque inspection, unbounded finite query, recursive term inspection without a retained term index, deferred source requiring compilation. These do not assert that the source language is empty. |
| Unsupported recursion | Weighted recursive alternatives, recursive operation family, constrained cyclic imports, ambiguous cyclic imports, unguarded recursion, bounded unresolved recursive occurrence. These are explicit limits of the current compiler, including on mathematically meaningful languages. |
| Construction consistency | `QueriedRecursiveOccurrence` rejects reads of temporary recursive payloads. `InconsistentRecursiveFamily` rejects discovered keys or minima absent from the final body. Neither error denotes an empty language. |
| Structural/codec validation | Invalid support, wrong arity, open references, recursive guard reads, missing root observation, child forest with other than one term, undecodable constructor, datatype derivation errors. Reject before relying on the corresponding representation invariant. |
| Logical/solver uncertainty | `SolverUnknown`, timeout, pruning/similarity/minimization failures, unresolved relational equality or syntactic equality, residual guards. Unknown is not a proof of rejection and must not produce a successful incomplete enumeration. |
| Integer/refinement support | Uncountable/unsupported lattice expressions, integer leaf reads that cannot be compiled, inexact measures, root condition applied to a non-constructor. The supported syntax and domain must be explicit. |

## Assessment

Every source module and exported function family has a semantic role above.
The checked development covers language semantics, distinct-term indexing,
member indexing, probability, arithmetic, and shrinking. It also contains
executable source drivers for suspended enumeration, recursive symbolic
count/select/rank, recipe compilation, pruning, and complete finite minimization.
These drivers expose errors, callbacks, caches, and operational choices.
They are more than abstract contracts. Their local theorems and composed
examples do not establish every whole-driver invariant.

The principal remaining positive proofs are finite binder-identity integration, heterogeneous runtime-family/support preservation, other recursive syntax adapters, and concrete representation correspondence. The `RecursiveCallback*` modules derive exact all-view inverses and complete bounded global rank queries for the typed single-knot binary-choice algebra. They preserve source order and distinct positions. `RecursiveNaryChoice` derives the local arbitrary-branch choice adapter from those child producers, including its independent class table and complete checked inverse. The `RecursiveNary*` modules extend typed body compilation, complete flat record equations, all-view inverses, and bounded global queries to arbitrary branch counts. Candidate rows stabilize at the requested forest height and satisfy the source knot equation; all flags retain bounds, order, and distinct positions. `StaticSamplingDispatch` and `BucketMergeDispatch` extract every finite flag branch under local constructor/field laws. The full ordered class and sampler knot equations now follow from the source size guard. `RecursiveTermAlignment`, `RecursiveTermMass`, and `RecursiveRankMass` derive value/term counts, exact forward ranks, and full ranked probability fields for typed single-knot products, choices, maps, pays, and labels, including bounded prefixes. The `KeyedTerm*` and `KeyedCallback*` modules also derive complete binary-choice mutual-family fields, source equations, and bounded global inverses. The later `KeyedNary*` and `RecursiveJoin*` modules provide the flat keyed choices and typed nested-join adapters described above. The initialized
enumeration driver now has finite-term soundness, constructive completeness,
final rendering, and sufficient stable execution bounds. The cyclic binder
builder also has total language-preserving construction under complete
cycle marking. Complete symbolic count/select/rank execution,
equality normalization, three-valued acceptance and successful pruning now
have checked source-driver theorems. Pruning still has explicit primitive
adapter and recursive termination obligations. Formula alpha-renaming
and finite sampler-record consistency now have general proofs. Explicit fuel
does not prove unbounded termination. The minimization model preserves the
selected root's accepted representatives after its repair. It does not preserve
every distinct accepted term, because it deliberately selects representatives.

Generic discovery has a finite executable worklist and whole-root language
theorem. Dynamic type allocation remains its representation bridge. Template
restriction has an exact explicit-state product proof. Finite generator
composition derives member counts, ranks, grouping coverage, and masses.
The API distinction between distinct terms and retained members remains
necessary; equal values need not have unique member ranks.

External contracts are narrower: Haskell primitive/runtime behavior, total
user codecs/index callbacks, lawful random draws, and sound solver answers.
Diagnostic rendering and user effects do not prove semantic correctness.
No source algorithm is marked correct solely because tests pass. No generic
contract substitutes for an unproved internal algorithm invariant.
