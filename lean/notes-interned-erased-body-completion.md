# First completion after an enclosing dependency is erased

`InternedNestedOrdinary` inserts the existing finite ordinary skeleton into
the full lexical source syntax. `source_build` equates its actual execution
with the original finite template, including both caches. `source_binder`
equates the source binder's two probes, reservation, body construction, and
cleanup with the existing template operation when the starting caches have
complete payloads.

`InternedNestedErasedEdge` gives a concrete source callback. Its live edges
retain the local inner argument and earlier captures. Its final edge reads
the enclosing argument and an empty child. The source executes the edge
request before node normalization discards it. `first_build` supplies the
earlier complete inner request. `changed_outer` proves that a later source
execution returns that same inner record with a changed enclosing value.
The theorem permits other pending Mu payloads. Its final state includes the
actual new probe and discarded-edge allocations.

`InternedErasedBodyResidual.Admitted` permits these inner calls in arbitrary
ordinary node and union child positions. `build_residual` derives a complete
first execution and a finite `Work` program for every later enclosing value.
The proof certifies both `Safe` and `Ordinary` for that program. Thus its
actual effects preserve constructor fields and cannot request a Mu key.
The ordinary program executes both inner probes and returns the earlier
complete record. It does not omit the discarded-edge effects.

`InternedErasedBodyCompletion.binder_completes` closes the enclosing source
binder. Its first depth execution supplies the inner requests. The ordinary
probe and fresh callback execute the derived residual work. The fresh
callback remains safe while the enclosing record is pending.
`closed_completes` starts from empty caches. `closed_complete_record` adds
the derived record facts, complete payload coverage, available result, and
exact subsequent replay. No theorem in this completion chain assumes a
successful first run, callback key stability, or a global request-family law.

The example has closed lexical scope. It contains raw and smart inner calls
inside ordinary node and union children. Every ancestor uses symbol zero.
`reads_outer` proves that the original inner expression reads the enclosing
slot. `outside_independent_fragment` proves that lexical independence cannot
justify this example. Completion therefore covers actual dependency erasure,
not an unused input.

This is a two-level erased-inner fragment. Each inner live body is an
ordinary skeleton and cannot itself construct a fresh-dependent binder.
The erasing branch is one declared edge with an empty child. Arbitrary
recursive nesting of such erasure, union-induced erasure, and binder-cleanup
erasure remain outside this theorem. The source model also starts with
prepared edge guards. These statements do not close the general closed-input
first-run completion obligation.
