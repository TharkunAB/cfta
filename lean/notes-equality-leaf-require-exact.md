# Complete recursive required-path correspondence

`EqualityLeafProjectionRequireExact.require_transport` proves the complete
actual required-path worker against the original occurrence operation. The
source worker runs first. The proof constructs a finite later cache in which
the changed occurrence compiles to the exact already returned source record,
without further allocation. No whole-worker or whole-pass correspondence
equation is assumed.

`RequireCorrespondence` supplies exact root-only and nullary leaf branches.
It also derives a source-first parent reconstruction stage from represented
inputs. `ClosedWorkers` decomposes successful completed optional requests and
proves full allocation-free replay of the actual parent constructor.

`RequireTransport` composes strict child correspondence through ordered child
lists and original ancestor rows. The original arity check deletes rows
before child recursion. Source child and edge requests are already complete
when proof preparation extends the cache, so their exact results remain
unchanged. `RequireParent` joins these results with canonical parent
normalization, including duplicate rows, dead rows, and a parent that was
already EmptyNode.

The final theorem uses structural recursion on strict original child
occurrences. Its local leaf requirements are availability, finite ordinary
construction, and the actual nullary required-path equation. The finite raw
leaf compiler derives all three. `raw_transport` and `compiled_raw_require`
therefore have no supplied ordinary-input, leaf-correctness, recursive worker,
or cache-closure premise. They retain original raw guard syntax and actual
rejected sentinel effects through the concrete leaf compiler.

This result covers the complete required-path phase of the finite occurrence
fragment. It does not yet prove simultaneous edit correspondence, projected
leaf target transport, or the complete fixed equality schedule bound. Those
operations must use the same finite-cache record relation before the existing
structural progress theorem can yield the physical schedule result.
