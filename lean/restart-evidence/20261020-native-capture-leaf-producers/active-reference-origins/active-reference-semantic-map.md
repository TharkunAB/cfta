# Exhaustive terminal leaf-origin proof map

Source review on 2026-10-20. This note reports source inspection. It adds no checked theorem or runtime counterexample.

A closed node is its own sole encoded leaf. The whole closed result can be a new normalized ordinary value. It need not equal a leaf of either input. For example, ordinary nodes with nullary rows {a,b} and {a,c} can produce the new node {a}. This is a source-inspection scenario, not a newly checked constructed witness. Union construction can also combine ordinary rows from several child results. A whole-leaf identity relation therefore cannot replace row-wise origin and ordered child-call evidence.

After finite swap/reset normalization, compileNode has these branches:

- self returns the exact left operand.
- empty returns Empty. repeated returns a reference. Neither branch gives a row-bearing ordinary or Mu leaf.
- ordinary follows the actual ordered row-pair Walk and normalized makeNode. A selected row retains both original input rows. Each selected child retains its actual ordered request, returned child writer and both original input-child mass bounds. NativeActiveRowOrigins supplies this active-reader bridge.
- Mu enters the actual domain, requests the two stored bodies and executes optionalBinder. NativeActiveMuBodyOrigins retains the actual child and construction. NativeCapturedMuOrigins gives an exact initial full-cell alternative or the same earlier optional occurrence for a selected full Mu leaf.
- union follows the actual ordered member Walk and makeUnion. NativeOpenRowOrigins.union derives an indexed actual member request for each row Origin at a supplied common view. This is per-row evidence. It does not assert that the entire normalized ordinary result came from one member. The parent owns the active-reader ordered-child adapter.
- reference checks actual domain membership and reads the exact bound value before the ordered child request. The present component removes the old completed-reader-History premise by using the supplied same-reader writer map.
- unsupported fails and cannot have a completed body Trace to a pure result.

Three local measures have different uses. Literal structural child descent decreases the finite Value syntax. Ordinary child mass bounds compare each original input child with its corresponding original operand. They do not bound the generated child. A recovered earlier optional occurrence has a strict prefix-fuel decrease within its given actual Trace. A reference child has body fuel minus one. These are local inequalities. A warm child can use a historical writer with an unrelated body fuel. No theorem here supplies a global decreasing clock across arbitrary returned-writer-map lookups.

A sound next exhaustive relation must keep exact operand identity at terminal self, actual construction and ordered child receipts at ordinary/union, actual binding resolution at reference, and actual stored-body/optional execution at Mu. It must allow row fragments from several union members. It must distinguish a closed-root stop from traversal through open union or Mu syntax. Original source execution ancestry and global active-owner exclusion require further causal evidence. Generic availability, a current cell or reader heap growth does not supply that evidence.
