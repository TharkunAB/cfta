# Structural cases

Captured frame: actual finalization and literal configured callback closure.
Selected frame: actual deferred parent tuple and exact consumeSelected operation.
Tuple task: actual ordered visitChildren, unchanged point and completed prefix.
Child task: actual eagerChild with actual parent tail and stopped closure.
Rows task: actual guarded ordered scan at original point/cache/caller/queries.
Origin: same capturedTuple, tupleHead, ordinaryRows, selectedOwn,
selectedReturn and fallbackChildTail constructors. All original receipts remain.
Current: same actual Packet, past TupleInputs, source bounds, capacity,
subset, native availability, closedness, height, pending and reservation fields.

No semantic finish/body/resource law is proved by these runtime equations.
The cons transition alone proves its genuine original work decrease.
No stopped branch, output prefix or complete endpoint is removed from the task run.
