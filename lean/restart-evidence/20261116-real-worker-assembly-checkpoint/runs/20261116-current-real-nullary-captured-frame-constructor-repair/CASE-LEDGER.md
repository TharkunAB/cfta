# Cases

Actual accepted own prefix, zero children: derive the current source Packet and
native Post.refl from original inputs. No child resource supplier is needed.

Actual finalization stops: retain the exact source stop and emit no outputs.

Actual finalization completes, callback stops: retain all callback outputs and
the exact stop through the actual receipt continuation and finish function.

Actual finalization completes, callback completes: retain every output and exact
endpoint resources. Restore original row cache and metadata via actual native
Post at that same returned caller. Keep full returned query memos.

Malformed and rejected own prefixes are outside this accepted-own base header.
They remain in the full real worker target and need their actual source branches.
Nonempty completed tuples require the genuine smaller-task history proof.
