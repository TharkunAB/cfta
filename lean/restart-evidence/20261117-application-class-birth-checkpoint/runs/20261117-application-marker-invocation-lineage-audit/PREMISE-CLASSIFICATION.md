# Premise classification

The current useful PAST facts are the actual source row `EdgeFields`, physical arity, storage validity, literal own preparation, one indexed invocation/ledger derivation, and any actual selected-entry/native unfold receipts from that same branch. Their call arguments preserve all original fuels, root and endpoints.

The actual source row certificate must belong to the selected row. Acceptance elsewhere, a matching symbol, or four children do not provide it.

Terminal membership of `n + 1` at a later U-arrow, the role of every member of that UF class, native inhabitance after intersection, and a chosen completion assignment are desired results. They are not admissible extra premises.

A genuine past terminal merge receipt is valid evidence. Its write must be paired with the actual later read, rather than an independently selected arrow trace. A shallow nonterminal Mu receipt is also valid evidence, but it concludes a new pending slot with bucket[]; it cannot be used as the former write.

An internal induction over the actual chosen nested trace can discover the first executing or deferred cut. A public arbitrary future history/role/alias provider would assume the missing result. No such provider is proposed here.

No formal FIRST header is frozen. The desired app-to-U-arrow membership does not have a defensible universal contract without accounting for deferred cuts and proving actual branch genealogy. The pinned existing declarations already expose the true smaller receipts. This packet records the precise remaining cut instead of weakening the global target to an ordinary-only trace.
