# Same-call identity Type shape plan

Status: planning only. No body or compilation is included.
The current source parent observer is SourceSynthesisCurrentFunctionParent.
Its input is an original node function pool. It does not cover a default union,
a Mu function value, or a value after a later edit.

The proposed first observer returns physical data from the SAME component RowCall.
Its output includes the exact singleton native arrow row and its real guard.
The guard is eqGuard [[[1],[2]]]. It is not Top.
The domain and result are the two ordered actual allTypes calls.
The observer returns their closedness, hereditary Top annotations, and the
concrete SourceMemoGate.unconstrained Boolean. It does not return a primary-gate
false fact or claim that closed/plain values have an ordinary or Mu root.

4. Use many_call for indices 0, 1, and 2 of that call. Retain the ordered domain
   and result intervals, not independently constructed native witnesses.
   The marker source instruction is a literal leaf. Its actual build gives the

8. Prove plain top=true from the concrete Top guard. Use annotated_mono and

   Availability follows from the same child-call readback and prefix growth.

Remaining tag/depth obligation

Closedness and hereditary plainness alone do not imply a false primary gate.
EndpointStatefulGateTrace.NodeTrace.union returns true without reading children.
The finite node case additionally needs depth=0 and free=[]; the closed Mu case
needs the derived plain Boolean and free=[]. Thus current_allTypes_root_cases
is a separate UNPROVED structural target. The file contains its exact candidate
header. Every input is actual current construction data; no shape provider is
added. This target is not used as an assumption in the first observer.

The source universe body is a union of ordinary node alternatives. Native
makeUnion merges those ordinary rows. Do not equate this source union syntax
with a native Union tag. UniverseBody.callback_node proves the native node
body at depth 0, but its present interface uses Value String Guard.
UniverseColdReadback.allTypes_cold_mu also uses String and a cold start.
UniversePrefixSeed.atom_complete supplies replay from a retained String seed.
None is directly a current Label-valued warm-prefix classifier.

Two possible next implementations need review. A mapped/generic version of the
existing universe callback/seed proof can derive the current first Mu and replay.
Alternatively, derive the native node/depth shape of every current cached Mu
body from actual source publication and use request hit/miss/cleanup. Existing
NativeTypeSites.build_mu_bodies proves annotations, not that root tag/depth.
InternedFreshOrdinaryFirstOrderHeap.binder_shallow requires an incoming Shallow
heap; the actual BasicContext contains no such field. Do not add it as a gate.
No new tag framework or evaluator is proposed before one of these reuse routes
is checked. Source PlainMu only restricts annotations within binder bodies.

Even after the tag target, one identity arrow row cannot clear a function pool.
The ordinary branch uses an OR over every actual canonical function row.
Each other row needs its own source-derived child trace. The current parent
observer supplies identity membership, not absence or clearance of other rows.
The generic and all-three actual read observers remain separate consumers.

No emitted-Type history, global assignment, model existence, partial input
pullback, whole default execution, or Haskell defect follows from this plan.
