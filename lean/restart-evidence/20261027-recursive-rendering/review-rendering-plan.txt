Proposed native renderer and smallest semantic theorem

The actual new renderer must use the reached native heap, not any Graph parameter. Source-only draft-native-renderer.lean.txt gives concrete definitions and exact candidate theorem signatures for SourcePruningEnumerationRender. expandFragment follows literal fragments/getValue; at a pending Some handle it uses lookupNode of the actual output heap and MergedOrdinaryHeight.recursiveBoundary. Mu AND Union produce the supplied marker, as in Haskell. Other unfinished nested fragments fail; unfinished roots reject. renderRow reads the root and every retained residual fragment at the actual successive enumeration states. It performs no native query or heap write. Missing-handle behavior remains explicitly outside the admitted realized source domain; it is unreachable under the strong NoPendingNative theorem gate.

NoPendingNative before means every stored pending slot has node=None and scs=[]. It is a finite structural test on the actual values array, not an assumption of desired meaning. Safe+Stratified+NoPendingNative suffice to construct forest and slot assignment equations. They do NOT alone imply that a concrete root render succeeds: a lone pending None/[] root passes this gate but has no rendered root. The smallest observer theorem therefore takes the ACTUAL successful native renderRow observation, and checks of its ACTUAL returned residual pairs, and derives:
  exists assignment,
    Satisfies (NativeLanguage.handles holds ambient H) residualMeaning assignment before
    AND term=assignment uv
    AND RenderStable before after
    AND Satisfies (NativeLanguage.handles holds ambient H) residualMeaning assignment after.
Here H is this output's OWN reached native heap; no final Satisfies is assumed. Remaining inputs are Safe, allocated uv, actual Stratified levels and NoPendingNative. This is a marker-free domain restriction, not a statement that every current .done/early-stop output satisfies it.

Proof dependencies and order

1. Instantiate EnumerationAssignment.stratified_assignment at the actual native heap language, actual Safe/Stratified state and the finite marker-leaf fallback. This constructs the assignment for all forest and stored equations. No CompleteGraph/native correspondence is used.
2. Prove graph-free native readback observers by fuel/list induction over the literal new renderer. Use actual getValue_success/findRoot_correct, the assignment's original forest equality and stored-slot equation. Actual compression Frames or representative_semantics retain these equations. getValue_storage supplies Safe/RenderStable from actual allocated reads; Frame alone supplies no Safe. Pending Some contradicts NoPendingNative at the ACTUAL representative. Pending None/eliminated cannot give successful concrete rendering. Actual enumerated fragments recurse at the actual read core. The root observer yields term=assignment uv.
3. Follow the actual residual mapM using mapM_sound. safe.1.guards supplies each original fragment's allocation bound; actual RenderStable transports values/counter/obligations through reads. Every returned pair equals (guard,fill assignment originalFragment), retaining duplicates and order. Apply checks of these exact returned pairs to obtain guardsHold before. Combine with the constructed forest/slot equations for full native Satisfies; actual RenderStable then transports it to the final read core.
4. Keep native Caller, output queries and full memo witness unchanged: the renderer only reads/compresses enumeration state. If a cached read endpoint is exposed, frame the ACTUAL returned core and use NativeCacheFrame.cacheValid_frame with the separately obtained actual Safe. No stale index dictionary or guessed native endpoint is needed.

If constructing rendering success is also wanted, existing CarriesGraph, FragmentCarries and ReferencesCarry are graph-FREE structural predicates despite their names (EnumerationCarriers:18-25; EnumerationGraphReferences:35-41). Reuse them on actual native cores. Under NoPendingNative a carried root cannot be pending Some; GraphValue excludes None and eliminated. Safe/root paths therefore force an enumerated representative directly. This is the native replacement for EnumerationRenderability.completed_carrier, with no CompleteGraph. Stratified rank then gives the same finite expansion argument as EnumerationRendering. To guarantee root AND residual rendering, retain root carrier and ReferencesCarry (or exact per-fragment carried inputs), rather than assuming success from NoPendingNative alone.

Deriving NoPendingNative for every ordinary done output remains additional work. It requires pure-equality-slot emptiness plus exclusion of pending recursive native domains. Native done classification can derive recursiveBoundary=true and empty buckets for present-handle pending slots; it cannot erase those domains. Early stops need a partial-output interpretation, not complete finite native-term membership.
