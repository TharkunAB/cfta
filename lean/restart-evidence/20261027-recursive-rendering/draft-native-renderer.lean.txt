# Concrete native rendering at one actual emitted cache

The heap is the heap at this output's own caller.
Rendering reads the enumeration state and compresses representative paths.
It does not change the native caller, query memo or native heap.
The runtime retains the source recursive-marker branch.
The assignment theorem excludes that branch with a structural output gate.

local instance nativeRenderMonadList : Monad List where

/-- Every remaining pending slot is an unconstrained pure equality variable. -/
def NoPendingNative (state : Core) : Prop :=
  ∀ uv node scs, state.values[uv]? = some (.unenumerated node scs) → node = none ∧ scs = []

/-- An unchanged stored array retains the structural pending-slot gate. -/
theorem noPendingNative_values (before after : Core)
    (closed : NoPendingNative before) (values : after.values = before.values) :
    NoPendingNative after := by
  intro uv node scs stored
  apply closed uv node scs
  simpa only [values] using stored

/-- Render actual stored fragments and retain native recursive truncation explicitly. -/
def expandFragment (heap : NativeHeap) (marker : Symbol) : Nat → Fragment Symbol →
    EnumerateM Symbol Constraint (Term Symbol)
  | 0, _ => failure .fuelExhausted
  | fuel + 1, .node symbol children => do
      pure (.node symbol (← children.mapM (expandFragment heap marker fuel)))
  | fuel + 1, .hole uv => do
      match ← getValue (fuel + 1) uv with
      | .enumerated fragment => expandFragment heap marker fuel fragment
      | .unenumerated (some handle) _ =>
          match lookupNode heap handle with
          | some value =>
              if MergedOrdinaryHeight.recursiveBoundary value then pure (.node marker [])
              else failure .unfinishedFragment
          | none => failure .unfinishedFragment
      | _ => failure .unfinishedFragment

/-- Render the requested raw root through its actual representative and stored value. -/
def expandUVar (heap : NativeHeap) (marker : Symbol) (fuel uv : Nat) :
    EnumerateM Symbol Constraint (Term Symbol) := do
  match ← getValue (fuel + 1) uv with
  | .enumerated fragment => expandFragment heap marker fuel fragment
  | .unenumerated (some handle) _ =>
      match lookupNode heap handle with
      | some value =>
          if MergedOrdinaryHeight.recursiveBoundary value then pure (.node marker [])
          else reject
      | none => reject
  | _ => reject

/-- Pair the actual root rendering with every retained guard and its actual rendered subtree. -/
def renderRow (heap : NativeHeap) (marker : Symbol) (fuel uv : Nat) :
    EnumerateM Symbol Constraint (Term Symbol × List (Constraint × Term Symbol)) := do
  let term ← expandUVar heap marker fuel uv
  let state ← get
  let pending ← state.obligations.mapM fun obligation => do
    pure (obligation.1, ← expandFragment heap marker fuel obligation.2)
  pure (term, pending)

NoPendingNative is a finite, meaningful output predicate. It can be checked

with an empty bucket is a noncandidate but fails this gate. A pending None

Enough for an observed render, not yet a render producer:
NoPendingNative+Safe+Stratified does not guarantee any root rendering exists.
For example a lone pending None/[] slot satisfies the structural gate but
expandUVar rejects it. Constructing rendering needs the additional ACTUAL
root/fragment provenance. Existing EnumerationCarriers.CarriesGraph,
EnumerationGraphReferences.FragmentCarries and ReferencesCarry are graph-FREE
structural predicates despite their names; they can be reused on native cores.
Under NoPendingNative a carried root cannot be pending Some, and GraphValue
excludes eliminated/None. Safe and root paths then identify an enumerated
representative directly. This replaces EnumerationRenderability.completed_carrier
without CompleteGraph. Stratified rank gives the same finite recursive read
bound as EnumerationRendering.expandFragment_complete. Derive that producer
separately if needed; the observer above does not assume those provenance facts
or claim all native done outputs meet them.

Actual Recursive connection:
Apply renderRow_assignment at output.cache.core and output.caller.heap, using
that output's OWN Packet.safe/ordered and full Post/memos witness. Do not use
an aggregate later sibling caller. The read has no native action, so caller
and queries stay exact. The resulting assignment can instantiate a retained
captured soundness receipt with the SAME initial/final cache, native endpoints
and stable family. A whole Recursive.run proof still needs the complete
semantic trace through narrowing, callbacks, restart and all earlier captured
writes. OutcomeResources alone provides resources, not that trace.

The checked predicate is an explicit condition on ACTUAL rendered residuals.
Source terms/runs does not decide every residual (Enumeration.hs:1196-1203,
1280-1287); template callback acceptance is not the same condition. No concrete
solver correctness or automatic all-guard acceptance is claimed.

Early stop outputs and recursive marker outputs are excluded from this strong
complete finite-native-term theorem unless they independently meet the stated
structural gate and actual observation. They need a separate precise partial
or truncation semantics. This design does not claim a partial term has a
completion, and does not claim every marker belongs to a least-Mu language.
