## Why the relation must follow program positions

ProgramAt is deliberately not a reflexive subterm relation. It includes an exact app/4 root, app function/argument descendants and filter program descendants. A constant itself is not a ProgramAt position. A filter root itself is not a ProgramAt position. Neither annotations nor the fixed application marker create program positions.

The minimal useful per-variable invariant is therefore:

    ∀ program, ProgramAt (assignment uv) program → ProgramAt originalTerm program

It must be DERIVED for actual graph-bearing variables from their recorded source occurrence. It should not be added as a supplied universal future-origin admission. Requiring ProgramAt originalTerm (assignment uv) would wrongly exclude constants and filters. Requiring ProgramEncoding (assignment uv) for every slot would wrongly include type and filter values in program grammar.
