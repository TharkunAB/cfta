# H-independent six-seed invariant and one-query step

Status: HEADER-ONLY DESIGN. UNCOMPILED and UNPROVED.
SEEDS-DEFINITION.lean.txt is an ordinary Prop-valued function proposal.
No runtime, invocation datatype or evaluator is added.
ONE-QUERY-OPEN-FIRST.lean.txt is the exact proposed internal induction step.
It has no body, axiom or sorry and is not a compiler input as a theorem.

The invariant has six parts: source NoNewMu; the closed node clause; the
closed edge clause; singleton-base node Profiles; singleton-base edge child
Profiles; and all four existing auxiliary Returned laws for every numerical
pid apart from u and b. The key functions and result predicates are existing
ones. No root, future history, future pattern or entry occurs in Seeds.

ClosedQualified is not a singleton condition. It allows empty-domain calls
and calls that reset closed operands. Those node and edge clauses must stay.
The singleton clauses quantify over ANY numerical pid. No pid exclusion is
needed for them: an authentic auxiliary key cannot equal ANY singleton base.
The pid exclusions apply to the four auxiliary families' selected-key laws.

The proposed one-query theorem takes pastSeeds only as the genuine smaller-
query induction hypothesis. It is private and conditional. The final source
Nat theorem must derive its initial Seeds from complete empty native memo
initialization and source inventory. A source caller must not supply Seeds,
Gamma or any desired cache law as a new final premise.

The step keeps the literal supplied fuel and original InputsThrough and
FieldsThrough plans. It concludes Seeds at the actual execute state for every
outcome, including failure, constraintError and blocked states. It also covers
every bounded actual Trace prefix. It does not choose an adequate replacement
run or concatenate independent controls from different queries.

Use this proof order to avoid a circular future-inventory assumption:

1. Fix any pid apart from u and b. Instantiate the two numerical source
   callback bundles from the past physical source-grown heap. The existing
   family engines preserve the four genuine past laws at the original fuel.
   Their read callbacks need only current Physical and source growth. They do
   not need NoNewMu at their returned state. Quantify pointwise over pid.
2. For ONE chosen actual whole-query horizon H, derive its initial C/M laws
   from Seeds. Closed node qualification uses the closed clause. Mixed node
   qualification gives an authentic singleton domain, then the singleton node
   clause applies. For an edge row, if its domain is singleton, use the whole
   singleton edge clause. Otherwise every qualified original zipped child
   must be closed, so use the closed edge clause. Keep all zipped children.
3. Run the existing actual-prefix Returned engine. The checked C/edge finish
   leaves and the conditional mixed-finish factor consume the initial laws
   and the internally preserved auxiliary laws at each SAME before-finish
   cut. The mixed factor must not become a public future-law supplier.
   The actual entry derives pid!=u,b and its numerical key from source
   readback. No future pattern needs to be available at query start.
4. Derive the post-query closed clauses directly from that actual Gamma.
   For newly produced singleton nodes, eliminate one true writer/call bundle.
   Full source call admission is Qualified OR auxiliary. The pure singleton
   key lemma excludes every auxiliary alternative. The true producer Gamma
   yields Profile in the Qualified case. Retain inherited exact cells forward.
5. Derive the singleton edge clause from its true edge origin and every
   ordered actual child. Full edge admission classifies each original child.
   At a singleton domain, auxiliary child alternatives are excluded. Recover
   each exact completed child cell and retain it through that query's suffix.
   Use the singleton node clause for that same cell. Keep sentinel and arity
   cases from the checked edge-body theorem. Do not add an all-qualified or
   child-Profile supplier to the source theorem.
6. Derive actual per-prefix optional NoNewMu from the same Gamma, numerical
   auxiliary laws and genuine Mu-owner admission. Port the existing optional
   wrapper to the generic actual before state; its present public source
   wrapper still names one earlier cold prefix. Nonoptional heap effects and
   execute/prefix induction already have the required literal pattern.

Then perform a genuine Nat induction over the actual sequence of query calls.
Each step derives Physical, source growth and operations validity at its own
endpoint through existing prefix/effect receipts. The next step uses that
exact endpoint and its actual query root/fuel/plans. Initial memo laws are
vacuous only at the real initially empty families. Do not reset warm caches.

The two numerical callback candidates are still UNCOMPILED at this freeze.
The closed-to-mixed initial-law conversion, generic optional wrapper and full
one-query step remain OPEN. No proof of the Nat sequence is claimed.
Native inhabitance, UF-class compatibility, guards and one finite assignment
for all causal obligations remain outside this invariant and remain OPEN.
