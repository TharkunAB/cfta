# Actual catalog and arrow self-product rows

Run `python3 check.py` from this directory or pass its path from the repository root. The checker uses project Nix, own-source warnings as errors, and every public theorem with standard axioms only.

Ten laws retain actual Kernel.execute, ordered walk, edge and makeEdge effects. They derive reference/reference cutoff, repeated catalog children, arity mismatch, marker closed-self including the possible reset, and arrow self children. Readback adapters use actual RowKeys and marker RowReadback. The diagonal specialization derives cutoff membership from actual Mu entry. No successful child callback is assumed.

The module does not prove arrow/catalog cross rows, marker/universe value classification, full hash-join normalization, outer Mu replay, or a whole-worker bound. checked.json records the source hash and complete theorem list.
