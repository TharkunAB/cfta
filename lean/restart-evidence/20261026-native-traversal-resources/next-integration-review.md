# Next original-resource integration

The smallest next producer is NativeBranchCompletion.complete_with_history_resources
for the existing NativeBranches.run alternatives worker. Preserve the entire old
complete_with_history output. Replace its recursive Ranges premise with current
Seed, Fits, guard carrier and one original reservation over the ordered sum of
per-edge costs. Count duplicate alternatives.

Arity rejection costs zero. A supported projection some (tries,residual) costs
SelectedEdge.cost edge scs before.core.counter tries. Unsupported projection costs
zero and retains the existing explicit stop. The private head_complete producer
can invoke CapturedEdge.complete_with_history_resources. Split the reservation
at each head, advance the seed, and pad an unused suffix only after a stop.
Append Fits/carrier at the actual final caller. Per-receipt resources alongside
the earlier Post/query/history facts can support later hook composition.

NativeBranches.run restores the same captured enumeration cache for every
alternative. It threads the actual returned caller and query memos, including
native effects from valid child rejection. The old complete_with_history proof
already transports realized slots, native flags and decoded handles using
headPost.effects.keeps. NativeCacheGrowth.cacheValid_post packages this cache
transport. RecursivePacket.captured_post also preserves captured metadata and
dependency facts. Preserve these distinct cache and native boundaries.

This step covers the existing shallow scan. NativeContinuations.run invokes a
hook after edge completion. Its next sibling starts at that hook's actual
returned caller and queries. Legacy NativeBranchCompletion.Ranges follows only
CapturedEdge.run and advance receipt. It does not reserve admission after an
intervening recursive subtree. Siblings still restore captured cache and
metadata, rather than the subtree's enumeration cache.

PrefixCompletion.PrefixValid retains a legacy capability through a proof-only
finish. The actual recursive worker does not execute that legacy scan.
Recursive.callback_prefix_complete derives the actual callback and next selected
prefix. It does not complete or bound the whole subtree. Recursive.resume retains
explicit exhaustion, unsupported, callback and nested-alternative stops. Later
proofs must cover these outcomes and derive Post/resources at their reached
native endpoints. Keep per-emission Post separate from final-native Post.

Whole recursive completion from original admission and whole-driver language
soundness/completeness remain open. Structural cache/history receipts and callback
pruning do not establish language acceptance.
