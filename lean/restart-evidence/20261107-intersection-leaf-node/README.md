# Actual leaf-row product completion

Run `python3 check.py` from this directory or pass its path from the repository root. The checker uses project Nix, own-source warnings as errors, and every public theorem with standard axioms only.

Five laws derive actual edge and ordered node-product completion when either operand has only zero-arity rows. Equal arity evaluates no child requests. Unequal arity constructs the actual dead edge. The proof retains all ordered edge and node cache effects, derives final Facts and availability, and proves the result has no free names. The actual optional-Mu continuation is therefore unused. Neither child-caller completion nor a successful fuel/resource premise is supplied.

The endpoint does not identify a result with its original marker or prove catalog membership, complete Mu intersection, generated closure, native-container realization, or the whole-worker bound. checked.json records the source hash and complete theorem list.
