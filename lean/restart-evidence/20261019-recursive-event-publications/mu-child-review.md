# Stored-Mu unfold child contexts

The new module derives an original stored-body row and a supported selected child call from actual stored unfolding. The output relation is literal. It does not include further epsilon unfolding through a retained Mu.

The private induction follows the original stored value. Closed shortcuts retain identity. Ordinary rows use their actual encoded prefix, ordered stored child calls, row allocation, suffix and node allocation. The proof derives the semantic heap, input availability and replacements at each indexed call. Union branches use their exact member execution intervals. Nested Mu branches use the actual current ordinary callback and preserve the original-value descent. Replacement values cannot inject the selected literal row: the outer replacement is the Mu itself and nested locals are bare references.

The public theorem derives the same stored Mu's earlier publication writer from its retained record at the supplied reader. It needs SemanticHeap and availability at the actual unfold entry, an actual completed unfold, a literal row and selected child, an empty-start reader publication History, and forward record growth. It does not need Ready or an issued Path. Its issued intervals are derived only inside the actual unfolding call.

The Child predicate bounds the original indexed child by the original stored body's structural size. It does not bound the generated child. An unchanged closed child has an identity alternative. A changed child retains its actual lexical call and derived support at the call entry.

Root and the independent source reviewer read the final production source and found no material issue. Strict direct2 has a zero-byte log. Canonical1 is clean. Full public1 prints both public declarations with all eight settings, complete proofs and standard axioms only. Direct1 is retained as a failed encoded-call rewrite attempt.

The constructed check uses an actual used outer Mu with a used nested Mu child. The nested source captures both outer and inner locals. Actual unfolding reconstructs a different used child. The check derives its initial semantic data and publication history, invokes unfold_child, excludes the identity alternative and extracts the supported changed-child execution. Its explicit structural-size instance is the generic source theorem's instance. Four strict fixture attempts are retained; the first three contain proof elaboration or compilation failures. Final strict4 and full public1 are selected.
