# Same-writer entry support

Status: proposed. This package contains no new Lean theorem or Lean job.

The next additive module can export six heads: SupportedWritten, SupportedOrigins, initial, edge_call, reached, and selected. The first two are propositions. The remaining four are actual-execution producers.

SupportedWritten must retain the exact existing OuterParentHistory.Written existential: the same ten bounds, checked before/after states, fourth memos, Merge memos, actual Parent success equation, initial native Good, physical Stored, and live-only field/inherited/child facts. It must add Support writerMemo, UnionNormal writerBefore.heap, and ConstrainedCapGuardHeap.Heap Plain writerBefore.heap INSIDE that same existential. Plain means SourceMemoGate.plain guard = true. This GuardHeap is Mu body/probe profile equality. It does not mean that every stored row guard is plain.

SupportedOrigins uses the same FlatMemoThunk.Valid key links and returned-cell property, with SupportedWritten for the exact captured request and result. Initially empty outer edge tables satisfy it without a writer premise.

edge_call takes its literal successful edgeCall equation, initial outer Good, EdgeReady, SupportedOrigins, and the three entry laws. A cold call records the same actual Parent writer at its entry and stores those laws with it. A ready hit returns the stored certificate. Physical key/readback equality identifies its same full captured request. Current Support is not used to infer support at an independently chosen earlier writer.

The actual Origins traversal needs only an additive copy of OuterParentHistory's outer-node/row/child induction. It does not need another copy of the Target/Lower/Parent Merge-support proofs. A private Entry abbreviation can bundle the three current laws. A private entry_reached applies OuterMergePositionSupport.reached, OuterUnionNormalHistory.reached, and OuterGuardHeapReturns.reached to the SAME actual prefix. Actual rows_edge, rows_tail, and walk_tail receipts supply the intermediate laws needed by the next completed call. The final reached theorem uses the same initial Good/Inputs and SupportedOrigins plus the three initial laws. It does not require a future outer return.

selected must copy the small physical readback part of OuterOwnerSelection.selected. It must call the NEW edge_call once, unpack that same SupportedWritten, and call ActualOwnerSelection.selected on that same Parent success equation. Its output retains the full selected Scan/Required/pass/MkEdge tuple and original false-primary ClassTraces, together with support/normality/guard facts at the SAME writer entry.

The final Scan can also receive normality and GuardHeap Plain. Precheck keeps the constructor heap. Its physical Good proof is the existing small ActualOwnerSelection.prefix_good construction, copied additively because it is private. UnionNormalScan.records preserves normality at the actual record Scan return. RecordScan.scan_mapPaths converts that SAME literal receipt for ParentGuardHeapReturns.scan. No false gate is assumed on the prepared forest. These standalone preservation theorems already exist; the missing step is their correlation with the selected historical writer.

Expected size is about 500 to 570 lines, plus up to 45 lines for the concrete final-Scan adapters. No new lower-worker induction or general invariant framework is needed.

Support is a pure pointwise entry law, so a proved Extends oldMemo currentMemo plus current Support would imply old Support. The existing Written predicate does not retain any inclusion from its hidden writer memo to the current memo. An arbitrary current Support and old Written therefore do not supply this bridge. A new inclusion history would also need actual worker transport. Directly recording all three entry laws at cold publication is smaller here.

The scope remains actual successful calls and actual unfinished outer phases. Internal failed Parent/Merge tables are excluded. The result adds no interval uniqueness, new source binding ancestry, native Mu observation support, active-owner key exclusion, decreasing rank, or general termination theorem. Normality and guard-profile laws remain explicit initial premises; arbitrary Good alone does not imply them.
