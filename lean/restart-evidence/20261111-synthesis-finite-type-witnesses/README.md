# Structural finite type witnesses

Finite TypeIn witnesses use the actual default four leaves, catalog arities with child witnesses, and the arrow marker. Their induction proves supplied-universe membership. Generalized instances use these witnesses to derive their demanded image membership. Rigid typeNode membership follows the actual finite Ty encoding and needs no universe premise, including rigid var_e and non-arrow Fun arities.

The checker verifies exact public names and namespaces, source hashes,
standard Lean axioms, and own-source warnings as errors.

```sh
python3 lean/restart-evidence/20261111-synthesis-finite-type-witnesses/check.py
```
