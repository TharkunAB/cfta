# Captured owners and original binding ancestry

Reviewed on 2026-10-20 at 19:44 CEST. This is a source audit. It adds no Lean check or proof pair.

`NativeOwnedGeneration.execute` now retains one selected full payload, one actual generating optional instruction, its generated rooted writer, and the captured Owner from that same prefix. It does not supply an original-program path. The generated root has initial inputs `leaves siteBody`. These inputs differ from the empty initial inputs of the original closed source build.

`SourceCaptureOriginalSlots.original_slot` transports a row-bearing callback capture to an exact index in those initial inputs. In an optional generated build, this identifies a leaf of the actual child result. It does not eliminate captures. `InternedStoredLeafShape.leaves_shape` makes such a row-bearing leaf closed, since a reference has no RowAt. Closedness does not identify its producer. `NativeSelfCaptureSlots.lookup` instead handles the mapped self inputs of a stored unfold. It does not apply to the unchanged optional-binder leaves map.

`StoredMuRootContract.Correct` compares assigned deletion observations and bare-reference tags. These observations do not retain publication events, exact original syntax, or source occurrences. The contract cannot replace a causal binding receipt. The actual Rooted Written and PublicationBodySourceRows receipts remain necessary when a stored winner is selected.

The existing source chain is useful and exact: a selected original-build Mu gets its actual rooted publication; `written_body_origin` gets that same event's historical raw build and SourceRow; `terminal_source` keeps its actual suffix; `from_source_row` yields an indexed actual child call or an explicit capture or stored-winner stop. Empty original inputs exclude only the capture stop on that original source path. These theorems do not make a native-generated source root the original program root.

Two stronger candidates must be rejected. A closed generated capture need not be one of the two captured Mu operands. For example, two distinct recursive bodies can share a closed ordinary constant C in a common row. The completed C/C child takes the self branch and returns C. The parent's reconstructed row can contain C and a repeated-pair reference. Its leaves include C, which is neither Mu operand. This is a source-level scenario, not a new kernel-checked counterexample. Also Head generation can install a new nested Mu before any later native request. The preserved Head fixture checks absence in the original source heap and presence after actual unfolding. A subsequent native operand cannot be called an original stored payload merely because it is closed or available. No combined later Owner fixture is claimed here.

The smallest newly exposed prerequisite is returned-writer recording at an unfinished native prefix. Existing writer `preserves` proofs accept only a pure-return Trace. `NativeEdgeWriterGrowth.History` has initial, physical advance, and completed clean-trace constructors. It must not be asserted at every arbitrary prefix. The real compiled-owner fixture stops with its root owner still evaluating.

The proposed generic theorem takes initial Clean, Good, Fields and History plus an actual Trace to arbitrary remaining control. It returns the actual node and edge Written maps at the exact reached native state, and Retained from the initial state. It does not return History at that state. Strong fuel induction splits each protected compiler body using the actual bind-prefix theorem. An unfinished body recurses on its unbound prefix. A completed body records its writer only after the literal finish step; a zero-step suffix leaves the body-return map unchanged. The current lookup, demand, protected-body and finish proofs retain the same captured requests, bodies and checked states.

The immediate consumer can extend the same recovered Owner tuple with Forwarded for its exact completed child at the optional site. This removes an internal History or future enclosing completion premise. It still does not complete original binding ancestry. That next transfer must follow row or fragment receipts through the child's actual execution, retain closed-root stops, handle earlier warm writers, and distinguish Head-generated and native-generated source roots. The existing indexed first ordinary cut is suitable geometry. The checked union-leaf boundary forbids same-leaf descent through normalized source union members. Outer execution/active ancestry currently concerns the separate outer nodeResults table and literal caller phases. It is not a native compiler binding route.
