# Identity after the exact successful initial narrowing

Status: complete source-only draft, UNCOMPILED. Root owns compiler and publication actions.

## Smallest actual stage

The new law takes the same accepted current source expression, the same actual closed build receipt, and one observed original full stored Mu. It takes the actual successful SourcePruningOuterNarrow.narrow receipt for root slot 0. It derives the exact reached heap's Keeps, Facts, and original-to-current Grows. It then applies the public after-growth identity theorem to that exact heap. No growth, readiness, Post, or identity supplier is an input.

This is the configured narrowing operator used by SourcePruningEnumerationAction.prepare and SourcePruningEnumerationSelectedStep.runPrefix. The new law handles any successful fuel observation. It does not choose an unrelated completed narrowing run.

## Proof route

1. closed_verified, closed_free_empty, and SourceEqualityRequiredCache.constructed derive the original available closed root and ready heap from the SAME given build. No initializer runs again.
2. SourcePruningOuterNarrow.narrow_complete derives one stable complete run and its actual Keeps.
3. The public MergedFreshOrdinaryColdReplay.nodeEdges_stable derives stability of the GIVEN successful read. Two small private proof lemmas lift that law through narrowAt and the Mu/type/fallback wrapper. The narrowAt lemma follows the existing checked private proof in SourcePruningNativeViewObservedOrdinary. No evaluator is added.
4. Raise both runs to fuel + bound. Determinism identifies their complete result AND heap. Transport the derived Keeps to the exact observed endpoint. This covers Mu/type skips, Empty results, and nonempty filtered nodes.
5. The actual Keeps supplies Facts heap as kept.ready.semantic.1.normal.facts and Grows sourceHeap heap as kept.growth. Apply current_stored_universe_reference_identity_after_growth with these derived facts.
6. The same Keeps supplies current coverage and semantic heap. The identity law's preservation conclusions therefore give unconditional Covered [] and SemanticHeap at the exact final machine. Retain original root, narrowed root, original complete Mu, original stored record, and larger-fuel identity.

## Inputs and contracts

| Kind | Inputs |
| --- | --- |
| Actual source receipts | accepted current expression; actual same closed build; observed original stored Mu |
| Actual stage receipt | successful native root narrowing at the stated fuel, value, and heap |
| Existing operator configuration | Typing and Key types; holeKey, fits, admits, metadata |
| Actual kernel state | domain cache and its validity |
| Derived stage resources | ready heap, Keeps, Facts, Grows, available closed narrowed root |

holeKey, fits, admits, and metadata are the existing narrowing API arguments. The theorem works for these supplied functions. It does not identify them with Haskell's default typing configuration or derive their typing/pruning correctness. There is no new input contract for generated types, a future model, membership, caller readiness, a body product, a probe result, or kernel identity.

## Remaining boundary

The new law does not establish that an arbitrary selected enumeration step reaches this root narrowing. It does not execute the subsequent native request inside a full outer memo/caller wrapper.

The stored-Mu premise refers to a record observed in the SAME actual source heap. It does not assert that all-rigid or empty inputs have a Mu. The no-Mu branch remains explicit.

General closure of generated type values under native intersection, same-run preprocessing completion, joint finite witness assignment, the global witness theorem, and full Haskell correspondence remain open. No Haskell file was inspected or changed.
