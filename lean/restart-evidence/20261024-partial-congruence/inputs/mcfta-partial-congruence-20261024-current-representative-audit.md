# Selected-current representative audit

`resume` normalizes each parked UVar and compares its representative with the raw `current` argument (Pruning.hs289–297). The source does not normalize `current` there. `enumerateUntil'` passes the same selected raw `uv` to both callbacks; after `enumerateOutUVarWith`, it passes `uv` again, not the captured or a newly resolved representative (Enumeration.hs960–1007). `enumerateOutUVarWith` resolves the input before expansion, captures `uv'`, then writes the result directly to that captured slot (883–905). A post-expansion root guarantee must therefore come from an invariant. It does not follow from the callback call site alone.

For the actual phase-4 callback, the pre-expansion `Right` event has no enumeration-state effect: `recordTypes` leaves the type set unchanged, `templateOracle` returns its pure `Right` result, and `typedTypes` uses its default branch (Pruning.hs107–126,239–250). Narrowing may change the selected node but writes at its current representative. The post-expansion observers read or path-compress; they do not union classes. Thus these concrete callback operations do not introduce a new class merger. This does not justify arbitrary state-changing callbacks or arbitrary supplied node expanders.

The source-backed protection argument is conditional on a well-formed forest, live non-eliminated slots only at roots, bounded suspended references, and exact maintained candidate/canonical-waiting indexes with no machine-count overflow:

1. The selected ID is a raw candidate outside the waiting keys (Enumeration.hs817–870). Live-slot correctness makes this ID a root. Canonical waiting support then says that no stored suspended reference belongs to its class. In particular, its own expansion constraints avoid that class.
2. Constraint descent retains the referenced IDs. Edge equality classes allocate fresh UVars (480–484,758–779). Neither operation introduces a reference to the selected class.
3. The only explicit union path in node preparation joins the classes named by terminal suspended constraints (710–747). Those classes remain separate from the selected class. Assimilation and node restriction write those target/source slots without adding a forest union (490–527).
4. Shallow ordinary children allocate fresh slots and install their full suspended constraints. Terminal endpoints and recursive boundaries use the existing node-preparation path (786–802). Under the separation invariant, these operations retain the selected root through expansion and the final captured-slot write.

Existing Lean proofs express the corresponding eager-model argument. `Driver.Ready` contains `Safe`, allocation membership, the selected-root fact and `Avoids`. `findExpandable_ready` obtains it from the old scheduler scan; `getValue_ready` preserves it. `Protected` retains the selected value, root and complete class. `enumeration_protected` proves this for the modeled eager node/edge traversal, using the terminal-merge protection proof. `enumerateOut_safe` explicitly uses `expandedFrame.root` to justify the final captured-root write. These are relevant existing APIs, rather than a new canonical-current assumption hidden in `resume`.

The complete current native implication remains unverified here. The new pure cached-index `Correct` predicate contains alignment, candidate flags and exact canonical counts; it does not itself include forest validity, `LiveRoots`, or a complete driver invariant. Existing count-transfer and pending-assimilation endpoint results are not a composed preservation theorem for every current cached/shallow execution. The analogous protection proof for `enumerateShallowHere`/`prepareShallowChild`, followed by composition with native cached selection and the concrete compressing callbacks, is still needed for a formal source-level guarantee. No counterexample on an actually reachable phase-4 execution was established. No native defect or repair is claimed.

Observational `resume` congruence has a smaller requirement: the two runs receive the same raw `current`, partial term and pending list, and their representative reads agree under the full frame. This yields the same comparison result even when `current` is not canonical. Canonical-current preservation and the pruning soundness contract are separate from that next observation theorem.
