# Existing exact APIs and missing attachment

SourceCurrentNativeNodeWriterHistory.Written retains the captured handle/request, Good and NodeReady at body start, an actual compileNode raw Trace, the evaluating owner, its protected finish, and growth to the reader. Its existential contains no original T control, original start state, used count, or original-prefix equation. Written.grows preserves that absence. The writers/warm theorems therefore cannot identify where that writer occurred in THIS T trace.

SourceCurrentNativeEdgeWriterGrowth.History starts from actual empty tables, records physical heap advances, and adds completed clean protected traces. Its node Recorded invariant exports Written, which forgets the original-prefix attachment. The fact that its recursive proof found a body locally is not an exported witness of a prefix from the original T.

SourceEqualityNativeDemandProtectedPrefix.node_cases assumes the compiled wrapper has already been reached. It splits that actual wrapper prefix and retains owner/count facts. node_body_owner proves exact request ownership at the observed finish after a real completed body. Neither reconstructs the earlier wrapper from an arbitrary finish instruction.

SourceEqualityNativeDemandBodyCode.Clean excludes literal finish instructions in source continuations. compileNode_bodyCode and body_clean cover the actual compiler and checked edge emitted source code. Clean(initial node query) is derived directly in the helper draft. Clean is not preserved by every native yielded step: an evaluate demand emits compileNode.bind(fun result=>finishNode handle result next). Assuming Clean at every reached control would discard those actual frames.

SourceCurrentNativeDemandFrames.node_lookup_demand_frame and SourceRecursiveIntersectionNative.demandNode_evaluate already identify the actual captured request and evaluating cell at a native evaluate dispatch. SourceEqualityNativeDemand.step supplies the literal compiled wrapper at that exact started state. Those are the forward dispatch facts. They do not recover its original prefix from a later observed finish.

The missing theorem is a SAME-prefix version of the existing writer recursion for PARTIAL protected traces, or an equivalent structural finish-origin descent. It must retain the literal original start, original control, actual used count, captured finish continuation, and complete producer state. It must handle arbitrary nesting and continuation resumption. It must derive source cleanness from the concrete initial query or actual original worker compiler. It cannot take an externally supplied ancestry ledger.

The new target chooses the genuine initial-query scope. Extending it to the actual original worker requires its concrete initial source-control proof. It is not established by an arbitrary Code value or by a future Clean supplier. The target is independent of a future semantic model and does not require later completion.

Canonical owns the separate returned-cell-to-finish-birth proof. Its frozen header64ac3ff5... exposes the actual original finish prefix for any initial protected Trace. This audit does not duplicate that extraction. Composing that prefix with the missing compile-origin target would attach the producer, including one older than a later source-domain entry.
