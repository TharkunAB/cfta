The two new declarations are private in the existing owner namespace.
They retain the identity worker bit width and actual equality instances.
The current Packet witness names the actual inventory, caller, memo and cache.
Its memo query equals the recorded current source query.

The resource theorem retains every initial premise from IdentityActualTupleAt.
The worker IH still names IdentityEagerEmittedCompleteAtDepth at recursiveDepth.

the later closed callback resource conclusion. Ready, stored target,
IncomingAvoid and selector-length premises are also retained. Their binder
names start with underscore because this prefix projection does not use them.

Current Packet, ChildInputs, full-list TupleInputs, Fits, Heap and current
native reservation are derived inside the induction. No such current or future
resource result is a new top-level premise. Root's two transport helpers consume
only earlier prefix conclusions and literal observed source events.
