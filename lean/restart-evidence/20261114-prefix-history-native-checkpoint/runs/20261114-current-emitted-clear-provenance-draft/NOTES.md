## Candidate declarations

`enter_recorded_bucket_origin` takes an actual successful `Entry.enter` and the
existing total-forest invariant. It derives:

- the original variable's path to the returned target in the original forest;
- the exact original stored value at that target, including the complete bucket;
- equality of all stored values before and after entry;
- the actual handle's decoded lookup;
- unchanged per-slot histories and the exact active-history update.

The bucket equality preserves each `sc.var`, each trie, and each occurrence.
It does not canonicalize, erase duplicates, or rename targets.
The proof inverts the actual read and successful return. It uses the public
`enter_history` theorem for the other history fields.

`enter_active_key_origin` gives a backward alternative for each actual active
key: it was already in the original target's per-slot history, or this exact
entry inserted it at a recursive boundary. The second alternative identifies
the key with `recursionKey handle bucket` for this actual full bucket.

The first alternative remains a real obligation. The theorem does not assert
that every key in an active history was inserted by the current entry.

## What is still missing

For a true-clear event on an actual emitted branch, the proof must recover an
earlier actual entry and a finite causal chain from that entry to this clear.
The chain must retain the original full buckets and targets at every relevant
entry, allocation, inheritance, incoming merge, and assimilation. It must also
retain the actual earlier completed fragment and its Left callback. Shared
alternative execution must retain the selected branch's captured cache.

The existing `Extends` relation proves forward key retention. It does not give
this backward chain. The candidate gives the actual entry fact at one end of
such a chain. No proof here extracts the whole chain from emitted membership.

Even that chain would leave a semantic obligation. Equal keys do not retain
target identities or repeated trie incidence. If two removed suspended entries
contain the same path, one assignment must give their raw targets equal terms
at that path. Their variables need not be the same union-find class. A proof
must derive their compatibility with all retained domains and with every other
historical obligation. The waiting index cannot supply this equality: selected
roots have no incoming suspended references, and stored targets generally lie
outside the selected root's class.

The required assignment remains existential and joint. No universal implication
from an arbitrary post-clear model to the removed constraints is introduced.
No supplied model, finite-resource provider, future result, or trace certificate
is introduced.

The checked generated-Type atom theorem restricts native values structurally.
It does not establish this causal chain, intersection language correctness, or
finite productivity of all retained domains. These gaps remain separate.
