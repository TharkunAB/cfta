Actual runtime boundary

1. ChildDispatch.run checks incoming Empty before partitioning. Empty returns raw [], unchanged Caller/queries/core/waiting, and Some original cache. For a nonterminal partition it retains the shallow action's complete raw list, original outer core and actual cached preparation separately. An ordinary node stores the whole supplied bucket. A nonterminal Mu/Union allocates an empty bucket. A reference remains unsupported. The terminal branch calls the existing complete terminal adapter.
2. ChildTraversal.run continues only on EXACTLY one successful raw fragment AND Some cache. It feeds the returned Caller, saved queries and that actual cache to the suffix. A missing cache stops even when the raw observation is a successful singleton. A rejection [] also stops. Inner errors, outer errors, None and other list shapes stop with the complete observation and candidate unchanged. No suffix executes after a stop.
3. The raw singleton returned core equals the returned cache core by ChildDispatch.singleton_core. It need not equal the observation's outer core. On the shallow path the outer core is the original input; on terminal incoming rejection the outer core is the read core while the synthetic logical write can be present in the cache. Never replace either field by the other.
4. complete_trace and stopped_trace retain the literal ordered child calls. stopped_trace locates the actual stopping child after the completed prefix; it does not invent a later endpoint. A stopping raw singleton stays inside that observation, outside completedPrefix.
