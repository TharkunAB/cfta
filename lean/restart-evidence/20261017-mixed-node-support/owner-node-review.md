# Mixed-table plain node completion

The four owned modules are ConditionalPlainSupport, ConditionalPlainChildren, ConditionalPlainRows and ConditionalPlainNode. They are additive. All earlier production and evidence files remain unchanged.

Support defines the internal bounded NodeResult/Below interface. It proves actual node publication for the filtered active predicate. The selected handle uses the exact stored owner's rank from coherent resident key readback. Other handles use reverse lookup/demand transport. Only their unchanged static Region or PlainEdge filter is applied. Unrelated constrained active owners need no rank bound. Exact descent and inherited-prefix receipts retain the same conditional returned store and filtered bounds.

The terminal producer constructs Empty, explicit union and Mu cleanup bodies from the initial Context and residency. It uses the existing actual rebuild and probes. It does not obtain a future body from an assumption. Terminal cleanup may change the returned syntax. No result Region or hereditary result annotation is asserted.

Children and Rows are internal induction helpers. Their explicit Below premise is limited to strictly smaller node ranks. Walk computes the exact allocated descended equality payload at the current index. It uses the actual head return to derive the next Context, equality readiness and availability. Completed-frame transport restores the original filtered ancestor bound before the tail. Rows constructs its parent call first with ConditionalPlainEdge.finite. The actual parent shape supplies the Region and smaller rank of each returned child before descendants run. The actual inherited prefix, children, raw reconstruction and later original rows follow the source order.

Node.finite discharges Below by strong induction on nodeRank. In the evaluating branch, the actual begin supplies the complete owner and running Context. Complete value equality transfers the candidate Region to that owner. The filtered push theorem admits the strictly smaller body bound. The finished actual body supplies the semantic NodeLaw and result residency before exact finish. Ready hits use the existing actual sound stored-owner law. Every branch retains the whole actual caller, strict reads, reached checks, full Post, conditional returned store and stable literal worker result.

The public hereditary_finite endpoint derives Region from local annotations, initial availability, closedness and current physical Facts. It retains the entire finite conclusion. It does not require a globally annotated heap. Its conclusion does not strengthen the semantic warm node law to a hereditary output annotation. Such an output law would require an additional causal returned-node certificate.

The public descendants_finite endpoint has only initial Context, inherited readiness, resident input, child Regions, conditional store and filtered active bound. It derives its internal Below hypothesis from the already closed node theorem. It constructs its own actual descendant graph, stable execution, strict reads, checks, same-return full Post, result residency and EdgeLaw. It assumes no future child call, completed graph, result shape, range plan or recursive callback.

Two imported integration kernels test the main composition. ordinary_after_cap actually begins a non-Region cap request in fresh outer tables over arbitrary lower warm state. It derives that running Context. It then constructs a one-row, one-child ordinary node call and its full receipt. The initial cap rank is at most the plain request rank. Thus the old all-owner bound at the actual requested rank is false. The filtered bound holds. Actual frame retention proves that the identical captured cap owner remains evaluating after the complete plain call. hereditary_descendants derives child Regions from a locally annotated resident row and constructs the full descendant suffix, including its retained filtered ancestor bound.
