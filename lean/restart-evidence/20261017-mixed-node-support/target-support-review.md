## Boundaries

This is a supplied-success preservation theorem. It does not construct a new query, prove general termination, discharge machine capacity, or model GHC forcing and pending behavior. Existing finite query endpoints can supply a trace separately.

Both queried operands must be wholly hereditary for the plain predicate. A positive cap alone does not discharge that premise. The current source gate also permits some finite ordinary nonplain endpoints. Therefore this bridge supports the restricted editor family with initially supported retained leaf positions. It does not prove all source-approved selected classes preserve all masks.

The plain predicate is the exact `SourceMemoGate.plain = true` test. It requires empty equalities and supported positive syntax. It does not mean the absence of every positive residual. No Haskell source was changed, and this work establishes no new Haskell defect.
