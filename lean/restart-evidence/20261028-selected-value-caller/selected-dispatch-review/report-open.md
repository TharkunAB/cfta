The concrete integration obstruction is the old captured-parent lookup premise. The original selected slot stores `handle`, and Entry records ancestry from that exact decoded value. After one Mu unfold or a Union row rebuild, the prepared ordinary node can have a different entry and different rows. The original handle must remain in the slot. A second Entry call or a replacement slot would change the modeled source operation.

The actual CapturedEdge.run has no parent-lookup argument. It accepts the original target, inherited bucket and one actual edge. Its finalizer writes the original target. The prepared-parent bridge therefore needs no new runtime definition. The new theorems separate the original stored handle from the actual prepared ordinary parent.
