explicit immediate source anchor. A selected output row must have a
nonempty effective own field and a present child at the tracked index.
The theorem returns the indexed source row, its complete RowOrigin,
the unchanged child options, the same present source child, and strict
InternedValueMass decrease from that anchor to the child.

Link.positive supplies the indexed row. nodeEdges then forces the anchor
to be an ordinary node. InternedValueMass.node_child_lt supplies the strict
inequality. These are structural facts. They require no new Good,
availability, closedness, Cap, guard-alphabet, or completion premise.
The selected continuation is literal, not an observational substitute.

The theorem does not assert that the output node is smaller than its
anchor. It does not assert that an arbitrary generated anchor occurs in
the initial program. It supplies no inequality with a different earlier
writer operand or source occurrence. The separate lineage-review package
pins that exact boundary, including the existing actual repeat example.
