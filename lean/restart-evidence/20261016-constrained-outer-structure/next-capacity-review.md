Define a recursive predicate on the two *initial operand records*: ordinary node identities fit `2^bits`; every row identity fits `2^(bits+2)`; every child has the same property; Empty is allowed. ## Quantitative discharge after that adapter

An initial bound must account for more than height. A height-one ordinary value can have arbitrarily many distinct nullary rows or arbitrarily many Empty child slots. Native row joining can examine the product of row counts. Target operands merge projected alternatives; class targets add intersections, and the class pass folds all classes. Equality combination, normalization, and indexed descent add sidecar interner reservations. Height bounds none of these counts. Initial warm returned payloads also need measured sizes or a derived causal size bound; the current conditional structural Stored certificate gives domain and height, not a bound on row count or guard size.

The count interface should include initial node, edge, domain, and equality supplies; concrete row/child occurrence sizes; class/path/trie sizes and selected indices; and upper bounds on each primitive constructor/reservation attempt. Derive attempt counts by structural rank and finite list/trie recursion on an unbounded-key operational model or on arbitrary finite prefixes. Do not obtain the count by first invoking the conditional completion theorem that needs the same plan. A simple sufficient serial condition would compare `initialNodes + nodeDraws` with `2^(width-2)` and `initialEdges + edgeDraws` with `2^width`; add the appropriate shifted-domain and equality period bounds where used. Derive each draw bound from the syntax and actual primitive schedule before treating these inequalities as an initial theorem.

`Cache.reserve` counts issued candidates. Resident-table cardinality alone does not bound the source supply. Source node and edge supplies are process-global across symbol caches (`Type.hs:451–525`), and losing or duplicated insertions can consume unused identities (`Cache.hs` module header). A runtime quantitative contract must include other types and interfering allocations, or state a serial isolated scope. A fixed input-size bound cannot justify arbitrary process history or concurrency.

Recommended next stage: prove the current finite ordinary per-query key-closure lemma, derive the fast-primary Scan range helper, then add actual-prefix reservation accounting for the class target/leaf path. This leaves one clear arithmetic resource condition before attempting a closed whole-root allocation bound. Full Mu/reference/union progress, repeated reduction fixed points, host forcing/concurrency, runtime table implementation, and frontend correctness remain separate parts of the full goal.
