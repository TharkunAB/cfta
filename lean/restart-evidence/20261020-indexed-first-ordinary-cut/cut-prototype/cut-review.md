# Indexed first ordinary-child cut prototype

The prototype defines three public heads: Cut, Cut.facts, and split. It uses no heap, Context, Ready, history, closure, source-expression ancestry, or DecidableEq premise. It imports the existing stored literal RowAt relation and uses the full finite Value structure.

Cut has exactly three constructors. Its node constructor retains an open ordinary value, exact row and child lookups, the remaining indexed leaf lookup, and the original index as the sum of the preceding row leaves, preceding child leaves and inner index. Its union constructor retains an open union, exact member lookup, prefix leaf length, and nested cut. Its Mu constructor retains an open Mu and the same indexed cut in its exact stored body. There is no arbitrary endpoint constructor.

Cut.facts derives RowAt of the complete parent row, the exact selected child lookup, and the exact inner leaf lookup. split starts with the actual selected leaf occurrence and RowAt of its complete row. It returns RowAt of that row in the original value, or an indexed first ordinary-child cut. A closed root's leaf is the whole root, so it returns the first arm directly. Empty and reference row-bearing cases are impossible. Open ordinary values select their exact flattened leaf occurrence. Open unions and Mu values prepend only their exact indexed literal prefixes.

The proof uses structural size solely to recurse through a finite literal union member or Mu body. This is not a runtime progress measure, a generated-value bound, a decrease of a self replacement, or a theorem relating two different source callbacks. The selected full row, ordered child index, duplicate occurrence offsets and closed-root stopping remain explicit. A normalized source union is not assumed to preserve an original member's leaf list. SourceRow composition is separate future work.
