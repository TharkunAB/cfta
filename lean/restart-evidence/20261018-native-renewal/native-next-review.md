# Native renewal composition boundary

SourceCurrentUnconstrainedGuardClosure already proves conjoin_plain,
ready_plain and loaded_ready_plain. A separate guard closure module is
unnecessary. The new ordinary positive_child endpoint adds the derived
positive source side and strict source-child mass to actual writer and
indexed call provenance.

The remaining branches cannot all use that ordinary endpoint unchanged.
NativeOpenQueryRowOrigins.Resolved preserves the following distinctions.
The self case returns the exact input row. It does not execute requests for
each child. The union case retains an actual ordered indexed member call,
but its row witness is MergedFreshOrdinaryGraph.Origin at the reader. It
does not promise a physical nodeEdges member of that member call's result.
The reference case retains an actual entered-domain read and the resolved
child request. Domain support and its actual bound value remain part of
the source handoff.

The Mu case has a stronger existing source receipt than a physical-row
index alone. NativeMuWriterSourceRows.MuRow retains one captured writer,
its entered child request, its actual generated bodyValue and its optional
binder outcome. Its Anchor records an original RowAt occurrence in that
bodyValue with the same full guard, symbol and arity, plus identity or
actual stored child calls. The same guard transfers non-Plainness to that
original generated-body row. This is a useful intermediate anchor. It is
not an occurrence in either original query operand.

Two precise composition obligations remain. First, RowAt under a generated
Mu body is not a physical row selection in bodyValue. Applying the physical
NativeOpenQueryRowOrigins classifier recursively at that point would assume
a premise it does not provide. NativeOriginExposure supplies actual
retained-Mu unfolding and keeps the Origin tail at the original reader;
it does not by itself align that stored winner's unfolded row with the
current body query or derive its original operand occurrence. A successful
unfold may allocate new values, so its returned heap cannot silently
replace the fixed Origin reader.

Second, the body child request retained by NativeMuBodyOrigins can be open.
Its checked entered state and exact reference resolutions are available.
The older closed-input NativeQueryMuRowOrigins request endpoint cannot be
applied to it without proving closedness. The open-query and full-Origin
endpoints retain the necessary distinction between direct, returned,
reference and Mu provenance. A source-anchor composition must consume
these actual branches, retain paired guard derivations and use the
captured writer of each warm result.

A useful next producer must transport a selected positive row occurrence
through that actual generated-body query and optional reconstruction to
an earlier operand occurrence. It must retain the ordered native child
pair requests or the actual stored substitution calls that change the
children. Ordinary positive_child closes the direct ordinary step of that
producer. Its local mass decrease does not supply the missing Mu handoff,
an initial-source decreasing rank, or a finite renewal bound.
