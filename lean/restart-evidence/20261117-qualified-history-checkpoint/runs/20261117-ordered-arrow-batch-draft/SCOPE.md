# Ordered pending arrow batches

Status: UNPROVED. The definition and public header were frozen before the proof.

The target allows a bucket to use an earlier owner's union-find class as a target.
It uses one fixed snapshot and one final assignment. The assignment must satisfy
the forest, every stored equation, and every bucket in the finite ordered batch.
It must preserve the original kept values and other pending owner values.

The order and class compatibility are explicit mathematical inputs. They are not
proved facts about every causal execution. The theorem does not claim that raw
acyclicity is enough. It retains the original snapshot safety and stratification
premises. Initial target typing applies to targets in the original kept set.
Typing of earlier owners must follow from the same finite construction.

Native domains, guards, readback, original-root completion and source event coverage
remain open. No reachable-source or Haskell defect is claimed.
