# Original source-child depth bounds

The new module has two public producers. Both start from one actual successful source `build` and its initial joint `Context`. Each producer inverts the literal parent call. It constructs the exact ordered child-list call, the exact constructor return pair, and the context at the constructor entry. No child schedule, output bound, completion oracle, or future context is supplied.

`node` returns a depth bound for every original child of every row in `surviving rows`. `InternedNormalizationDepthExact.makeNode_surviving_depth` identifies the result depth with the maximum depth of those original surviving children. Coherent canonical edge deduplication preserves this maximum. Dead source rows have no bound. They can contain deeper children than an Empty parent.

`union` returns a bound for every value in the ORIGINAL output member list, before union normalization. `InternedNormalizationDepthExact.makeUnion_depth` preserves their maximum through Empty deletion, flattening, deduplication, merging ordinary rows, singleton collapse, and canonical readback. Coherence, cached availability, linking, and liveness at the actual constructor entry come from the initial context and actual child execution. These are derived facts, not later-entry premises.

Both producers retain complete source syntax and values. They require no closedness, `BinderFree`, finite ordinary domain, capture restriction, reader transport, or semantic observation comparison. Physical `Value.depth` is the measure. The bounds do not constrain later reconstructed values under replacement maps.

The source-built witness has two families in one public theorem. An actual reserved body call for an outer Mu contains a nested used Mu. Its raw node result has positive depth one and two surviving rows. The node producer supplies every selected child bound. A second actual closed source uses a nested union, duplicate nested used Mu, and Empty. Its original member depths are exactly `[1,1,0]`. Normalization collapses them to the same single Mu value. The union producer supplies the original-member bounds. Initial contexts and actual calls come from source execution. No fixture receipt is assumed. The copied private construction prefix is from the separately frozen binder-rank fixture; no theorem from that fixture is imported or invoked.

Selected production checks are direct2 (literal zero-byte strict log), canonical1 (clean terminal build, 271 jobs), and public1 (two complete declaration/proof/axiom pairs). Selected constructed checks are kernels4 (literal zero-byte strict log) and kernels-public2 (one complete pair). All selected runs use Lean 4.34.1, effective 4 GiB memory.max/high, zero swap, and a five-minute cap. All full probes use the eight print/lint options and contain only the standard three axioms, without print omission or diagnostics.

All failed attempts remain. direct1 had a dependent-case equality elaboration error. kernels1 left a ground list contradiction after evaluation; kernels2 used definitional equality where evaluation was needed; kernels3 kept a redundant tactic after evaluation had closed the contradiction. An early full probe was launched against unsuccessful kernel2. That failed probe contains errors and `sorryAx`, is explicitly unselected, and does not count as checked evidence. kernels4 and full kernels-public2 are the only selected constructed receipts.

These bounds supply one missing premise for a rank-bounded fusion induction. The consumer must still connect the selected row or original member to its exact indexed child source call and specialize the bounded induction hypothesis there. This component does not prove bounded node/union fusion closure, general binder fusion, or termination.

Source dependencies are the actual source executor and its verified child-list effects, the joint source Context, and the exact node/union normalization depth lemmas. The ordinary and union constructors retain their literal output states in both public statements.
