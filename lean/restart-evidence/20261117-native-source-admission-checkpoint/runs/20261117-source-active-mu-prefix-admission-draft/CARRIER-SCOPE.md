# Carrier scope

Private proof carrier only. No runtime datatype or traversal is added.
The exact public36376d9e header is copied before proof work.

NodeAdmission uses existing Qualified or an authentic full-P context with the
nine literal auxiliary node-pair/key alternatives. It contains no body result.
EdgeAdmission requires child admission only when arities match. Rejected and
mismatched checked bodies emit no child requests.
CodeAdmission follows existing Code syntax. Result continuations are checked
structurally for all returned values. They do not receive a result law.
Enter/read obligations require the exact rooted instruction prefix. Enter also
retains its literal Trace1 and actual entered handle. Their wholeCount bound is
fixed to the same original history. The induction produces these obligations
from actual compiled code; the public theorem receives none of them.

The necessary remaining proof components are compileNode admission at an actual
source parent, checked edge-body admission, one-step preservation and the
closed-root prefix induction. All remain UNCOMPILED at this freeze.
