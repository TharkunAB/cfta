entry. It derives the existing retained-cell alternative or the authentic entry
and dispatch of the same old cell. It uses closed root operands instead of two
enumeration-slot lookups.

The second theorem starts at the actual empty native tables. It eliminates the
retained alternative, derives the old authentic entry, and applies the checked
cold-source C/M law to that same returned cell. The old-entry witness and the
new/old domain-handle equality are no longer caller assumptions. It keeps the
actual old source build, stored universe, input and field plans, original bounds,
one later entry, and the captured request's input operand qualification.

This is an internal old-cell result law. It does not derive every worker input
qualification, auxiliary-family ancestry, full warm NoNewMu, native inhabitance,
one joint finite completion, or compiled Haskell correspondence. No future
result/body/model law is an input. No old source byte, import, runtime, proof
limit, or Haskell source was changed. Root owns compilation and integration.
