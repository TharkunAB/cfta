# Numeric proof boundaries

The stage theorem needs no induction on the Lex rank and no output law for recursive candidates.
After one-rank unfolding, every candidate value is an actual member of the current finite image list. The joins cover it without an assumed property.
The private four-coordinate comparison records chronological retention along the SAME computed row/slot trajectory. It does not assert monotonicity under changed input seeds.
The future source can import `Init.Data.List.Nat.Range` explicitly for `List.mem_range`. This does not change the public header.
The public-only unfolding route and all proposed stage proofs remain unelaborated. This package contains no implementation or compiler attempt.
