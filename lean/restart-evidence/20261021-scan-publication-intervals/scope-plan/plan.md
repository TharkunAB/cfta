# Scope of the same completed checked native call

Status: SOURCE-ONLY PLAN. The proposed two heads are unproved. This package runs zero Lean or Lake commands. It changes no official source.

The smallest route is a completed physical Trace to checked WordRanges conversion, followed by the existing scope completion and completed-step uniqueness. A separate scope induction would repeat protected-frame scope certificates already proved in ScopeCompletion.

`SourceCurrentAllocatedNativeRequestBounds.WordRanges` quantifies `SourceEqualityNativeDemand.Steps`. These are checked-interpreter steps over the full native and equality-operation state. They are not the raw `SourceRecursiveIntersectionNative` steps. The older plan used “raw prefix” as shorthand for the Steps graph without physical admission. That wording does not specify the right interpreter and must not be used in the new claim.

## Prefix proof

PhysicalExecution.Inputs at a node contains the exact node Words implication. At an edge it contains the exact edge KeySafe predicate. Every other control has Words = True. A small private Inputs-to-Words lemma follows by control/code cases.

Induct on the length of the supplied completed physical Trace. Compare it with an arbitrary checked Steps prefix from the same entry. A zero-length prefix uses the supplied current Inputs. When both traces step, their equations concern the SAME deterministic checked `step control before`. Outcome.yielded injectivity aligns the next control and every state field. Apply the induction hypothesis to the same tails. At the final pure control, Words is True and a further yielded step is impossible. This proves the universal prefix quantifier directly, without predicting fuel or allocating a new execution ledger. [R1–R4]

## Same-return scope proof

Invert the supplied Step once. Apply word_ranges to its Trace. ScopeCompletion.initial_complete takes precisely the genuine initial Scoped/Idle, Good, SemanticReady and closed original available operands, plus those derived ranges. Choose an internal constant language predicate: the scope statement has no language premise. It returns one Receipt with Scoped and an Idle/closed result. Construct Step.run from that Receipt.trace. The public AllocatedTargetQuery.Step.unique equates its value and full checked state with the originally supplied Step. Transport the scope, idle, and closedness facts through those equalities. No cache writer is reselected and no result closure is assumed. [R5–R8]

ScopeCache.Scoped is an unconditional law for returned cells. Positive Support, CurrentNative.At and causal Mu History do not imply it. Idle is also a genuine entry premise. Empty tables have existing initial_scoped and idle_initial producers. Warm callers must retain the actual scoped/idle cache invariant. [R7]
