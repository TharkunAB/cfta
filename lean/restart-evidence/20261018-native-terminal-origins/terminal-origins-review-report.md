## Retained writer and route facts

`NativeWriterReadyRetention.writers` recovers the actual earlier writer from
the current returned cell and causal native History. Its receipt includes
the exact request, protected evaluating cell, compiler body trace, finish,
writer-to-reader heap growth and native returned-cell retention. A warm
reader does not run a replacement callback or select a new candidate body.

`NativeQueryRowOrigins.Route` records only actual swap and reset hops.
Swap reverses the ordered operands. Reset retains both operands and changes
the domain to the empty domain. The route is not a history of arbitrary
recursive Mu body calls. Native History and returned-cell retention recover
the protected terminal writer after these hops.

The historical `NodeReady` fact supplies a valid domain and Available
operands. It does not supply `InputView.Original`. Historical Good also does
not imply that every available payload has Original syntax. Closed operands
do supply the missing fact: `OriginalOutput.closed_original` combines their
literal closedness with historical availability and coherent metadata.
This argument permits arbitrary nested Mu payloads and their interned bound
names. It does not impose BinderFree.

## Actual union member origins

`NativeUnionWriterOrigins.left/right` recover the selected captured writer
before they inspect the union constructor. The selected branch and actual
successful compiler trace exclude an incompatible constructor shape.
The proof derives Original for both operands from the historical writer
facts and the explicit operand closures. It then obtains each union member's
Original proof from the actual union payload.

The existing literal union theorem derives the ordered member Walk and
the selected index. The new result retains exact prefix, member request,
suffix, checked states and fuel sum. Left and right union branches retain
their respective operand order and the original domain. The selected row
has an epsilon Origin in the actual returned member result at the same
reader heap. This uses the same full row, including guard and ordered
children. It does not identify an original input occurrence or assert a
decreasing rank.

The proof does not invert WorkInputs of an unreduced `makeUnion` to recover
all input availability. That inference would fail when the work reduces to
a pure singleton. It derives the needed input syntax through the closed
captured operands instead.

## Actual Mu compiler schedule

`NativeMuWriterOrigins.trace` inverts the completed literal `compileMu`
trace. It derives both actual operand identities, the exact entered domain,
the request on the two literal bodies, and the optional-binder endpoint.
The fuel equality is exact: the body request uses the remaining child fuel,
and domain entry plus optional construction contribute two steps.

The optional entry's input receipt supplies availability of its actual
body value. The observed successful trace excludes a pending optional
outcome and derives the literal `maybeMu = .done` equation. The result also
retains the complete final checked state. The returned-cell consumer obtains
this schedule from the protected historical writer. It does not assume a
successful future body request or a desired row relation.

The schedule also gives literal identity when the actual intersection-pair
name is absent from the body value's free names. This is the optional
constructor's no-construction branch. It is different from smart cleanup
after construction when a callback's local binder is unused.

This physical schedule does not identify a used stored binder's body with
its current ordinary callback or with a losing prospective callback.
`NativeConstructReadback` needs an actual source-publication History from
empty at the optional entry to prove its stronger smart readback. Final
native History cannot supply that earlier source-publication fact by
backwards heap growth. The native History interface can start at arbitrary
initial heaps and permit arbitrary growing physical advances. The source
publication and native writer histories therefore remain distinct.

## Closed terminal root

`NativeQueryClosedTerminal.route_closed` preserves both operand closures
through the exact swap/reset route. `closed_residual` retains the same
terminal returned cell, writer and source route while excluding literal
left-reference and right-reference terminal root branches. The proof uses
the root operands' actual free-name fields and the literal branch selector.
It does not assert that all internal native requests are closed. A Mu body
request can expose references under its extended domain.

## Stronger terminal classification

`NativeQueryTerminalOrigins.returned` first constructs the older row-origin
receipt from the actual returned query cell and native History. It derives
the terminal route closures and then calls the union or Mu producer for
that exact terminal cell. A selected physical node row supplies its epsilon
Origin at the reader heap. The proof does not supply an assumed recursive
row relation to those producers.

The public `request` consumer derives final History, Good and heap growth
from the actual completed checked request. It then applies the same
returned-cell result. Neither endpoint assumes a future successful request.

The `Resolved` predicate resolves the terminal branch classification. Its
Mu arm contains the actual physical schedule but does not mention a row
occurrence in the body or ordinary probe. Thus the name does not mean that
general used-Mu row correspondence is proved. The union arm identifies a
returned member result and the same full row, with ordered actual calls.
It does not yet map that row to the original member input.

## Remaining proof boundary

Actual source schedules and causal returned writers are output producers,
not general completion theorems. The union member result still needs its
own recursive provenance. The used Mu case still needs a source-grounded
relation between the actual returned binder and the relevant reconstructed
rows. Captured earlier winners must retain their own chronological source
origin when that relation is proved.

These results do not supply a global decreasing rank, all-active-node key
exclusion, a finite fresh-request bound, unbounded outer completion,
convergence, or Haskell runtime correspondence. No new implementation
defect is established. Final selected sources and checked public receipts
are pinned separately in the review manifest.

One narrow next-case proposal remains unproved here. The public terminal
consumer selects a physical ordinary root row. In its Mu case, smart
cleanup therefore cannot leave a retained `.mu` or return the bare-self
Empty result. It must expose an unused stored body, unless the optional
pair was absent from the raw body. A future proof can test this split and
use the existing causal unused-writer law for this root-row case. That route
still needs a producer for source-publication history at the actual optional
entry. It does not prove the arbitrary used-Mu correspondence stated above.
