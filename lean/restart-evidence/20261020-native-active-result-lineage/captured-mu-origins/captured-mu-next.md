# Remaining capture producer interfaces

This note maps current proved dependencies. It does not assert a new general capture theorem.

The native optional call builds binder true (encode (leaves parent) [intersection pair] parent) with exactly leaves parent as its input pool. NativeMuOptionalGeneration.trace recovers its actual generating operation and rooted writer from a literal checked prefix. CapturedMuOrigins.capture correlates one indexed full Mu in that pool with an initial full cell or a strictly earlier operation in that same prefix.

When an actual build original [] empty returns exactly the initial native heap, CompletedBuildRootedWriters.build_writer can root an initial full Mu cell in that original execution. NativeOriginalRequestScope uses this exact startup equality for queried original operands and domain bindings. That equality does not hold automatically after earlier native or Head operations. For those heaps, the initial full-cell arm must retain the actual earlier producer rather than claim an original source root.

The leaf collector stops at every closed value. A closed NODE leaf can therefore be a complete result newly assembled by ordinary native row intersection. It need not be equal to either original operand. ActiveRowOrigins recovers actual source row indices, both source child lookups and the selected child call from a physical selected output row. It does not yet carry a whole indexed leaves occurrence through that construction, including the closed-value stopping rule. An indexed per-native-constructor leaf producer is the remaining extension for these closed NODE captures. A supplied desired leaf ancestry relation would not prove it.

For an actual stored unfold, the lexical input pool is map (input selfEnvironment) (leaves storedBody), rather than leaves parent of a native optional call. NativeSelfCaptureSlots.lookup and canonical_slot classify a row-bearing mapped input as the same closed leaf or the full self Mu; unmatched literal references have no structural row. These heads classify exact values and slots. They do not derive a source execution writer for the closed leaf. HeadMuGeneration.head provides the actual stored unfold that introduced a new full Mu during Head. It requires its own actual Head and entry support; a checked native prefix does not include a preceding Head interval automatically.

IndexedLeafSourceRows.source_cases and SourceRowTerminalSuffix apply to a supplied actual completed build with Context. They preserve the same row, source calls, rooted entry and suffix. They do not turn a native-generated root into the original source root. The original-capture suffix theorem preserves a slot in the actual initial input list; that list is nonempty for generated encode builds. SourceRow binder arms also keep the selected historical winner. The current callback must not replace that winner's actual publication.
