# Live source execution consumer

The new module is `MicroCFTA.SourceCurrentStoredLiveSourceLineage`. It exports five heads: `Aligned`, `empty`, `reference`, `ordinary`, and `complete`. It consumes the existing `StoredProbeCompatibility.Compatible` predicate. It does not strengthen that predicate to whole-list Paired or global marker freshness.

`Aligned` states a source induction case at one common Ready heap. Its raw source calls and stored reconstruction calls use exact full heaps. `reference` derives equality of the actual reconstructed values. It handles an indexed varying reference, an opaque fixed capture, and an index outside the input list. Fixed captures use agreement only on their actual free names. They can contain arbitrary nested Mu records. `empty` discharges the Empty source case.

`ordinary` requires an induction hypothesis only for strict immediate syntax children. The existing StrictChild witness retains the source row, child occurrence, and strict syntax-size bound. The proof does not require compatible support for children in dead rows. Actual raw buildMany profile correspondence derives a source row's liveness. FreeNameSemantics.evaluateEdges_member then includes each live child's support in the parent support. Only then does the proof apply child induction. Actual raw empty tests align both row schedules. Stored node expansion retains complete symbols, guards, and ordered reconstructed children through canonical survivor filtering. The proof includes closed node shortcuts and does not assume canonical order for original closed rows.

`complete` consumes a proved Aligned source case, actual past raw source calls and their contexts, actual growth to an initial common Ready heap, available lexical inputs, and initial replacement availability. It constructs both stored calls in sequence. It derives Keeps, both local publication histories, final availability, exact warm replays, and Related. It does not assume future stored-call completion or an output relation. It does not construct arbitrary raw source calls itself. The exported ordinary induction step retains its strict-child IH; it is not a theorem for arbitrary binder syntax.

The constructed test starts with its own leaf build. It derives Ready for two sequential actual source Mu builds and constructs their Publication receipts. It then builds both ordinary source instances in source order. The ordinary source has one live row with children var0 and var1 and one dead row with children Empty and var2. The local ordinary markers differ. An ignored capture aliases the first marker but not the second. After binding both markers, the entered ordinary source is Compatible, while the var2 child is explicitly not Compatible. The test discharges all strict child cases using empty and reference. It invokes complete and obtains both actual stored calls, Keeps, local histories, final availability and Related. It proves the first returned result is nonempty. It supplies no future result, callback law, or completion premise.

Related includes physical Empty agreement and all finite open observations. It does not imply literal root-part equality or self-filter congruence. In particular, this module does not resolve the bare-reference versus union self-filter case. The general binder and chronological selected-writer cases remain open. No finite-Cap, NoDeep, ordinary-only child restriction, or whole-heap closure premise is added.
