# Room and the smallest positive-mass C rank

Source-only assessment. No Lean check, C evaluation, runtime example, proof implementation, or official edit was performed. The prior adequacy assessment is unchanged. The conditional successful-resource theorem remains unproved at this assessment's source cut.

`Room bits profile` requires `profile.domains + 2^(profile.nodes + profile.nodes*profile.nodes) < 2^(bits+1)` (AllocatedNativeResourceForecast105–107). Therefore it necessarily requires `profile.nodes + profile.nodes*profile.nodes ≤ bits`. In particular, the mathematical parameter choice bits=64 permits at most seven in the PROFILE node bound: eight gives exponent72. This is not a claim about the implementation's machine word size. Checked native entry states use width `bits+2` (AllocatedNativeComputedBudget62–72).

There is a complete symbolic lower bound at numeric rank `(0,1)`, for EVERY alphabet, budget, and Nat entry profile. Let `C` be the public envelope and let `scalar p = max (max p.nodes p.edges) p.mass`.

1. A raw numeric rebuild replaces nodes, edges, and mass by `h(scalar p)`, where `h(b)=b*b+b+1`, and keeps domains. The definitions give `primitiveGrowth b b = max (b+1) (max b (1+b*(1+b))) = h(b)`. This uses OuterInitialSchedule23–24, OuterConstructorBounds35–36, ConstrainedCapEditFrame30–33, ConstrainedCapTargetForecast17–18, MemoMergeResourceControl45–46, and FreshOrdinaryResultMass21–22.
2. Every numeric Parent profile ends with `MkEdgeNumeric.finalProfile entry.mass`, whose width is `max entry.mass 1`. Its `primitiveGrowth` is at least its input scalar plus one. Thus Parent's output has nodes=edges=mass=`B` for some `B≥1`, regardless of which class cases its finite join contains (ParentUniformEnvelope28–37; MkEdgeNumeric27–29).
3. At rank `(0,0)`, C's row fold is empty. Its output seed is exactly one rebuild of its entry seed (OuterRankEnvelope55–65,67–75). At rank `(0,1)`, the outer fold has exactly ONE row, and that row has B numeric slots after the Parent, with `B≥1` (47–59).
4. The first slot's candidate list contains `(0,0)`: count0 is in range1, mass0 is in range(B+1), and the strict-rank filter accepts `0<1`. Hence its output join contains `C(0,0,post)`. That child's output nodes/edges/mass are at least `h(1)=3`. `cover_member` preserves that component bound, and later slots retain it (OuterRankEnvelope21–45,102–105; InitialSelectionForecast60–68).
5. The row's final rebuild therefore has nodes/edges/mass at least `h(3)=13`. The outer final rebuild has nodes/edges/mass at least `h(13)=183`. Thus `(C budget 0 1 seed).outputProfile.nodes ≥183` for every seed. This argument uses finite folds and two well-founded unfold equations. It does not evaluate a concrete C instance or assert an exact output.

Consequently, `Room bits (C budget 0 1 seed).outputProfile` implies `bits≥183+183*183=33672`. Any larger joined Room profile inherits this necessary bound by component order. In particular, THAT Room premise is impossible at bits=64, or at any bits<33672, even before considering its domain or edge bounds. This is a mathematical impossibility of a specific coarse forecast premise, not a runtime fault or a termination counterexample.

Rank `(0,1)` includes the literal empty value: its structural mass is1; it has no PositiveAt constructor, so the positive-path quotient list is empty for every inherited family (ValueMass17–21; RequiredPositivePosition26–40; PositiveQuotientCount62–65,124–126). The lower bound does not need an invented all-zero entry fixture: it holds for every Nat profile, and therefore for every genuine entry profile that can be supplied. No full genuine initial resource packet is constructed here.

The forecast pays a Parent, at least one virtual child slot, and raw row/node rebuilds even when the empty value's actual worker would skip them. Profile node bounds also use a common scalar that includes payload mass. The bound183 is therefore a reservation bound, not a claim that an actual run allocates183 nodes. This identifies a concrete fixed-width limitation of the current sufficient Room condition. It does not prove that all C ranks or all widths are impossible. It supplies no widening construction, state/cache transport, or complete nonvacuity witness for the full initial packet.
