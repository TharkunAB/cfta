The smallest next source obligation for this proof route is to derive the required auxiliary laws for the actual inherited current tables, then preserve them through the same current request. They must be derived from actual source history and the existing captured origins. They must not be added as an unexplained innerPast premise to a purported source warm theorem. An alternative proof route could avoid these shape laws; no such alternative producer was found in this bounded audit.
