# Case ledger

The actual hook completes. The188 producer retains every actual output and
supplies the completed OutcomeResources branch. Public restoration derives
the full current Packet for original cache and metadata at the same endpoint.
The proof does not add callback or native execution fuel.

A hook that stops is not a completed sibling transition. Its outputs remain
covered by188. ReceiptContinuation.stopped_hook retains those exact outputs.
Missing/finalization-stop/unhandled receipts produce no hook outputs.
The full worker induction must retain their actual stop reason and endpoint.
