The four public heads are `Fusion`, `empty`, `reference` and `nonempty_maps`.

`Fusion expression` is an induction property, not a proof for every expression.
It retains two actual raw builds at their historical entry and return heaps.
Each entry has the complete source Context. Both actual raw return heaps grow
into one Ready reader. Each raw result is available at that reader. Root
filters and stored calls then execute warm at that reader. No historical
raw-build/filter adjacency is required. No warm raw-source call or availability
of every unused lexical capture at the reader is supplied.

The lexical premise is the existing ReaderReplacementSlots.Paired relation.
Resolved reference slots have equal physical Empty Boolean tests. A nonreference
capture retains the same immutable value and equal maps on its original free
names. The interface also retains live Aliases and exact scoped self tests.
Reader replacement availability remains an explicit initial resource premise.
The conclusion is physical Empty Boolean agreement for the actual outputs.
There is no Generated-to-Empty premise, whole-parent output law, observation
relation, source-domain restriction, BinderFree premise or finite Cap.

`empty` proves the full interface by inversion of the actual source, filter
and stored equations. Both returned values are literal Empty.

`reference` generalizes the existing GeneratedVariableFilter proof to the
physical-Empty slot relation. The actual historical variable equations derive
the exact selected lexical slot, including out-of-range Empty. A reference
slot uses its supplied resolved Empty pair. Bare-reference filters leave both
references unchanged. A nonreference fixed capture has equal free-name maps.
Scoped self tests prove its two actual filters equal. Filtering introduces no
new free name, so the maps also agree on the selected filtered record. Actual
execute_congr then derives equal returned records. No law for the captured
Mu or any future source output is assumed. The private filter and slot helpers
follow the existing variable proof. They add no new execution model.

`nonempty_maps` is a stronger conditional adapter for arbitrary source syntax.
It uses the same historical source calls and the actual warm reader filters.
It does not need paired slots, live aliases, self tests or raw-growth premises:
the initial source Contexts and reader raw availability suffice for its proof.
SourceEmptyAbstraction.source derives the raw Empty tests from matching symbolic
input flags. The existing filter_empty_iff applies at the reader. Actual warm
filter verification derives filtered availability. StoredNonemptyReplacement
then derives the output status from nonempty resolved replacements on the
filtered inputs' free names. Reusing the older adjacent-filter theorem directly
would require extra reader availability for unused lexical captures; this
adapter instead composes its existing ingredients without that premise.

The constructed witness builds a genuinely used closed Mu from empty tables.
It instantiates two actual variable calls at different uninterned local names.
One map resolves to the actual Mu; the other leaves a literal reference. The
outputs are physically distinct and nonempty. Initial Ready, source Contexts,
replacement availability, live aliases, scoped tests, paired Empty flags and
all actual source/filter/stored calls are derived. The full variable law proves
output Empty agreement. The nonempty-map adapter derives concrete output
nonemptiness. The public statement exactly aliases the private checked witness.
This is an interface integration, not a general recursive-source fusion proof.
