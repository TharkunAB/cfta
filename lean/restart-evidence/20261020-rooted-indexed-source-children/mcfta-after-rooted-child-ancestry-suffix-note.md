# Selected binder resume: explicit suffix obligation

Added 2026-10-20 16:59 CEST. This note supplements the frozen ancestry design report. That report remains byte-for-byte unchanged.

The proposed selected_body_child_or_prior endpoint is valid with an explicit selected fullMu cell at the return heap of the actual completed whole source build. CompletedBuildRootedWriters.build_writer_or_prior consumes that exact fact. The endpoint does not automatically consume an arbitrary Origin.binder stop.

Origin.binder places its selected cell at a LOCAL request return heap. It supplies Reached at the binder entry. It does not supply Grows from the local return to the whole source return. Reached's callback-start growth is not that suffix. Ordinary Grows also does not create issued history or a rooted selected writer.

For a binder at the top of the original SourceRow, the local return is the source return by the receipt's indices. For a binder reached through one or more SourceRow.union constructors, a concrete suffix can be derived while those constructors are still available. Each union retains the selected member's actual return, the remaining buildMany suffix, the parent makeUnion equation, and historical Context. Context after the actual member build supplies facts and inputs for the actual suffix; buildMany_verified derives growth to the parent constructor entry; run_correct for makeUnion derives growth to the parent return. Compose these suffixes outward with any separately supplied later reader growth.

This is a proof route from real source schedules. It is not an existing field of Origin, and this note does not claim the route already implemented. A future consumer must retain the selected binder stop and its suffix in the SAME chosen existential during the SourceRow induction. It must not recover the suffix by proof identity, select a different binder witness, or infer it from the final Origin alone.

No change to accepted Origin is required for the current claim. Implement the suffix only in a concrete consumer that needs automatic local-stop-to-whole-return selection. Until then, keep the explicit whole-return selected-cell premise in the proposed resume theorem. No Lean or runtime job is run by this note.
