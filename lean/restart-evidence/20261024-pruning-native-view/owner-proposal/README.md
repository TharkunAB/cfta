# Value-level native pruning declaration proposal

This package proposes `SourcePruningNativeView`. It contains bare context/header fragments and exact review-only operation/type contracts. It contains no definition body, proof body, compiled module or test result.

Read `declarations-review.lean.txt`, `operation-equations.json`, `proof-route.md`, `local-statements.json` and `case-and-binder-types.json`. `contracts.json` is the STRING SHA-256 manifest for the six context/public fragments. `insertion-map.json` gives their order and future attachments. The combined declaration file is review-only and is not an additional compiled fragment.

All three definitions retain the full existing Symbol and Value/State types. Only the existing comparison Result carrier is reused. The old comparison reader is excluded. Actual repaired exposure, actual makeNode and actual second exposure remain explicit. The public completion statement concerns narrowAt; only the literal Mu bypass equation is exported for emptyAt.

Root must approve the exact declaration proposal and separately authorize a complete source draft. A compiler command requires the later whole-source review. `source-index.json` retains full live defining sources, exact cuts and static import routes. The top-level pins exclude only top-level pins.json and FROZEN.json.
