# Output compiler scope review

Reviewed by the component owner on 2026-10-16 19:22 CEST.

OutputCode preserves the frozen structural Code interfaces. Its request inputs require the finite ordinary domain and an empty seen list. Work continuations receive the actual Work equation, current WorkInputs, derived valid machine, Extension, and SemanticReady. Node and edge continuations receive residency and the OutputStored certificate for that exact child request. They receive no desired own-parent output profile.

The ordinary node proof follows the actual ordered hash join. Each returned row retains its physical residency through later child effects. The recursive edge certificate supplies profile `(R*R, max A 1)` for each paired original row. All₂ gives the exact number of result occurrences. The literal join count is at most `R*R`. Actual makeNode filtering and canonicalization cannot add rows. The constructor theorem includes coherent cache hits at the same heap.

The node dispatcher preserves source guard order. Reset uses an empty-domain child certificate. Self uses physical self_record before profile monotonicity. Swap exchanges the original profiles. Empty seen excludes repeated-pair references. Input domain inversion excludes Mu, union, and references in the remaining payload branch.

Accepted edge code traverses the literal zip. Each returned child keeps its conditional certificate and availability through later Extension. Input arity bounds the zip length. The final raw makeEdge uses that same returned child list and the actual combined guard. The sentinel emits `[Empty]`; `max A 1` is required when A is zero. The checked body proof distinguishes error and blocked outcomes from actual yielded code. It retains the exact operation-state return and then certifies the emitted children or sentinel code.

These are local code certificates. They do not derive finite native execution, literal instruction bounds, root capacity, GHC demand order, or runtime correspondence. The separate actual-trace interpreter must derive child certificates and returned-cell storage by mutual trace induction. These public local theorems take initial physical facts and current input domain. They do not take supplied future result profiles, final cache validity, or a successful own-body execution premise.
