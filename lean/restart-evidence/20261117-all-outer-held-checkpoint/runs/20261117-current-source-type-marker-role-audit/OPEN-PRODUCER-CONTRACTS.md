# OPEN source producer contracts

These are design contracts. They are UNPROVED, have no Lean declaration and
are not added assumptions to an existing source theorem. The source-facing
scope stays exactly the accepted initializer and literal real eager invocation
in ORIGINAL-SOURCE-SCOPE-REFERENCE-HEADER.lean.txt. Keep the same actual emitted
output, original workFuel/depth, no stop, full stored U and original root.
No implication from noStop alone to role consistency is asserted here.

1. OPEN: source Type/Marker occurrence-to-class provenance.
   From that source invocation and its SAME bundled causal/child ledger, derive
   finite occurrence qualifications for demanded Type fields and arrow-marker
   fields. At an actual arrow row the first staged child has Marker role, and
   the next two children have Type role. Ordinary catalog children have Type
   role. The exact terminal winner is the class reached by that SAME child
   trace. Preserve these roles through real UF merges, finalization and later
   callback tails. Do not infer roles from a label or from only-U atoms.

2. OPEN: source role-safe stored equations at the final snapshot.
   For each Type-qualified class, its exact stored fragment uses Type leaves,
   catalog constructors with Type children, holes in Type classes, or an arrow
   with a Marker-qualified first fragment and two Type fragments. For each
   Marker-qualified class, its expanded equation preserves the literal marker
   (possibly through marker holes); pending classes can use the marker base.
   Derive this from actual allocation/selected-child/finalizer receipts. Do not
   assume TypeFragment of the actual stored arrow. Its first fragment may be a
   hole. Protect OLD equations with actual R/E histories; those histories alone
   do not supply a role qualification.

3. OPEN: authentic class consistency and same-evaluator base.
   At the SAME final forest, prove that no class required to produce a Type is
   also required to produce the marker, and prove that every referenced role
   closes through the exact roots lookup. Source catalog separation makes this
   distinction necessary. A root-based pending base may then choose the marker
   on Marker classes and var1 on Type classes, with arbitrary defaults only on
   other classes. Roots.class_iff gives UF-compatible choices once actual role
   consistency is proved. The existing all-var1 base is not a marker base.

   The required single-evaluator conclusion is, for the SAME base/roots/values
   and every supplied evaluator fuel, TypeIn catalog (evaluateSlotsWith ... uv)
   at Type-qualified uv and evaluateSlotsWith ... mv = marker at Marker-qualified
   mv. Its source qualifications/base must be DERIVED, not supplied as future
   typing, assignment, Satisfies or model facts. This is the next semantic
   producer target, not a claim of a completed generic lemma.

4. OPEN: ordered recompletion and final semantic preservation.
   The same evaluator must type all retained historical targets. Apply ordered
   patching only after authentic owner order, exact same-position class
   compatibility and dependency closure are derived. Every patch must preserve
   marker roles, other current native domains and retained guards under ONE
   final assignment. Existing ordered recompletion proves UF/equations/arrow
   Holds and kept agreement, but has no native/guard conclusion. It does not
   establish ALL historical causal obligations or original root acceptance.

Minimal first bounded source leaf: exact original-U arrow invocation -> the
three ACTUAL staged positions have Marker/Type/Type origin, with the SAME
terminal winner and returned stored equation. Existing source rows fix the
layout, and indexed child traces identify the invocation. Neither an independent
terminal marker demand nor an unrelated assignment witness may be spliced in.
A formal role datatype/header needs this authentic provenance choice first;
this packet deliberately introduces no replacement grammar or framework.
