# Premise classification

The header is frozen before proof. The candidate is UNCOMPILED.

Current facts: exact recursive Packet at the actual caller/cache. It supplies Context and pending-slot realization. The parent node is Available and closed in that SAME current heap; this is a genuine past source row fact, not a future native result. Its selected row is exact. These parent facts must come from the real captured source/Frame/post in the caller composition; Packet alone does not constrain an arbitrary incoming value.

Actual input origin: literal cached own preparation at its original preparationHeap/captured cache, and indexed selection from its staged children. These determine membership of incoming in the source row. The preparation heap need not equal the later current native heap. The theorem derives incoming availability and closedness through current parent facts, prepare_inputs, and the actual selected child index. It assumes no incoming availability/closedness directly and invents no second stored operand slot.

Actual operation: the literal SharedIncomingNode.run successful outer observation at the supplied representativeFuel/nativeFuel/p/h. The full returned caller, queries, read Core and raw action list are retained. An outer .ok raw list may contain rejection/error actions; the header does not assume that its inner actions succeed. No later execution, Trace, Returned law, or native completion is supplied.

Conclusion boundary: a state-identical branch gives QueryHistory 0. This is an exact state receipt; it is not a claim that all operation branches with identical endpoints performed no native lookup. The native branch derives the real incoming/old request and QueryHistory 1 to the actual PRE-PHASE caller. The literal enabled-check phase and final caller are retained separately. A disabled or exactly skipped check gives QueryHistory 1 at the returned caller. A performed enabled check can change checked fields and fourth; QueryHistory alone has no constructor for that transition. The theorem does not pretend that it does.

No Fits/Room/Admits premise is needed for this structural extraction: the actual successful observation supplies its own completed native call. Original budgets are unchanged. The current parent source qualification and exact Packet are required past source facts. This is the prepared-source-child case; other incoming origins and the performed-phase history composition remain explicit scope boundaries. It is not a full semantic warm-history theorem.
