For coherent records, actual descent retains a class exactly when at least two distinct suffix paths remain under the chosen child (`SourceEqualityDescend.lean:18–34`, `92–114`). Thus an all-drop hypothesis is:

    for every C in E and u,v, j::u in C and j::v in C imply u=v.

This is about full completed components, not the raw input class list or just `kept`.

## Proposed lemma 1: the completed equalities separate one child

Define the least equivalence relation `Rel E` generated by

    a ++ suffix  ~  b ++ suffix

for a,b in one component of E. This is right congruence on position paths. It is not prefix congruence. Existing `EqualityNormalize.Connected` has only class edges and transitivity; it does NOT already include suffix extension (`EqualityNormalize.lean:1098–1100`).

Proposed exact contract:

    E is an actual congruence fixed point and is consistent;
    E satisfies all-drop at j;
    Rel E (j::u) q and Rel E (j::v) q;
    ----------------------------------------------------
    u = v.

All class paths are proper; the empty path is isolated in `Rel E`. This proper-path fact must come from the actual class representation, not from the adjective "normalized" alone.

The proof obligation is completion for the arbitrary suffixes in a finite relation derivation. It cannot be discharged by `components_equal` on recorded paths alone. Existing `fixedPoint_congruence_closed` handles each suffix requested by an overlapping recorded extension (`EqualityNormalize.lean:1003–1019`). `components_equal`, strict subsumption transitivity, and irreflexivity provide the overlap and cycle facts (`EqualityNormalize.lean:1039–1095`). A derivation induction must reduce arbitrary suffix overlaps to those existing facts. This is the precise pure geometry still missing.

No source sort law is needed if this relation handles composition transitively. The actual tail-first schedule still matters for the next execution lemma. Existing `ordered_perm` proves only permutation; do not treat it as a sortedness theorem for normalized records (`SourceEqualityClassOrder.lean:55–65`).

## Proposed lemma 2: actual selected edits preserve positive position support modulo E

First use a finite-cap subcase to state the law precisely. For a value with `Cap Plain depth`, let P(value) be the finite SET of child-index paths to nonplain ordinary rows. Stored unions contribute alternatives without adding an index. Plain Mu regions contribute no positive path. Different canonical row indices at the same child-index path contribute one set element. This is deliberate: Required and native products can duplicate row origins, so counting rows is invalid.

For an ordinary owner V, the selected own-positive root gives `[] in P(V)`. Parent receives only the literal row children. Every initial support path supplied to that Parent is therefore a nonempty path in P(V).

Proposed actual-return contract:

    original owner V and literal selected row;
    exact original false-primary scan receipts;
    exact Required return and chronological ClassWorker.pass return R;
    E from the actual inherited-first combined prefix;
    actual causal support laws for warm Merge/native cells;
    finite positive support on the participating values;
    ----------------------------------------------------------------
    for every s in P(R.children[j]), there is q in P(V), q != [],
    with Rel E (j::s) q.

The induction must derive the support law from real empty-table initial prefixes. It must not accept the desired source relation or a future outer return. Each class uses its actual captured forest, which can already have changed. At an edit leaf, actual projection changes the source prefix, Merge can remove guards or select columns, and native intersection transports a positive path from an actual ordered operand. Ordinary row products conjoin guards; a positive output need not retain the COMPLETE guard of either source (`SourceCurrentNativeActivePairedRows.lean:67–77`). The law must use positive path support, not equality with one full input row.

Required's identity/plain/ordinary origin cases can support its stage of this induction. Actual accepted recursive exposures are hereditary Plain (`SourceCurrentRequiredGuardOrigins.lean:125–166`; `SourceCurrentRecursiveSourcePlain.lean:168–190`). Native common-cap preservation exists (`SourceCurrentConstrainedCapCurrentNative.lean:57–124`); it is not yet the finer path-support law. Existing class-cap results allow `inputDepth + capturedDepth + sizeOf edits`, then compose these bounds through the tail-first fold (`SourceCurrentConstrainedCapMixedEdit.lean:31–37`; `SourceCurrentConstrainedCapMixedClassPass.lean:32–35`, `89–117`). They do not prove a decreasing owner rank.

The FULL immediate-owner conjecture does not assume that the whole owner has a finite Plain cap. A nonplain Mu may occur in a region that no selected path enters. Therefore the finite-cap version is only an intermediate scope. The general support observer must also mark those opaque nonplain Mu barriers, or the execution induction must prove that those regions remain untouched. Original false gates exclude nonplain Mu at or below their endpoints (`SourceEndpointReachability.lean:23–47`, `68–99`), but do not by themselves give a cap on every unrelated original child. Transporting this exclusion through earlier edits is part of the same substantive execution obligation. It is not justified by a false gate on a changed forest.

Conditional consequence, not a proved result: if the returned child equals V, lemma 2 selects a map P(V) -> P(V) minus {[]}. Lemma 1 makes any such selection injective. This contradicts finiteness since [] belongs to P(V). This finite argument is downstream work. Do not implement a cardinality wrapper before the actual support relation is available.

## Physical-only cache gap

`MemoMergeEffects.Stored` requires only the original tagged key, Available input/output, and conditional closedness (`SourceCurrentMemoMergeEffects.lean:21–24`). In a suitable coherent heap containing an available closed ordinary owner V, define one entry at `Value.empty.referenceOf` with original Empty and result V. This table satisfies Stored. `AllocatedMergeWorker.call_hit` returns V from Empty at any successor work bound, with no heap/equality/memo change (`SourceCurrentAllocatedMergeWorker.lean:59–70`, `85–91`). Empty has no positive support. A local support statement from physical Stored alone is therefore false. This is a source-grounded fabricated INITIAL table construction, not a claimed reachable empty-table counterexample or implementation defect. A separate bounded formal check is now authorized for this exact boundary.

Even the current physical writer is not enough to close recursive support. `MergePositiveRowOrigins.Writer` stores an actual body Run and historical Stored, not support laws or Raw for its nested historical table (`SourceCurrentMergePositiveRowOrigins.lean:37–44`). `positive` identifies source fields and actual recursive child requests, but that child Run can still use a hit whose semantic support is absent from its type. `OuterMergeHistory.initial_reached` derives Raw at an arbitrary actual unfinished prefix from an empty Merge table (`SourceCurrentOuterMergeHistory.lean:347–369`). This is useful causal provenance, but the extracted Writer drops the stronger recursive cache invariant.

The repair is to prove the actual path-support law for Run/Call under a cache whose returned entries satisfy that SAME law, then propagate that cache law from empty through Parent and unfinished Outer prefixes. This can follow the existing effect/language contract induction. It must include warm first winners. A supplied `CacheCovers` language inclusion is not sufficient for structural support: Empty's language is empty, so Empty-to-owner coverage is vacuous (`SourceCurrentMemoMergeLanguageContracts.lean:15–27`).

Native physical Good likewise records ready operands and available results without a semantic result law (`SourceCurrentNativeOperationInvariants.lean:28–35`; `SourceCurrentAllocatedNativePhysicalCompletion.lean:26–31`). `NativePrefixWriterMaps.prefix` derives actual node/edge writers from an actual clean trace plus INITIAL History (`SourceCurrentNativePrefixWriterMaps.lean:541–558`), but each extracted `Written` retains a body Trace without an internal History premise (`SourceCurrentNativeWriterReadyRetention.lean:43–53`). A stronger support invariant must follow that same chronological trace or retain enough global history to inspect each returned child. Do not manufacture internal History from Grows. The outer warm-edge history also retains a literal Parent execution with physical Stored, not a new structural support law (`SourceCurrentOuterParentHistory.lean:34–46`).
