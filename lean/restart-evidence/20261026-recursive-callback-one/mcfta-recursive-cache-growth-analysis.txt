2. Smallest missing numeric result and composition

First prove list-weight laws for the EXISTING B definition: Frame preserves B; appending an empty pending slot preserves B; a stored pending-slot replacement adds the difference of bucket lengths; a distinct-slot assimilated update preserves B; writing an enumerated value does not increase B. A balanced sum equation avoids truncated Nat subtraction in the replacement lemma.

Use the actual existing producer witnesses to obtain a child receipt bound:
  counter(after) <= counter(before)+1
  B(after) <= B(before)+bucket.length.
It should include valid raw-empty returned caches. It must not add Safe for rejected caches. Terminal fold conservation and incoming descendants.length<=bucket.length give the terminal case. Existing terminal and fold public packets alone do not bound final target bucket length; the proof must use the actual assimilation/write equations or a new observer lemma proved from that execution.

Induct TraversalCompletion over its actual ordered children. For inputs=[(node_i,bucket_i)], the useful result is:
  counter(after) <= counter(before)+inputs.length
  B(after) <= B(before)+sum_i bucket_i.length.
The original child inputs remain fixed across the suffix. This is compatible with the current genuine pending/protection transport. No recursive subtree is executed inside this shallow child traversal.

For one completed captured edge, let T=tries.length, A=edge.children.length and S=scs.length at the captured input. The original-only bounds are:
  counter(receiptCache) <= C+T+A
  B(receiptCache) <= B+A*(S+T).
CostBounds.descend_length_le and suspended_length (CostBounds.lean:16-27), then its child-bucket argument (47-65), derive every bucket length <=S+T. Own allocation adds T slots but zero mass; finalization only reduces mass. These are conservative bounds; subtracting the finalized parent bucket is optional.

OriginalForecast.cost_le (OriginalForecast.lean:26-56) already supplies T<=GuardWidth.width alphabet and A<=scalar profile from current Fits/Heap/Available/Linked and actual selected membership. Hence at the ordinary entered cache one can use:
  Cnext = C + GuardWidth.width alphabet + scalar profile
  Bnext = B + scalar profile*(B + GuardWidth.width alphabet),
since the selected stored S<=B. For a forecast from BEFORE narrowing, also export B(retained prefix)<=B(original) from its exact same-bucket replacement/clear receipts; current narrowed_admission exports only the selected S bound and counter equality. NarrowAdapter.adapt_core (21-36) retains the exact observed core; NarrowContext's actual write shape replaces the same scs. ParkedRestart clears scs to [], and callback Frame.values/counter preserve both measures.

C and B must remain original input data. Native Fits does not bound arbitrarily many enumeration-only .none allocations. Counter alone does not bound a bucket with arbitrarily many repeated suspended entries. SlotBound limits IDs, not multiplicity. No theorem should infer either numeric upper bound from CacheValid, Safe, FragmentHistory, or native profile alone.

A positive-depth hook needs the same construction from its ACTUAL aggregate subtree Post, composing it with the completed-edge Post first. OutputResources for an earlier emitted output is not a substitute for that aggregate endpoint. Query equality alone must not identify different full Memos.

This preserves logical/cache admission, not numeric capacity automatically. The subtree must return Fits and a guard carrier at its actual native endpoint, and the outer schedule must pay its work before the next sibling. The old zero-depth edge schedule is insufficient for positive recursive native effects. A reservation based on the original depth and C/B/profile/alphabet recurrence is the missing resource composition. Each returned-cache recursion needs the Cnext/Bnext receipt bounds above; each sibling restores the old C/B but starts from the actual larger native profile/carrier. Stops with no endpoint do not execute a sibling; no Post or cache validity should be invented for failed raw/native observations.

Recommended next unit: add actual scalar child/traversal/captured-edge bounds while retaining the same completion witnesses, then carry those bounds beside Packet into a depth induction. Keep FragmentHistory's existing pending/rank contract and old completion types available by projection. There is no need to add a future successful subtree or final cache bound as an admission premise.
