## Concrete induction contract

A faithful source fragment law needs the following proposed interface. This is a design target, not a proved general theorem in this review.

For one source expression and two actual historical raw returns, retain the historical Contexts, actual source equations, return-to-reader growth, raw availability, common reader, live aliases, self-name tests, lexical Inputs and replacement maps. Retain the OUTER parent bare-self selector. It determines which direct own atoms survive. A member's standalone-self exception must not replace the surrounding mixed-union exception.

The initial physical inputs are two actual same-reader fragment call families:

- For each retained literal reference or Mu atom of either raw return, an actual `execute atom map reader = done output reader`.
- For each literal raw row of either raw return, an actual `RowCalls map reader original output`.

The law must derive two kinds of matching fragment certificate:

- Each retained left atom call has a retained right atom call and `Clauses reader (Relation P)` between their actual outputs.
- Each surviving left raw row call has a right raw row call, opposite survival, and `RowMatch (Mutual (Relation P))` for their full outputs.

Here `Relation P` is exactly the checked at-most-one-source-pair normalization relation. The law must not substitute arbitrary transitive closure of source generators. Reverse matching requires the corresponding reverse certificate; it does not follow from one directional theorem.

These call families restrict through root-union literal and row inclusion. Therefore strict member induction can use the current outer parent schedules without constructing or warming a whole subgroup. The global own-retention selector must pass through that induction. The new assembly theorem consumes precisely this kind of fragment result at the top union.

## Remaining source obligations

Original member indices are necessary source data, but they are not a semantic induction certificate. A row inside a member can lie below another root union. `Row member original` is not generally physical `original in nodeEdges member`. The new ordinary worker applies only when the historical source expression is an actual node. A smart-unused source binder can also return ordinary rows and needs its own actual binder readback case.

`NativeBinderReaderRows.binder_row` is relevant to that case: actual selected-cell readback connects a physical returned row to the current strict-body raw call using final-reader History and forward growth. Its conclusion is a complete epsilon `Origin` statement. It must not be read as literal row membership in that raw body. A fragment proof must retain or invert the extra finite epsilon witness.

A source reference can return an arbitrary resolved lexical Generated pair. The fragment proof must obtain local clauses from an explicit lexical induction certificate or a genuine smaller Generated derivation. Membership alone does not imply `Directed`. A literal Mu output requires actual successor clauses for the selected older writer. The current requester's strict source size does not bound that writer's source expression. The new selected-writer generator theorem supplies actual memberships and schedules, not these semantic clauses.

Observation depth decreases at matched ordinary row children. It does not decrease at a Mu epsilon step. Finite epsilon witnesses supply a decrease only when the actual next comparison retains the genuine successor relation; an arbitrary new generator chain can lose it. Thus no same-depth self comparison, global closure law, or backward observation transport is used in the reviewed modules.

This batch closes the actual ordinary row fragment schedule and causal survival case, and provides conditional union clause assembly at the original reader. It leaves reference-slot clauses, the general binder fragment case and the full source Directed instance open. It does not establish traversal termination or Haskell correspondence.
