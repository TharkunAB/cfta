Invariant completeness

Valid (FlatUnionFind 49–57) requires every Parent target to have a STORED Root. Each stored Root has a Nodup member list, size equal to list length, and exact membership iff direct root lookup equals that representative. This excludes stale, missing and extra members, parent chains and self-parents. It is stronger than just Nodup and size=length.

The stored-root requirement also closes the default-root case. If a representative is absent, no other variable can point to it. entryOf_spec (72–106) derives exact singleton metadata for that absent root. It does not assume missing roots have no incoming parents. Root self-membership and positive size follow from the exact membership clause. initial_valid accepts duplicate initialization inputs, as the source does.

Exact source operation

root makes one map read. find returns the same forest. entryOf has the same fallback as Haskell: any entry that is not a Root gives size 1 and singleton membership. Under the invariant, the fixed-point root inputs to unionRoots cannot be Parent records. The source contract explicitly requires distinct representatives (Haskell 108–109); unionRoots_valid requires both fixed-point receipts and distinctness. union derives them from actual one-hop root reads and checks equality before unionRoots. No precondition is silently dropped.

The strict size comparison selects right only when left is smaller. Ties select left. merge redirects the losing member list, then writes the winning root with winnerSize+loserSize and loserMembers++winnerMembers. This matches the source update order and tie behavior. The same-root union branch retains the exact original abstract map.

Fold and final invariant

redirectMembers_lookup (166–178) proves exact pointwise writes without any invariant or Nodup input. Duplicate visits cause no additional effect because every visit writes the same Parent winner value. merge_lookup (187–192) preserves the final root write's precedence.

link_root derives the precise old-root redirect. link_valid uses that fact to prove the final complete-member invariant. It derives list disjointness from distinct old roots and exact membership. Nodup append and exact length then justify the added size. Existing parents outside the losing class retain valid stored root targets; all parents of the old losing root are covered by its complete member list. The proof does not assert the complete invariant at partial fold states, where root metadata can be stale.
