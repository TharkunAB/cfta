## Minimal actual path

Use the new PreparedRecursive worker itself, not the old Recursive worker or old Failure. The relation is indexed by actual workFuel, recursiveFuel, metadata, Caller, queries, captured cache, supplied next decision, and one actual output. Its four cases mirror the complete output-producing branches:

1. A supplied `none` emits the exact stopped metadata/cache/native endpoint singleton.
2. A supplied `.done` emits the exact no-metadata/cache/native endpoint singleton.
3. A successful actual parked prefix singleton enters the exact smaller-depth prepared resume with the same Caller/queries and framed returned cache.
4. A successful actual narrowed prefix enters actual SelectedContinuations. Its invocation certificate retains the literal entry-plus-one-native-preparation pair and the actual ordinary or singleton opaque/terminal hook input. A false actual recordTypes singleton supplies the literal next smaller-depth prepared resume cache and Restart.decision. That tail emits the same output.

All other bounded worker branches emit no outputs or retain only outputs from the selected hook. At depth zero an expansion emits no outputs. At a true callback record, the callback emits no outputs. A diagnostic callback likewise emits none. `finish` retains hook outputs from both complete and stopped alternative folds. Thus outputs produced before a later stopped sibling or by a stopped hook must keep their actual invocation path. No successful suffix or successful aggregate outcome is needed.

The selected invocation must distinguish the original stored handle/decoded value from the prepared native value and heap. Ordinary dispatch uses the prepared node's rows at the captured target and captured entered cache; earlier hooks supply the actual current native Caller and queries. Opaque and terminal dispatch use one actual Opaque.run receipt through ReceiptContinuation. Terminal winner and captured target need not be equal. A remaining Mu or Union after one unfolding is retained as that actual shape, not replaced by an ordinary node premise. The resource-free relation must therefore use the generic new invocation certificate from Root, not old OrdinaryInvocation.
