# Stored node expansion review

The checked theorem expands every original ordinary row at the exact warm caller heap. It requires `Normal`, source node availability, available environment replacements, and the actual warm parent execution. These are component premises. The theorem does not construct an initial parent call.

`RowCalls` retains the ordered literal stored child calls, the exact full edge request, its symbol, its complete guard, and its child count. `Expansion` pairs every original row before dead-row filtering. The result is ordinary. At every view heap, its exact row origins are the surviving output rows.

The closed branch derives closed children from coherent free-name metadata. Each child then returns its original value. Resident edge requests return their original edge at the same heap. The parent remains the literal stored value. The proof does not infer canonical parent row order from `Normal` or `Ready`.

The open branch extracts the actual encoded row execution. It derives common-heap row replay from that execution and actual constructor growth. It recaptures each child plan into that child's own stored execution with the original environment. Arbitrary nested Mu children remain permitted. No per-row or per-child future completion is an input.

Two source-built integrations are selected. The closed fixture has two rows and an actual productive raw Mu child. The open fixture has two original rows. Replacing its free capture with Empty removes one row. Its initial call constructs the reached ready heap, and the parent replays there. Both examples derive the new expansion certificate. They do not identify distinct node keys or prove a general reconstruction/union fusion law.
