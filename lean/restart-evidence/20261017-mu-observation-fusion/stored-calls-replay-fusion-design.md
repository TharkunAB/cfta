# Proposed initial union-normalization fusion endpoint

This is a design. No general fusion theorem is claimed here.

Initial inputs are Ready before, Values before originals, and Replacements
before environment. Let normalized be the literal makeUnion result. The
endpoint must construct an actual execute of normalized.1 at normalized.2.
It must then construct Calls environment originals at that first returned
heap, followed by the literal makeUnion of those member results. It must
retain every actual full heap, Keeps, and final result availability.

The proposed conclusion relates the two final Values by physical-empty
agreement and Same at every finite depth in the common final view. Exact
reference and physical row origins in every view would be stronger. That
stronger conclusion remains proposed until the case proof establishes it.
Physical full-Value equality is already false by the prior mixed-union
fixture. All-depth Same alone does not imply physical-empty agreement by
the closed raw-Mu fixture in this directory.

Construct both schedules before the case proof. SourceCurrentStoredCallsReplay
then transports every executed original occurrence to the same complete
heap. Flattening and duplicate selection need exact origin membership.
SourceCurrentOpenObservationLists.of_members handles the corresponding
root-list observations. Its append theorem composes the separate lists.

For an all-ordinary merge, canonical output rows retain actual source rows
and unchanged full child payloads. Extract both actual child sequences.
Replay identifies their ordered child outputs. Match surviving rows using
physical empty agreement, full symbol and guard, and exact child outputs.
Use makeNode_empty_iff for the empty case, and makeNode observation
congruence for live rows. Avoid replacing physical empty tests with Same.

A closed ordinary capture has no environment-dependent child. Derive this
from coherent node_free and childFree_member. A closed union similarly
has only closed members. Prove their exact warm reconstruction/readback
adapters rather than assume an open branch or erase a raw Mu. Existing
node_complete and union_complete expose both closed and open alternatives.

The normalization operation does not alter a nonordinary atomic Mu body.
The first proof can therefore replay calls on the same stored child value.
It need not infer a relation between different Mu bodies from equal keys.
General body/ordinary reconstruction fusion remains a separate obligation.
