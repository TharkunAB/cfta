# Observational projection after class-fold edits

Read-only audit, 2026-10-19 01:12 CEST. No Lean job or production edit was made.

## Exact remaining boundary

`ClassStructuralOrigins.node` consumes a physical `RequiredRowOrigins.RowAt result positions index row`.
`ClassFoldStructuralOrigins.fold` preserves its initial forest index and returns either an original structural occurrence or a chronological leaf/Head event with a residual structural occurrence.
These results retain full row symbol, guard, and arity.
They do not return a recursive relation between whole source and result values.
In particular, their output is not a certificate for arbitrary later projection and unfolding.

`RowAt.body` follows a literal stored Mu body.
An actual `ProjectionRead.Read` follows repaired `execute body selfEnvironment` at its reader.
The returned ordinary row can have reconstructed children and new physical identities.
For example, unfolding a stored `mu x. f[x]` replaces the stored reference child by the Mu value.
Thus the actual output row cannot be used as a literal indexed lookup in the original stored body.
This example explains the missing inference. It is not a checked refutation of all full-field source transport.

`StoredLiteralRowLineage.execute_row` does not remove this boundary.
It starts from a literal output row and an actual stored execution, and retains lexical child calls and external replacement cases.
It does not turn an arbitrary complete epsilon origin into `RowAt` in a different earlier source.
A retained Mu can also select an earlier writer. Its actual writer and current requester must stay distinct.
`RecursiveHeadChainRows.actual` already records chronological collector choices and actual Mu calls, but its terminal can be a generated ordinary record. It explicitly does not identify every terminal with an earlier nested stored body.

## Stronger assumptions that must not be inferred

The original false gate names the original forest. Required and each class phase can change that forest.
`RequiredPrimaryRetentionBoundary.required_changes_primary` already refutes false-gate retention through Required, even for coherent normalized active two-path records with closed returned endpoints.
No false gate on prepared or later class-phase values follows from the original gate.

A native event is not a plain region merely because the original branch passed its gate.
`SelectedRenewalBoundary.selected_competing_continuation` already constructs a completed class that imports a positive continuation from the competing original slot.
Therefore an observational class theorem must keep an event residual.
This is a structural counterexample to discarding events, not an implementation defect or a counterexample to all numerical ranks.

The new source-exclusion proof also needs the causal `ConstrainedCapGuardHeap.Heap Plain` at actual read/Head entries.
Physical Good, structural row provenance, or a returned-cell history alone does not derive that invariant.
Existing lower/Parent/outer guard-heap producers can carry it from construction.

## Existing complete epsilon endpoint to reuse

`MergedFreshOrdinaryExposureOrigins.nodeEdges_origins` derives
`MergedFreshOrdinaryGraph.Origin view [value] row`
from a literal successful read, initial semantic/covered/availability facts, and growth from the actual read return to `view`.
The simple valid choice is the read's final heap and reflexive growth.
It does not license moving this origin backwards to an arbitrary earlier reader.

`NativeOriginExposure.returned` already consumes complete epsilon origin, actual native writer history, current Good, input codecs, and the returned cell.
It returns the exact terminal request, captured writer interval, owner/finish receipts, and, when the returned result is Mu, its actual reader-relative stored unfolding and remaining origin.
`NativeOriginExposure.request` derives codecs and the returned cell from the literal query trace.
These endpoints do not require physical `nodeEdges result` membership or closed query operands.
A later actual read can be connected by forward physical/history transport. `History.advance` retains the tables and records growth.
Current Good still needs its physical producer; it cannot be inferred from History alone.
A new leaf wrapper that assumes the same complete origin and current Good would duplicate these endpoints.

## Recommended bounded next theorem

Prove one observational-spine producer by mutual induction over actual `NodeReads`, `ChildrenReads`, and `RowsReads`.
A suitable next module name is `SourceCurrentClassObservationSpines`.
The class/fold lift can follow the exact chronological schedule after the node theorem works.

Its node endpoint should retain these inputs:

- Original value `original`, the original false `NodeTrace` for the requested natural path, and its historical semantic/normal/availability facts.
- The ordered Required `Origin original prepared` derived by the caller from its actual Required return. Use identity when no Required phase precedes the edit.
- The actual `EditNode ... prepared before edited after` and its full `NodeReads`, populated/allowed/safe premises, initial shared readiness, memo validity, native history, and causal guard heap.
- The actual projection of `edited` at its real reader, followed by its actual complete row read and selected nonplain row. Keep each returned heap explicit and use only forward growth/keeps.

It should derive one of two results:

1. An ordinary `Route` at the same requested path in `original`, full source/output row fields, and the actual reconstruction/child-slice chain for the surviving row.
2. An actual leaf or Head cut in that same edit execution, with the residual path and the actual remaining edit/projection/read continuation that reaches the selected row.

The second result must be an execution-derived residual, not an assumed row relation.
Its constructors must retain the canonical output index, raw row index, selected signed child, literal earlier and later child calls, captured heaps/memos, and relevant event receipt.
A leaf cut retains the actual native result and query writer.
A Head cut retains its actual exposed value and the actual recursive body edit.
If later edits occur after the cut, retain those edits as part of the continuation.
Do not replace that continuation by a projected read of the unchanged event value.
That replacement is not justified when later edits change its children.

This producer should construct the path-safety relation. It must not take that relation or the desired parent source origin as an input.
At untouched branches, the original gate and Required origins supply safety by the existing Required proof pattern.
At changed ordinary branches, actual row rebuilding and `SharedEditChildLineage.Slice` supply the same ordered selected-child occurrence.
At an event, stop and retain its real remaining execution instead of claiming plainness or a physical `RowAt` for its observed row.
Once the residual reaches an unmodified native result, the existing complete epsilon endpoint above supplies the captured writer and retained-Mu unfolding.

The source branch must not claim unchanged children or `All₂ RequiredRowOrigins.Origin` across arbitrary class edits.
Those edits can introduce new native children. Keep the actual child-edit/rebuild chain instead.
No rebuilt child mass bound, decreasing global rank, all-source Directed theorem, or termination claim follows from this bounded producer.
