# Original-input cold universe readback

Run `python3 check.py` from this directory or pass its path from the repository root. The checker uses project Nix, own-source warnings as errors, and the exact public theorem list with standard axioms only.

The allTypes endpoint composes actual cold probe history, derived reservation absence, normalized callback execution, and source cleanup. It derives a closed Mu, the exact actual ordinary body, Facts, availability, and the resident Mu key and record. The typesOf endpoint uses the original library and query. No successful constructor, callback, cache miss, fuel, or resource premise is supplied.

The endpoint starts from empty caches. It does not prove arbitrary incoming-cache history, native lazyMap/allocation-order correspondence, generated intersection closure, or a bound for all enumeration work. checked.json records the source hash and every public law. No build archive is needed.
