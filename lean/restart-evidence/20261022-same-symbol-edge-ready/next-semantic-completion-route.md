# Direct row semantic completion route

This is a source-only route. No new adapter or compiler check is claimed.
SourceRecursiveIntersectionInputExact.lean defines finiteInput and
inputBounds in SourceRecursiveIntersectionInputView. They derive the
semantic finite-input interface from actual closed original roots.
The same file's source_schedule_total proves eventual node execution.
It does not directly state the required edgeSemantic completion result.

For two rows of actual closed original node roots, rows_readback in
SourceRecursiveIntersectionInputLanguage identifies their semantic rows.
IntersectSchedule.roots_ready and ready_rows in IntersectTotal.lean can
supply the edge WorkReady packet. Its call_eventual theorem supplies semantic
edge execution. IntersectRequiredFuel.Completes needs one such execution.
SourceRecursiveIntersectionNative.edgeSemantic identifies the exact
request, after checking the empty-domain conversion.

The new adapter must derive parent validity, closedness, availability and
actual row membership. The original ruleOut pivot and promoted candidates
are input rows. An allocated intersection result is not a later operand.
This can keep one source snapshot for a cluster. Parent reconstruction
and later semantic-context changes still need their own proofs.

H8 native scope, readiness, Good, Contextual, SemanticReady, ActiveAbove
and actual-prefix WordRanges remain separate requirements.
This route does not establish native termination, a result law, sequence
capacity, the full public pass, convergence or Haskell correspondence.
