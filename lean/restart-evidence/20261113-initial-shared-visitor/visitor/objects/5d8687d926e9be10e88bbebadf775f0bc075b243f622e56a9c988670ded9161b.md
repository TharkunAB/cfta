Status: proposed private header and proof plan only. No theorem body exists.
The child/hook output types are Type in this first header; they can be made
universe-polymorphic by an elaboration-only change if the client requires it.

The theorem specializes edgesOf to InternedEdgeResidency.nodeEdges, as the
actual original-input eager source wrapper does. An arbitrary edgesOf is
not enough: it could supply unrelated edges. No selection-membership premise
is introduced.

   No shallow Parent receipt or independently produced preparation is used.

2. Unfold only SharedPreparedChildPolicy.runWithChild at the SAME literal
   preparation observation. With the derived empty bucket, its terminal
   test is false. Its node branch is EXACT scan visit captured rows
   firstCaller saved. Retain the whole Preparation × Option Fold equality.
   This keeps every processed receipt, output and stopped/native endpoint.

3. Add one pure generic SharedBranching.scan_append lemma, analogous to
   NativeContinuations.run_append but valid for arbitrary executed visitor.
   It is a list induction with the same complete/stopped append equations.
   Combine take/lookup/drop with scan_append. The statement MATCHES the
   actual prefix result instead of accepting a future reach certificate.
   A stopped prefix has no subsequent head event. A completed prefix gives
   its OWN rowCaller/rowQueries, then the actual visitCapturedWith executes
   before the suffix. Never pass firstCaller to every sibling.

4. The indexed lookup derives rootRow membership in rows internally.
   Beta's same-preparation inclusion derives original root membership.
   Call public SourceSynthesisCurrentFirstFilterSourceLink.
   current_initial_filter_interval ONCE for that rootRow. Its complete
   original goal/candidate builds, makeEdge, makeNode, guard and full child
   records remain the returned source interval.

5. Observe CachedOwn.prepare at rowCaller.checked.native.machine.heap,
   with the SAME captured Core and empty incoming bucket. Its success
   singleton shape retains the original rootRow's two child VALUES and
   symbol by its actual zipIdx.map. This uses no Ready or completion
   supplier and does not rerun a native query. Other own-prefix outcomes
   remain possible and retain the source origin; no support/totality claim
   is inserted into the header.

The interval is immutable original source history. For arbitrary child/hook
operations this theorem does NOT claim original heap residency, Facts or
Available at rowCaller. Those require the real native Post from the concrete
resource proof. The header deliberately records the actual sibling caller
instead of pretending every sibling starts at the initial native heap.
