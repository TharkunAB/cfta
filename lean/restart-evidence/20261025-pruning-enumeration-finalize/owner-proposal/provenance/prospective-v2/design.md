# Captured-slot finalization proposal

Recommend three heads: finish, run, complete. This is a prospective interface. Root must select the exact headers before an owner is frozen. Root owns all bodies.

finish follows the source suffix. It clears expansionAncestry, reads the current raw target, writes the enumerated fragment at that same raw target, and returns the fragment. A missing raw slot retains the existing rawValue error. There is no representative lookup or replacement of the captured target by a later winner.

run first binds one typed local reset cache. Root will assign it the existing Cached.frame of the cleared core and original cache. The worker reads reset.core.values[target] next. On a present old value, it uses NativeIndex.write with gained=[] and lost=references old, at reset. The returned cache has the same reset/write core as finish. A missing raw slot remains Option.none in this cached representation. The theorem's actual stored equation excludes that partial domain. It allows every present old UVarValue, including eliminated and enumerated. The finish monadic binder _old has type UVarValue Symbol and is deliberately unused after forcing that read.

The producer derives the raw enum singleton and finite stable cached run. It assumes no prefix success or callback completion. The fragment is runtime input to this local suffix. The current stored equation supplies the allocated target bound. Existing count_complete supplies a uniform bound for removal of the current old references. Existing canonical replace_correct supplies post-count correctness; no second count identity is needed. candidate on an enumerated fragment is false and needs no decoder.

StorageValid plus FragmentBound are genuine inputs. set_storage preserves storage after the write; clearing expansionAncestry does not affect StorageValid. PendingRealized only constrains pending slots. The old/fresh list-set argument from Writes preserves it because the new enumerated value cannot be a pending value. This needs no Ready, Coherent, IsRoot, Safe or LiveRoots premise.

The exact core equality retains representatives, counter, obligations and recursionAncestry. It proves that expansionAncestry is empty. No full Frame is claimed across the write. Native heap, Caller and global memos do not change and need no executable parameters. Full native Mu/Union expansion, actual fragment production, initial/allocation cache history and physical index extraction stay separate.

The public waiting equality uses the actual canonical removal count. Its equivalence to replacement by an enumerated fragment follows from the existing replace definition and references. Recommend one named local Monad List for finish notation, zero LawfulMonad instances, no helper theorem, carrier or new predicate. Estimate 140–220 ordinary lines; Root selected hard cap 320 before bodies. A smaller state-only theorem could omit StorageValid/FragmentBound/PendingRealized, but it would lose useful caller facts for little proof saving. Prefer the combined contract above. The original prospective directory stays unchanged; this V2 retains the selected waiting expression and one typed reset-let header.
