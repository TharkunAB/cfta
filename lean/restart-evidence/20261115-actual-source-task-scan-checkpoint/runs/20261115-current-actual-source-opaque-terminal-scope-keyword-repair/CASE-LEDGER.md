The actual dispatch premise excludes the ordinary nonterminal branch. The proof performs no alternate larger-budget execution. The existing observed-result theorems internally compare stable observations, but their conclusions apply to the supplied actual receipt and endpoint.

IdentityEmittedCompleteResources requires resources for all emitted outputs and for complete endpoints. It does not require a native Post or Fits certificate for a stopped endpoint. This packet does not strengthen or narrow that original contract.
