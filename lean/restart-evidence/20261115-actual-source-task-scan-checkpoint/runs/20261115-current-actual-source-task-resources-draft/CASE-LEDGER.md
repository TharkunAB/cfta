# Whole task case ledger

| Actual task | Proof route |
| --- | --- |
| Empty tuple | Apply the complete tuple-nil resource component with the original worker induction hypothesis and genuine smaller-task induction hypothesis. |
| Nonempty tuple at count zero | Actual Current bounds the nonempty input length by zero. This gives a contradiction. |
| Nonempty tuple at successor count | Apply tuple-cons resources to the literal predecessor-count point. |
| Child with ordinary selector false | Apply the fallback component at the same task and endpoint. |
| Ordinary child at height zero | Actual Current bounds the incoming ordinary height by zero. Ordinary selection requires a node. A node has positive ordinary height. This gives a contradiction. |
| Ordinary child at successor height | Apply ordinary resources to the literal predecessor-height point. |
| Rows task | Actual Origin can only be ordinaryRows. It gives the exact successor-height point and actual ordinary selector. Non-node incoming values contradict that selector. The rows component handles the node case. |

Strong induction uses the existing task.work value. Every component receives only the induction hypothesis for strictly smaller work. No theorem premise supplies a component result.

CorrectAt retains every actual ledger, origin, current scope, root, original workFuel, recursiveDepth, forecast, restored cache, runtime result, and native endpoint. The statement imposes no new restriction on zero count, zero height, row shape, or row indexing.
