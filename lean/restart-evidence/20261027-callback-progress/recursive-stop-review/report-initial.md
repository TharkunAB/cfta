## Important quantifier limit

The exclusion of an immediate callback or selected-prefix fault is a local producer fact. A stopped recursive hook can return a nested reason through `.alternatives (.continuation … reason …)`. A global theorem eliminating all nested malformed callback/selected leaves would require a stronger depth induction, then preservation of its explanation through the sibling scan. It is not a projection of `OutcomeResources` alone.

Likewise, `ResourceHistory` is quantified only for each member of the emitted output list (`FiniteHistoryContract.lean:154–183`; `FiniteHistoryResources.lean:50–83`). It gives no history for a zero-output stopped branch. It cannot establish the requested stop classification by an induction over existing emitted-output histories alone.

`FalseCallbackReceipt` already retains the exact false recording singleton, original and returned Packet, RenderStable/Frame, exact actual `continueWith` result, and the same smaller-depth `resume` equation at its returned metadata/cache (`FiniteCallbackReceiptLanguage.lean:40–77`). A new generic false-callback wrapper would mostly repeat this receipt.

## Effect of an accepted chosen-edge model

`head_finite_complete_resources_accepting` retains the whole ordinary finite head packet and appends a semantic observer. Original native Satisfies plus meaning of this same selected edge constructs an assignment extension and proves the actual retained receipt is `.complete fragment middleCaller saved afterCache`, with the same term fill and native Satisfies at this own afterCache (`FiniteHeadCoverage.lean:100–123`). This excludes unsupported projection, arity rejection, and valid child raw[] **for this accepted head**. It does not exclude an earlier unsupported edge in the scan; that needs the explicit prefix-support policy.

The produced assignment can enter the actual callback because its Frame preserves full native assignment meaning at the same heap (`RecursiveCallbackLanguage.lean:33–68`). This is distinct from an oracle-rejection theorem. `recordTypes` obtains its Boolean from the template oracle; `oracle` has an actual early-rejection branch (`RecordTypes.lean:53–88`; `Oracle.lean:42–70`). The existing native Satisfies proposition does not relate the native heap language to the graph/template rejection policy. An accepted native term alone therefore supplies no proof that recordTypes returns false.

An accepted model also supplies no proof of sufficient recursive depth, no default/custom selector coverage law, and no proof that arbitrary type narrowing retains its term. Even a successful callback can restart into another nonordinary fallback or unsupported projection.

## Next useful proof, kept within the full goal

Root selected a small native scheduler progress observer. Preserve the entire old `callback_complete_semantics` header and output packet, call it once, and append an observer:

- From original `EnumerationProgress.ProperState before.core` and original native Satisfies, derive ProperState and the same native Satisfies at the actual returned framed callback cache.
- Use the actual returned Packet/CacheValid and the new native scheduler theorem to prove `Restart.decision stop order result.2 (frame after before) ≠ some .stuck`, uniformly in stop/order and the already chosen work bound.
- Keep the existing exact recording/continueWith laws. On the false branch they identify the actual recursive restart at that cache and decision. On the true branch the runtime still prunes; the observer does not claim that the restart executes.

This rules out one real complete-empty route of the concrete false callback. It adds no future successful execution, no desired final assignment, and no new assumption to the original producer. ProperState is an explicit conditional semantic antecedent. Its production/preservation through all actual native histories remains a separate obligation.

ProperState is stronger than Canonical: pending native slots require valid nonempty nonterminal tries, and pure equality slots require empty suspended lists (`EnumerationProgress.lean:16–32`). Packet does not currently imply this condition. The native candidate test must be used; graph-based progress cannot be transferred by asserting a fabricated Graph/native equality. Native Mu/Union boundaries must remain allowed in the native proof.

A later full stopped-result theorem can retain the complete old stable outcome/resources/history packet and append a derived explanation for each stopped outcome: exhaustion, exact successful unsupported ordinary entry, unsupported projection, or a completed-head/false-callback descent to one of those explanations. No such theorem has been proved here. It must retain each actual endpoint and full Memos, and it must not infer a full Memos equality from query equality.
