## Where capture remains possible

The generated arm is rooted in binder true (encode (leaves parent) [pairReference] parent), with initial inputs leaves parent. Those inputs can contain closed ordinary values or full Mu values. The exact original_slot theorem (39–47) maps a row-bearing capture back to its original input suffix index there, but it cannot rule it out. In particular, the leaf occurrence is not assumed to be encode.slot, and a selected closed leaf can contain several rows from different producers.

Thus the new exclusion closes the original-empty lexical capture branch, including nullary rows, without closing general generated-capture ancestry. Stored structural rows are also not complete residual Mu observations. Original binding uniqueness, source-size descent across historical winners, global renewal, termination and Haskell refinement remain separate.
