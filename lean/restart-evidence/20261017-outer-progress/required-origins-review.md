The module proves two different causal origin laws. It does not assert a
new global outer-recursion measure or completion result.

Every returned kept row has one original row with the SAME complete guard,
symbol, and child-list arity. The selected child graphs can replace their
values. Their annotations are not premises. Actual child heap effects
supply available returned values at the literal edge construction. The
physical makeEdge_fields theorem identifies the actual canonical winner,

losing candidate's fields to a different winner.

root. Identity retains every original row. The rebuilding branch uses the
row-origin theorem and actual canonical node readback. Filtering and
canonical row ordering can remove or reorder rows. Every retained row

finite Cap, or global annotation heap is required.
