# Independent review of the shared publication trace fixture

Review scope: the complete selected `publication-trace-kernels.lean` source, its public type, and its selected strict and full printer receipts. This review adds no Lean jobs and no proof pairs. It reuses one constructed group from the same warm source family.

Verdict: no material issue found. The proof derives a real earlier full cell at the selected outer event's pre-publication heap. Both publication indices refer to the same path returned by one `build_trace_writers` application.

## Actual construction and selected payload

The source first builds a raw nested binder with the nullary `tag17` row. It then builds a raw outer binder with the union of its local reference and the same nested syntax. The enclosing `box` source contains both requests in that order. The source build, first full Mu shape, first record, outer candidate record, and repeated nested cache hit are literal checked equations. The fixture has no supplied source build, writer, publication path, availability, or ordering premise.

The complete public theorem type matches the private checked theorem type byte for byte. It retains the actual source equations, exact full payloads, nullary row fields, all original-source event receipts, all final-cell writer receipts, and the universal precompletion ordering clause. It also retains one concrete strict earlier-index instance.

## One path and correlated occurrences

The private checked theorem invokes `SourceCurrentNativeOriginalPublicationTrace.build_trace_writers` once. It obtains `path`, `sites`, `finalWriters`, and `precompletion` together. `finalWriters` selects the final outer candidate on that path. The proof keeps its exact index, event lookup, rooted `Reached`, missing-before-write fact, prefix and three callback paths, and physical and issued suffixes.

The candidate equality identifies the selected event's stored body with the concrete first Mu. The proof does not identify the selected event, its heaps, or its syntax with the manually constructed `outerEvent`.

For this selected event, `publication_body_available` derives body availability from the event's actual historical Context, actual reserve operation, and actual normalized callback result. The `resident` field of that availability then gives the exact full inner cell at this same event's `afterBody`. The concrete first key equality aligns the lookup key. This derivation makes the precompletion instance nonvacuous.

`precompletion` receives this same outer lookup and full inner cell. It returns an earlier index strictly smaller than the outer index in the same `events path` list. The proof preserves the exact earlier payload, key, missing fact, original-source `Reached`, prefix and callback paths, and suffix to the selected outer `afterBody`. It does not select an independent trace or replace either recovered event with a manual event.

## Bounds of the result

The indices order actual publication occurrences in one completed source execution. They do not give a future native termination rank or a strict decrease in original syntax. The fixture does not prove unique writer syntax, unique source occurrence, or equality of recovered event heaps with manually computed event heaps. It does not execute stored substitution or a native prefix. Its full Mu payload equality does not identify the current requester callback with a prior stored winner's callback.

The nullary row is intentional. No child-existence premise is used. This is one selected constructed theorem in a previously used source family, not a new source family or a whole-library correspondence result.

Selected source, receipts, and dependencies are pinned by the adjacent source-pin and manifest files. The portable verifier accepts `--root` and `--fixture`, checks byte identity, independently checks the strict and full printer receipts, and does not invoke Lean.
