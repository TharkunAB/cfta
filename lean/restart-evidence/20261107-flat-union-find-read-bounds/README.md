# FlatUnionFindReadBounds

Every valid flat forest has the same representative reads at the fixed earlier fuel 2. One step fails on a stored parent. The actual compressing read retains effective entries and the same bound. Every count fold has the exact canonical result at 2 steps per reference.

This is a bound on modeled representative reads. It is not a bound on intersection, emptiness checking, all worker states, machine arithmetic, or total execution work.

The actual Lake target and every public source/axiom report passed with Lean 4.34.1 in the project Nix shell. `checked.json` records that observation. `theorems.json` lists all 9 public laws. `check.py` builds the actual target, compiles the source and axiom reports with warnings as errors, checks the allowed axioms, and checks that the source did not change. It prints compiler diagnostics on failure.

From the repository root, use the required serial capped runner:

```sh
env XDG_RUNTIME_DIR=/run/user/1000 DBUS_SESSION_BUS_ADDRESS=unix:path=/run/user/1000/bus /home/tritlo/Code/heavy-management/bin/capped --mem 4G --time 380 python3 lean/restart-evidence/20261107-flat-union-find-read-bounds/check.py
```

The temporary report is removed automatically. The script reuses the normal project build cache. No archived build tree or private source receipt is required. A separate cold rebuild was not tested.
