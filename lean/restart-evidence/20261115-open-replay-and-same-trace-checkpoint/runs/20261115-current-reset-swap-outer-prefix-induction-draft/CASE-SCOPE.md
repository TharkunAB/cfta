# Reset/swap induction with the real outer prefix

UNCOMPILED. No proof credit is claimed.

The theorem derives the actual child request from the actual reset/swap decision. Reset selects the reserved empty domain with the original operand order. Swap retains the original domain and reverses the operands. The raw compileNode body is exactly that child query.

The interface preserves the original OUTER .node request .pure control, parent state and parentFuel. Its given Steps1 ends at the real compileNode body bound to the actual continuation next at first. The theorem derives the identical outer prefix for the literal child query with that SAME continuation and SAME first state. It does not invent a step from the raw body to the child.

The child IH retains that exact prefix, the actual branch's request/domain/order, and a childFuel strictly smaller than parentFuel. It returns both existing Returned laws at that actual child endpoint and the same valueLaw at an actual child pure-result trace of that smaller budget. The theorem applies it at the UNCHANGED remaining body budget. It also applies it at each actual pure-prefix count bounded by that remaining budget. This derives both memo laws, all such actual pure-result laws, and the actual completed result law via the existing done_trace theorem. Zero remaining fuel remains included. parentFuel is not changed.

The useful induction interface is the conversion from the actual outer body prefix to the qualified lower query prefix. A theorem consuming arbitrary query laws at an unrelated warm state would not provide this conversion or genuine original-parent fuel bound. The implementation adds no cache framework, context/model, future running cell, hidden success, or changed operation budget. It asserts no claim about the appended continuation's later execution.

Existing NodeBranches.reset_law/swap_law transport contextual semantic laws. They were inspected. This theorem needs no such model. Existing NodeQueryReturned retains the precise outer prefix consumed here. NodeQueryResult is the conditional actual completed-query API used by lower query-result proofs. This producer uses the actual lower query IH's pure-result clause directly; it does not assume that a returned memo property alone proves every child result.

The caller must still discharge the genuine lower A/M child qualification and source/body result proof. In particular, the theorem does not prove that every hypothetical request belongs to A or M. It does not derive arbitrary warm-query correctness, an initialized source history invariant, semantic typing, domain inhabitance, or a compatible finite model.
