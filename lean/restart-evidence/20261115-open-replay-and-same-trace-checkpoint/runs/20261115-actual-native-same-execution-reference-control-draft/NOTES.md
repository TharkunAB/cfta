Status: UNCOMPILED CANDIDATE. No proof credit until Root checks it.

One public theorem consumes a full ACTUAL checked Trace from initial/start to
pure result/reader. Its two input prefix receipts are raw Steps from that
EXACT same initial control and complete start state. One prefix reaches the
literal original empty-domain U/P enter. The other reaches the literal
compileNode query WITH its real bound next continuation. Both original source
and the complete P remain explicit.

No suffix is a premise. No future Extension or availability is a premise.
The original whole trace and raw prefixes supply all actual controls and
complete states. The final reader is their ONE observed final endpoint.
The entry and producer counts have no relative order assumption.

  literal enter instruction. This supplies the genuine positive entry suffix

- The unchanged current_stored_universe_ref_control_at_common_reader then
  supplies all original full-U lookup, actual source binding read, strict

The public result retains BOTH checked prefixes and BOTH exact suffixes.
Their lengths are the original counts and wholeCount minus each original
count. It also returns both derived count bounds and all existing common-reader
control conclusions. All native memo, domain, machine, and constraint-cache
fields remain in the literal original states.

Source scope: accepted original source/build/stored full U; full P with original
closedness, identity and node-or-union tag; one original whole checked trace;
past source record growth; current operand availability and strict ORIGINAL P

This theorem does not prove that the original worker produces these prefix

completes or that earlier emissions are removed by a later stop.
