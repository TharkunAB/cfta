## Bounded result

The older MuActive.Aligned case has one varying first slot and one identical
list of complete captures. Under a nested binder the inputs instead become
[localA, outerA, captures...] and [localB, outerB, captures...]. The different
outer references now occupy captured slots. An application of that older IH
would require these captured tails to be literally equal. Actual publication
histories do not imply this equality. This is a mismatch in the induction
interface. It is not a proof that the binder's Aligned proposition is false.
No counterexample to general retained-Mu reconstruction or Haskell defect is
claimed by this component.

The new Slot predicate handles this missing lexical case. Bare references
have equal resolved replacement values under their respective maps. Every
other slot retains one identical opaque value, with map agreement on its
free names. That value can contain arbitrary nested raw or smart Mu records.
Paired records All₂ Slot over finite input lists in source order. It assumes
no future execution, returned observations, Alpha relation, or result law.

of_compatible embeds the existing MuActive.Compatible inputs into Paired.
reference proves exact repaired execution equality after the literal indexed
variable build. It takes an actual coherent current reader and availability
of the first input list. Fixed slots use the repaired execute_congr theorem
for all syntax. Reference slots use the actual optional lookup. Out-of-range
slots return Empty. No successful stored call is an input.

bind is an explicit shadowing update of an outer replacement map. The private
extension proof shows that two new local bindings to the same argument retain
old slot compatibility if their respective names are absent from the old
slots' free names. Aliases across the two sides are not excluded. The argument
can be any complete value. This is a lexical compatibility result, not a
claim that the argument is available at an arbitrary callback heap.

publication_extend discharges that freshness premise from two actual
Publication receipts. Each cut Context gives Available for every old capture,
including its issued-reference provenance. The actual missing-key reservation
has identity exactly cut.nodes.next. Cache validity places all old issued
free identities strictly below that next value. Thus the newly reserved own
name is absent from every old capture's free list. No caller freshness or
future writer law is assumed.

The theorem returns both derived freshness facts and Paired for the two
actual reserved-body input lists under the extended maps. It also extracts
both literal raw builds, their actual withoutSelfReference results, and growth
from each raw endpoint to its own afterBody heap. The source expressions of
the two publications remain explicit. The theorem does not assert that they
are the same expression, nor that their raw results correspond. A future
strict-source application must justify its own common expression or source
relation.

Publication receipts are past actual miss receipts. They do not encode an
arbitrary future callback. This module does not construct the publications
for every source call or prove their chronological selected-winner relation.
It does not compare the returned binder values. No Ready transport is inferred
from cache growth. The recorded growth also does not assert issued-ledger
extension into an arbitrary later reader.

## Remaining binder invariant

A full source induction must quantify finite paired lexical inputs, not just
one varying slot beside identical captures. This module supplies the repaired
reference base and the actual fresh reserved-body extension of such inputs.
The ordinary induction case still needs its corresponding Paired formulation.
The union case must use the proved literal and observational fusion laws;
general physical reconstruction/makeUnion commutation is false.

The Depth and ordinary probe entries need separate treatment. The repaired
ordinary name is fresh against live source support, not necessarily every
unused captured value. Depth is a probe sentinel and can occur in captures.
Therefore this whole-list fresh-reserved extension theorem must not be used
as a global freshness theorem for those probe arguments. The existing
NormalizationFreshness APIs provide support-scoped probe facts.

The smart retained/erased case and earlier warm winners still require a
coupled strict-source and chronological-writer induction. A selected warm
winner can have different earlier source syntax. Neither Paired nor exact
variable equality supplies the missing full row and ordered-child relation
for that winner. This module does not supply a full Aligned binder theorem,
retained-Mu congruence, or general outer completion.
