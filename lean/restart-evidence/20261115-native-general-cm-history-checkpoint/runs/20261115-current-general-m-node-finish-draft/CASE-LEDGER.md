# Case ledger

| Branch or operand shape | Actual proof route |
| --- | --- |
| Empty guard | The actual raw pure trace returns Empty. Empty has Profile. |
| Reset guard | Both source aliases have free list [interned uid]. Either request order therefore rejects reset. |
| Self guard | Actual physical readback identifies both operands. The pure result inherits the closed operand Profile. |
| Swap guard | The exact reversed query occurs at the actual original prefix. Same-prefix keyed-cell retention applies past M at beforeFinish. |
| Remaining Empty operand | The failed Empty guard gives a contradiction. |
| Remaining reference operand | Its nonempty free list contradicts operand Profile. |
| Union operand | The public general M union finish theorem applies with the same full pattern, entry, heights, and past laws. |
| Body alias with node operand | Both resident nodes have identities different from the full source Mu. Every seen pair contains that Mu identity. The actual pair is fresh in either order. The remaining selector is ordinary. The public M ordinary finish theorem applies. |
| Reference alias with node operand | The public M reference/node finish theorem applies in either request order. |
| Mu operand | Source readback identifies the entire operand with full original U. Its given operand Profile supplies Profile(U). |
| B/U | The public broad body-first outer producer uses the exact past body-first node law and returns full U. |
| U/B | The source tags force swap. The failed swap guard gives a contradiction. |
| R/U | The source tags force swap. The failed swap guard gives a contradiction. |
| U/R | The public broad diagonal outer producer uses the exact past coherent node and TopRow edge laws and returns full U. |
| Repeated pair | The body/node case excludes it physically. Union, reference/node, and both broad outer producers prove their own actual freshness. |
| Unsupported payload | The closed operand constructor cases exclude it. |

The entry prefix and the producer prefix belong to the same full checked trace. The proof does not order them relative to each other. The body/node freshness argument uses no original pattern availability at the earlier producer.

The explicit pattern, pattern identity, actual entry, alias choice, operand Profile, original height bound, strict reference height, and both operand orders construct the exact existing MixedQualified predicate at the start of the proof. The original full pattern receives no Profile or only-U premise.
