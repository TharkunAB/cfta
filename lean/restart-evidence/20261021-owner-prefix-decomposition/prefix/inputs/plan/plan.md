# Ordinary-owner prefix decomposition

The smallest useful missing producer is one public `SourceCurrentOuterOwnerPrefix.first_child`. It inverts an actual ordinary-owner body-to-node `OuterExecutionAncestry.Reached` prefix. It derives the source row's membership and the exact immediate returned-row child dispatch. It then retains either that same reached node or the actual subsequent captured activation and its unfinished body prefix.

This is graph bookkeeping. It needs no Context, Good, Frame, Room, semantic heap, source ancestry, active-cell law, or future completion. It claims no key exclusion, renewal, semantic descent, or global termination.

## Existing endpoints and gap

`Ancestor` already retains the actual enclosing activation, key link, valid running table, active cell, and unfinished body prefix (ExecutionAncestry 461–468). `Reached.owners` constructs that certificate from an actual reached active cell and an idle entry table (477–496). A new wrapper that merely unpacks Ancestor would add no result.

Literal `Step` has exactly the needed control branches and actual earlier return equations (326–365), but public Reached APIs expose only transitivity, table preservation, owners, and failure propagation. The narrow search found no public first-step or ordinary-body decomposition inverse.

`OuterUntouchedProgress.walk_prefix` (46–79) constructs a dispatch from caller-supplied completed earlier slots. It does not recover those slots from a body prefix. `OuterPositionalDispatch.walk_indexed` (40–92) does recover exact indexed calls, but it assumes a completed WHOLE walk and returns a completed child and suffix. An unfinished owner prefix cannot supply that hypothesis.

Do not replace the literal ExecutionAncestry graph with ActiveAncestry. Its rows_tail and walk_tail constructors require additional completed graph/receipt facts (ActiveAncestry 41–86). The older CopiedWarmHit graph uses a convenient head-first Reached constructor, but lacks the literal rows_tail case needed here (CopiedWarmHit 61–103).

## Proposed output

The sole input is an actual Reached prefix from an explicit ordinary owner's body to the actual candidate node phase. The output contains a split `ownerRows = skippedRows ++ original :: rest`, a derived body-to-row cut, the exact completed Parent edge call, the exact live inherited-prefix equation, the exact completed walk over `parented.children.take slot`, the selected full child lookup, and the later-entry alternative. The split derives SAME-owner row membership; it is not a new caller premise.

The immediate node is the first explicit walk_head entry on the retained unfinished chain. It is not the earliest node call in execution order. The skipped earlier row/slot calls can contain completed node calls. Their exact literal returns remain in rows_tail and the completed take-slot walk.

The later-entry alternative is either equality with that immediate node phase, or the actual `beginNode` evaluate equation and an unfinished prefix from its CAPTURED owner's body to the candidate. Do not assert captured=request, or captured.key=request.key, from graph syntax alone. Those statements require the genuine physical table/context laws. No new semantic obligation is inserted in this graph theorem.

## Proof route

Use a private first-step inversion of the snoc Reached relation (about 10 lines). Then use four private phase cases for rows, descendants, children, and walk. Rows can only select its head edge or skip one actual completed Parent/descendants pair. Retain its skipped source-row prefix and its exact reached cut. Descendants supplies its actual prefix equation. Children supplies live combined state. Walk can only enter its head or skip one actual completed node call; reconstruct the completed take-slot walk by prepending that SAME call, as in the existing indexed-walk proof. Keep the same index and full caller throughout.

Stop the phase decomposition at the first walk_head. Invert its remaining Reached prefix once: reflexive means the candidate is that node; otherwise the only outgoing node Step is node_evaluate. Return its actual captured request and remaining body prefix. No recursion through later semantic owner bodies is part of this endpoint.

Apply the result to Ancestor by unpacking its existing body prefix. Compose the returned row cut with the existing activation prefix. Existing Reached.running transports the SAME active cell to that row cut using Ancestor's existing NodeValid. The row split supplies the owner membership required by ResourceOwnerDispatch. This is a caller composition, not a second public wrapper in the proposed module. A later phase can repeat the decomposition on the returned actual captured activation, but no blanket resource or ownership claim is proved here.

Estimated implementation: 200–300 lines, one public head, private structural inversions only. No new public predicate, activation chain framework, worker completion proof, or copied ledger. If exact whole-prefix row aggregate equations become necessary, review that addition separately; the current reached row cut already retains the actual earlier row returns.

This component owns zero Lean, Lake, canonical, runtime, or proof commands and no official source edit. The proposed type is unelaborated. No implementation is authorized by this plan alone.
