# Private proof route
1. Fix the final heap for the semantic cell interpretation. Use Valid.map and growth.heap to transport old operand/result residency there before examining memo effects; keep old EdgeLaw unchanged. [S03,S06-S07,S11]
2. Prove a private ret inversion: actual done from ret value pending identifies that same result, same checked state, and exact pending.foldl finish memo. Derive it locally from execute/step; no private imports. [S01:132-151]
3. Prove a private native inversion: while native yields, pair memo and pending are unchanged. Native done enters ret; failed/constraintError/blocked cannot satisfy this completed run. Recover only the exact ret memo image. [S01:63-106,153-177]
4. Invert lookup/demand/order literally. A ready original hit leaves the memo unchanged. A miss creates handle n with the literal original request; a strict swap can create at most one additional handle n+1 with the literal reverse request. [S01,S03-S05]
5. Temporary invariant: every nonreturned cell is one of these fresh handles. Old cells are unchanged and returned. At order, the current handle evaluates and pending contains only older fresh evaluating handles. Native pending is [n] or [n+1,n]; a reverse-ready hit returns to [n]. [S01,S03-S04]
6. During ret, popped handles hold this returned result and the residual pending handles still evaluate. Fresh bounds make handles distinct and outside the old cell domain. No general public Control invariant is needed. [S03-S05]
7. Recover an exact old/one-fresh/two-fresh final cell image, not just Returned. This is the missing coverage fact needed to prove all allocated cells returned and to check each fresh cell law. [S01,S03-S05]
8. Reuse lookup_valid, demand_valid, finish_valid and lookup_extends for structural links. Demand/finish leave the table unchanged. Use finish_evaluating and finish_returned for exact completed cells. [S03-S05]
9. For old final cells use the transported interpretation. For fresh cells use actual resultResident/resultLaw and current operand growth; the strict reverse branch canonicalizes to the same actual canonical request. [S01,S06-S07]
10. Re-establish canonical presence only at done: ready preserves the old table; reverse-ready already has the canonical key; native paths publish it before ret. Old canonical keys persist by table extension. [S01,S03,S10]
11. Assemble Stable after, table Extends and old Returned. The fixed SAME after is the one from the observed execution; no replacement native state or memo is constructed in the theorem conclusion.
The private helper set is limited to final-heap cell transport, ret/native inversion, literal call effect/allocation classification, and final field assembly. Local abbreviations may name repeated memo expressions; none may occur as a new private identifier in the public TYPE.
A generic all-controls pending-stack framework, ready-hit completion API, native semantic proof, H8 packet copy, and execution provenance predicate are outside this slice.
