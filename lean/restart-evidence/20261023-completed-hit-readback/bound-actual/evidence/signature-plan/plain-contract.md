# Completed-hit readback

Fix the existing semantic view, model, ranks and holds of the initial Stable memo. Keep the actual fuel, complete initial Wrapper, result and complete final Wrapper of one supplied H7 call completion. If the original pair key or reversed pair key is published initially, derive equality of the final and initial checked states. The pair memo may change. No new execution witness or cross-fuel uniqueness result is used.

The original published key is a ready hit because Stable links it to an allocated cell and marks every allocated cell returned. For a reverse-only hit, canonical presence forces the original request to enter the descending swap branch. Otherwise the original key is present; equal IDs give the same contradiction. Public returned-cell retention preserves the old reversed cell through fresh publication and demand. Thus every reached step is pair control or pair completion, without native execution.

The proposal does not require Good, coherence, requested-payload residency, captured/requested payload equality or a result language law. Existing Stable remains the complete initial premise. The same supplied done equation is a completed-past observation, not a future success oracle. Suspended/running unrelated cells are excluded by this stable-boundary premise; the theorem does not claim arbitrary non-stable hits complete.
