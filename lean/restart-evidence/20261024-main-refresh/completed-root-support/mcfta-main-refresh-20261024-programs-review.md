## Laws and resource limits

`Types.hs:1165–1181,1327–1342` gives 1,000 random cases plus 64 fixed-schedule cases by default: eight validation, 32 integer-boundary/list, 16 predicate and eight half-range cases. Each comparison has a 1 GiB allocation budget. Ordinary exceptions and that budget yield no comparison result; `IllTyped` and asynchronous cancellation propagate.

`Specftacular.hs:1482–1514` applies optional small-case rechecks before accepting a newly tested law, then calls the existing law generalization path. `--recheck` defaults to zero. The upstream comparison at lines 213–221 records the false law `drop (length (concat xs)) xs == reverse (drop (length (concat xs)) xs)`, which passes the default 1,064 cases in a HugeLists run and is rejected with `--recheck 2000`. For example, `xs = [[], [1], []] :: [[Int]]` refutes it. A false accepted law can prune subsequent true candidates. Additional testing remains evidence, not a soundness theorem.

`Specftacular.hs:1542–1610` defaults completion to 4 GiB of live-heap growth and 256 GiB of allocation. It keeps the law's direct rules when completion exceeds a budget. This reduces pruning strength; it does not itself certify the law. Live-heap growth is sampled process-wide after GC and can include other workers. Without RTS statistics, memory limits have no effect. The comparison budget remains active. Bucket limits stop schema testing and retain already discovered laws; enumeration and the initial sort happen outside that testing action (`1113–1171`). They are not whole-bucket wall-time or whole-process memory bounds.

ADR 6 records useful performance evidence and several rejected alternatives. The new phase-4 route is implemented, not deferred. Fresh carrier renaming for each generated variable, discarding template-dependent annotation checks, replacing compiled templates with a full oracle, extra type lookahead, and a Feat-style test prepass are rejected alternatives. The cause of larger residency in the long enumeration-ahead run remains unresolved. The 14 GiB and multi-hour upstream runs are not suitable refresh smoke tests under Root's serial 4 GiB/5-minute policy.

## Concrete findings and validation gaps

1. **Negative type depth needs rejection.** `Specftacular.hs:522–527` accepts any Int with `O.auto`; the public record also accepts `Just (-1)`. `Utils.mtauWithin:165–171` stops only at zero and otherwise recurses to `d - 1`. A negative bound therefore creates an unbounded descending structure instead of a bounded grammar. This is a source-derived defect; I did not run a failure probe. Reject negative depths at the shared search entry and reject them in the CLI. Do not silently turn an invalid negative bound into an unbounded search.
2. **The README undercounts the fixed schedule.** `specftacular/README.md:32–34` states eight validation plus 32 directed cases. The current source has eight plus 56 directed cases, for 64 extra cases. ADR/comparison references to 1,064 tests agree with the source.
3. **The golden suite does not test the new phase-4 path.** `test/Golden.hs:32–115,143–157` now has six checked/unchecked cases, including KBO and LPO lists. Every case calls `defaultOptions size 1`. New golden laws exercise better polymorphic generalization and higher-order arguments, but a green golden suite does not validate partial typing, type-alternative merging, phase-4 stopping, background work or parallel merging.
4. **Additional resource robustness deserves a focused check.** `concurrently`, `forceInParallel` and `enumerateInBackground` fork workers without a bracket that cancels them when the caller exits exceptionally (`1249–1316`). A library caller that times out a search can leave work running. Also, `boundedCompletion` disables its allocation limit only after its typed `try` returns (`1574–1583`); an unrelated asynchronous exception can skip that cleanup. These are static lifetime/cleanup concerns, not observed test failures. The existing `valuesEqual` path does catch and clean up before it rethrows asynchronous exceptions. They do not justify claiming a default law error, but they matter for cancellable library use.
