# Outer busy-owner scope

The proof covers all bounded actual node calls, node bodies, edge calls,
edge bodies, rows, descendants, children, and indexed walks.
It follows every failed branch of the literal worker. A failed bind returns
its reached caller without executing a finish continuation.

A reported outer busy handle contains an evaluating captured request at
that exact returned caller. The request is existential. It need not equal
the query when the supplied tables are malformed. The immediate demand
laws also identify the query-key table entry and the unchanged full caller.
No valid-table, semantic, Cap, closure, idle-table, or rank premise is added.
This result does not exclude busy or absent observations.

The key-identity component supplies complete request equality only under
valid interner, coherent records, Ready inherited values, and available
nodes or resident edges. Its evaluation adapters also use Sound.
Busy retention alone proves no request equality, ancestry, or progress.
A future node-busy exclusion proof must identify the actual nested query
and relate its key to a captured active owner.

The constructed probes deliberately start actual node and edge owners.
A repeated demand reports busy. An indexed walk propagates that fault and
retains its exact caller. The walk probe calls walk directly with a
contradiction value; the children dispatcher would erase those children.
The probe is a diagnostic check. It is not an admitted outer cycle.
