# Required prefix shape and the actual eager input boundary

Status: bounded read-only audit. No new theorem, probe or source defect is claimed.
No compiler, live edit, Haskell edit, Git action or board write ran here.

1. The checked shape law belongs to one exact intermediate forest.
   SourceCurrentSharedRequiredPathShape.receipt_shape:55-69 observes one actual
   shared Scan-to-Required Receipt. It derives ChildrenShape for that receipt's
   results, compiled from the paths of its kept records. execution_shape:44-52
   derives Required-entry heap readiness from the same Scan, then calls the actual
   requireAll_shape. It claims no shape after the subsequent class pass.
   SourceCurrentSharedScanRequiredNumeric.Execution:48-52 identifies the exact
   results and advanceHeap endpoint. Receipt:77-105 retains the same execution,
   reads, resources, selected Sublist and language bounds. This is useful checked
   preparation evidence. It is not evidence about an arbitrary later input.

2. The raw eager row does not perform that preparation.
   CachedOwn.prepare:32-42 projects its guard, allocates own classes, and descends
   inherited and own tries directly to edge.children. EdgeInputs.children:15-18
   preserves the literal ordered buckets. SharedChildVisitors.visitSelected:53-62
   invokes the child policy on those exact values and buckets. No requireAll is
   inserted there. SharedEagerChildren.eagerChild:139-148 recurses on ordinary
   nonterminal inputs; other inputs use the existing shallow dispatch.
   Consequently a raw source row for choose:forall a.a applied to x:Int can
   supply app descendant paths at choose's U annotation. The earlier frozen
   source-layout observation is conditional; no complete run or defect follows.
   An arrow(Int,Bool) completion is possible in that local example.

3. Even an enabled shared check does not store its Required forest.
   SharedIncomingNode.run:67-70 first executes the PURE native intersection.
   Its checkEmpty=false branch at74-76 skips shared Conjunction completely.
   SharedEnabledEmpty.check:35-38 also skips when the descendant memo is false.
   If a check runs, the retained replacement at IncomingNode:81-85 is
   if answer then Empty else query. Here query is the original intersection
   result. It is not a value selected from Required.results in the private call.
   SharedIncomingQuery.complete:73-95 states these exact facts and distinguishes
   skipped from performed observations. The performed observation retains an
   actual private snapshot and CallReads. It does not replace the stored query
   by that snapshot's transformed constructor forest.
   Thus there is no current identity bridge from receipt_shape.results to the
   next eager child input. Heap growth alone cannot provide that identity.

4. Existing later path receipts are weaker than physical prefix shape.
   SourceEqualityRequiredPathShape.PrefixShape:20-28 forces Empty or ordinary
   nodes at nonempty Needed maps. PrefixShape.ordinary:42-47 exposes that fact.
   In contrast, ProjectionPathDomain.NodeClosed/ForestClosed:22-39 preserve
   selected closedness. A closed Mu is allowed at a proper path, and an absent
   ordinary child makes its conditional clause vacuous. ForestClosed does not
   prove that a term exists, that the demanded path exists, or that a head is
   ordinary. HereditaryTypePaths.TypePath.annotated:23-25 allows any continuation
   after reaching an Annotated value. It is a role classification, not existence.
   ClassEditComplete.class_complete:230-234 and ClassFoldLanguage.pass_complete:
   103-112 preserve ForestClosed and conditional language bounds. They do not
   preserve PrefixShape. No PrefixShape/RowsShape/ChildrenShape declaration use
   occurs in the checked CurrentClass*/EqualityClass* source files searched.
   TypeSharedRequiredPass.application/filter additionally take actual completed
   Required and class-pass observations; their returned routes do not repair
   this mismatch between the private results and the original stored query.

6. Smallest sound next boundary.
   Do not publish a wrapper of receipt_shape as a global eager shape theorem.
   For a DEFAULT preprocessing proof, first derive the actual reduce/refold
   output's path-normalization invariant, then preserve that invariant through
   the SAME native query, class edit, heap read and slot replacement. Keep actual
   source bucket-to-record correspondence. The present receipts do not establish it.
   For RAW execution, physical prefix exposure is not required to have occurred.
   Instead retain the actual fresh-opaque and recurrence-park predecessor buckets
   beside the existing same-tuple finite clauses. Derive finite interpolation and
   one shared assignment from source origins plus actual alias/constructor facts.
   Do not supply a future unifier, whole-cache model or productivity premise.
   The source-cone no-new-pair-binder seam remains a relevant base case, but it
   does not solve hidden paths, actual partial completion or parked reassignment.
   A proof-level auxiliary require/unification computation can be used only if
   its success and compatibility are constructed from the actual source run;
   it cannot be treated as a recorded runtime operation that did not execute.

The useful result of this audit is a concrete missing causal receipt, not a new
proof claim: Required.results are private intermediate values, while the eager
slot stores the original query. Both raw and skipped branches remain in scope.
