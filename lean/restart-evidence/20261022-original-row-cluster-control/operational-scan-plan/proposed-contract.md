# Proposed bounded proof contract

This is a contract sketch. The named scan control and its execute function do not yet exist.
Working public theorem: SourceCurrentOriginalRowClusterScan.cluster_complete.

Retain the H15 genuine packet with these exact specializations:

- One bits, source, Facts, executable formulas/solver, public guard equality, InputMeaning and RankedInput.
- One parent with OriginalInput source (inputOf parent), Available source parent and parent.free=[].
- One symbol and rows = (nodeEdges parent).filter(fun edge => decide(edge.entry.key.symbol=symbol)).
- The SAME arbitrary initialDomains with Cache.Valid, source-computed inventory I, and before : H7.State(bits+2).
- At before: Good, Contextual, SemanticReady, Stable, native Idle, source Grows and node-issued history, and Trace I initialDomains before.domains.
- The single initial Room bits profile ⟨source.nodes.next,source.edges.next,initialDomains.next+I.length,0⟩.

Derive an existential fuel, kept list and actual after with all of the following:

- Scan.execute fuel (cluster rows []) before = done kept after.
- Every kept full edge record belongs to rows; kept.length≤rows.length. Do not claim kept.Sublist rows.
- Good, Contextual, SemanticReady, Stable and native Idle at the SAME after.
- Native Extension before.machine after.machine, pair-table Extends and Returned before.memo after.memo.
- Trace I initialDomains after.domains for the SAME fixed source and initial cache.

No successful scan, abstract exact-meet function, future comparison callback, generated-parent provenance, future Room or desired final state is a premise.
Each actual comparison is derived from H15 with two rows of the same original parent. The explicit final Trace and initial reserve derive the next-call Room.
The completion theorem does not assert physical language preservation. Its exact operational control is what later pruning proofs must relate to the conditional canonical EdgeLaw.

The smallest local operational proof needed first is comparison lifting:
From an actual H7.execute fuel inner before = done common after, derive some 0<used≤fuel such that scan.execute used (comparison frame inner) before = yielded(resume frame common) after.
Here resume is precisely the ordered three-way branch in proposed-control.md. It is notation for that control expression, not a supplied callback or new semantic oracle.
That local completed-call witness is produced by H15 inside the proof; it is not an additional premise of cluster_complete.
A short induction on the observed H7 fuel proves this lift. It avoids a new independent RuleOutRun/ClusterRun framework and prevents unused native fuel from crossing the resumed boundary.
