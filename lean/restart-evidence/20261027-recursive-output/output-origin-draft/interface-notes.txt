Parked proof:
The actual prefix's parked raw is exactly candidate.map Restart.run using
its checked core. IndexAdapters.parked_core says the attached candidate has
that same core. The successful restart row supplies unchanged metadata,
the actual next decision, and the same checked core. Framing that returned
core into the candidate is therefore the candidate itself. This derives the
induction input at the actual reached cache. Counter equality alone is not
used as a substitute for this exact identity.

Induction:
None emits the singleton with Some metadata at the supplied endpoint.
Done emits the singleton with None metadata; decision_done_iff proves empty
candidates. Stuck and zero-depth expansion emit no output. At positive
depth, the parked singleton passes its derived actual decision to the IH.
Empty and callback pruning emit none. Accepted ordinary execution uses the
generic callback and sibling laws, then finish_outputs. Unsupported/raw
failures emit none at that node; earlier outputs in a stopped fold remain
included and are classified by the same induction.
