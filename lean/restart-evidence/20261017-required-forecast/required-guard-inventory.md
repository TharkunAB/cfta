# Required initial resource inventory

The reviewed worker supports selected closed endpoints under an open parent.
It does not require whole-forest closedness. All-root finite guard Caps remain
an explicit and separate premise of the selected cap producer.

SourceEqualityNeeded.build uses the original right fold. The selected path
union uses canonical ascending paths and signed natural indices.
SourceCurrentRequiredSupport.NodeSupport requires certificates only for
nonempty maximal trie paths. ForestSupport uses the original selected index.
An unselected sibling may be an unresolved reference. RequiredTipSupport
also retains the terminal certificates that prove selected endpoint closure.
The exact false primary certificates derive this domain at one source heap.

SourceEqualityRequiredWorker checks worker exhaustion first, then the empty
child map. An empty map returns the input before reference inspection. A
nonempty map at a bare reference reports unresolved. A recursive Mu or union
runs Head and then the same requirement on its ordinary or empty result.
An ordinary node scans its original rows. Each row tests fits before child
work. A kept row scans original child positions, constructs its edge, and
then scans the original suffix. Unselected children are copied. Child arity
is unchanged. Rejected rows do not run their child work or edge constructor.
The final node constructor receives the retained rows at their returned heap.

WorkerNumeric.workFuel needed = 2 * sizeOf needed + 1. Each selected child
has a strictly smaller initial Needed trie. A recursive Head needs one worker
step, and its ordinary result needs the next. Ordered list scans share worker
fuel; list length does not multiply this recursion-depth bound. The derived
sizeOf is noncomputable in this build. This is a logical Lean worker bound.

WorkerNumeric.node/children/requireAll verify supplied actual successful
execution. SelectedRequiredWorker.complete/caller instead construct their
own return from initial selected certificates and Frame/Context. They retain
the same full receipt, memo reads, caps, Frame and caller Post. Every worker
above the initial trie bound and every reader above an existential returned
reader bound execute to exactly that value and heap. No future graph, worker
success, or desired output cap is an input to the initial wrappers.

OpenRowReadResources now closes the supported warm Head numeric prerequisite.
Its WarmHead includes open ordinary inputs, closed suffixes and actual
same-heap Mu unfolding. The seen cutoff bounds fresh prefix identities by
the initial issued node inventory. A closed suffix uses the controlled
collector. complete/read/head retain the exact actual full heap, Fits,
residency and a shared computed read certificate. This does not admit every
arbitrary open recursive value: the initial WarmHead support is required.

RequiredForecast.headProfile uses that open reader envelope. Its stage
includes Head and a constructor. Its successor fixes the original row and
child width at scalar(stageProfile entry), scans children for each row, and
pays edge and final node stages. MassHeap.available/resident bound each
original payload from causal Stored; constructor growth handles actual hits
and earlier winners. Original list widths must be captured before recursion.

That complete initial numeric Required composition remains the next target.
