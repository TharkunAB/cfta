The occurrence retains the original start and end controls and full checked states. It contains an actual prefix Trace to `code (optionalBinder pair body next)`, the semantic heap and Available body at that entry, the exact successful maybeMu call, the exact native advance with unchanged equality-operation state, the actual yielded instruction, and an actual suffix Trace to the requested end. Its fuel equation counts that exact prefix, instruction and suffix.

The target key is literally absent at that operation entry. The same complete target payload is present at the operation return. The occurrence also retains physical and issued growth along the actual prefix and suffix. The key remains separate from the selected entry key.

No Good, Fields, Ready, caller history, global idleness, future completion, compiler owner or generated writer premise is used. Primitive Work effects add no Mu under their actual current physical admission. Memo controls and checked edge bodies preserve the physical heap. Optional binders derive both physical and issued growth from actual verified construction with available bodies. Initial SemanticHeap propagates through the admitted trace.

The proof first classifies the selected cell through the actual remaining trace. If already present at the current return, the exact current instruction either preserves that full cell or is an optional-binder call. A later site prepends the exact earlier admitted step; it does not replace that prefix with bare heap growth.

This result covers yielded Trace instructions. A final blocked instruction is not included in the Trace. It does not factor arbitrary publication histories or infer native memo history from physical growth.
