# Same-forest handoff after Required

The false primary receipt from Scan names the original input forest.
`LocalWorker.classes` runs Required before the class pass.
`ClassSelectedChildLineage.fold_selected` instead names the actual forest at the selected fold phase.
Length equality and closed selected paths do not identify these forests.

Existing caller producers already cover the leaf-native boundary:

- `ActualClassSemanticReads.class_selected` derives semantic `Selection` from a literal successful class call and initial numeric/context invariants.
- `ClassSelectedChildLineage.Selection.native` retains the exact selected original slot, target slot receipt, native request, returned cell writer, and native lineage.
- `ActualSharedLeafEvents.leaf` supplies the literal force and native execution at their exact shared states.
- `ActualTargetSlotHistory.force_writer` recovers an earlier literal Target writer from actual slot history. The history constructor that retains targets does not itself supply historical physical or semantic Good.

These are not missing wrappers.

## Checked false route

`RequiredPrimaryRetentionBoundary.required_changes_primary` proves that Required can change a false primary class to true for an active coherent normalized two-path record.
The initial heap has semantic readiness, costs, union normality, a causal plain annotation heap, and available original input.
Both selected returned endpoints remain closed.
Therefore a caller must not feed the original false primary receipt to a theorem about the prepared forest, or request an unconditional new false receipt there.

## Existing direct Required origins

`RequiredPrimaryOrigins.complete` already produces `All₂ RequiredRowOrigins.Origin original prepared` and exact conditional language, from the original false primary receipt.
`RequiredRowOrigins.Origin` has identity, plain region, and ordinary row-map cases.
`RowMap.indexed` retains a source row index, full `RowOrigin` fields, and ordered `All₂ Origin` child pairs.
`Origin.nonplain` and `Origin.physical_positive` already recover structural original row occurrences through changed Required children.
Their `RowAt` addresses retain ordinary row/child indices, union member indices, and semantic Mu body steps.
A new theorem that only restates this occurrence extraction would duplicate existing results.

`ActualRequiredRowOrigins.prepare` and `PositionalOriginDescent.continuation` use an unselected child footprint to retain literal child identity.
They do not cover a selected child that Required rewrites.

## Smallest useful remaining caller producer

The missing composition is an actual target operand after Required, with the original false gate kept on the original forest.
A useful future theorem should take:

1. The original false path/class trace and its original semantic, normal, and available input facts.
2. A literal Required return `originals -> prepared`, with its derived ordered `Origin` relation.
3. The actual later target operand call on `prepared`, with physical readiness, stored/raw Merge history, causal guards, and growth at its real entry.
4. A selected positive returned row.

It should return the same original forest index, an indexed ordinary source route, full source/output row fields, ordered `Origin` pairs from original source-row children to projected-row children, and the existing actual Merge writer/ordered recursive Run from projected children to returned children.
It must derive the prepared projection analysis from the original false gate plus the ordered Required origins.
It must not assume a false primary receipt on `prepared`.

`PositiveProjectionSourceRoute.positive` currently needs a false gate on its own operand and returns the identical complete row at the source route.
`ActualTargetOperandSourceOrigins.operand` consequently requires its false gate and literal operand call to name the same forest.
Neither theorem can be applied directly across this Required forest change.
The new composition must allow changed ordered children rather than claim complete row identity.
Original children can have a structural mass bound; the rebuilt projected/native children need not have that bound.
Earlier class edits remain a separate handoff after the first Required phase.
No new producer beyond the checked boundary was implemented in this component.
