# Paired ordinary source induction

The final production source is SourceCurrentStoredPairedOrdinaryLineage.lean.
Its SHA256 is 29bde64babb2e779ac5713fe768101a37c18acbaf343d332901bdef6f041a91f.
The source keeps the earlier private proof structure in a new module. Older
frozen source files remain unchanged. Private helpers cannot be imported.

Aligned accepts arbitrary finite Paired input lists. Bare reference names
can differ at any index. Each non-reference capture must be the same full
value, with replacement-map agreement on its free names. This is not a
relation between arbitrary different recursive captures.

symbolic_inputs derives one fixed-value and paired-name list. Projection
by each name component gives the exact respective input list. No freshness,
name injectivity, common tail, or map-agreement premise is added to that
presentation. source_empty and shape instantiation derive physical Empty
agreement for the actual raw source calls. This step does not assume the
parent or child reconstruction result relation.

The ordinary case calls Aligned only for actual strict source children.
It retains complete symbols, guards, and ordered children through both raw
and reconstructed row survival. The result is physical Empty equivalence
and all-depth fixed-view observations. Normalization can reorder or remove
rows. No unchanged source index or row bijection is claimed.

node_complete takes completed past raw builds and Context at their entries,
then growth into a common Ready heap. Available inputs and replacement maps
construct both sequential stored calls, their actual heaps, Keeps, available
results, common-reader replays, and local publication histories. It applies
the ordinary induction case after constructing those calls. It does not
assume a future stored call, expected parent output, or semantic completion.
The strict-child comparison hypothesis remains explicit. The binder and
union source cases and older warm-writer alignment remain open.

The fixture constructs a productive closed Mu, two differing reference
slots with unequal captured tails, nested ordinary rows, duplicate rows,
and a row discarded because one child is Empty. Both raw calls are actual
sequential source executions. It invokes node_complete and derives both
stored calls and local histories with a nonempty ordinary result. The Mu
is an identical opaque capture. The fixture does not execute a varying
nested binder or compare different Mu bodies.
