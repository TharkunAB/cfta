# General outer adequacy: bounded numeric survey

This is a source-only design report. It proves no new envelope, adequate fuel, completion, or state widening.
Exactly ten core files were inspected. No implementation or proof/runtime job was run.

## Existing initial-data bounds

ParentUniformEnvelope.profile/fuel are finite joins over initial own records, original counts, and ambient guard words; resident_bounds identifies an actual resident Parent forecast inside that join [S1:29–101].
Its complete theorem constructs the actual Parent return from the genuine Context/Frame/Fits/known/resident/Ready packet and UniformReserved, with output Fits and all nine replay-fuel bounds. It takes no successful-run premise [S1:139–172].
The SAME numeric receipt retains a resident returned edge. Fits.stored therefore bounds its mass, child masses, and child-list length by the predicted output profile.mass. This is a direct use of existing facts, not a missing Parent wrapper [S2:54–87,145–167,S3:32–59].
Schedule.parent carries BOTH the generated guard alphabet and Parent profile. Schedule.rebuild reserves the raw constructor. Their ge theorems retain entry bounds [S7:17–37].
ActualChildRank.dispatch proves strict Lex(count inherited payload owner, mass owner) descent at each actual live immediate dispatch, with its genuine initial resource packet and chosen-fuel Room [S4:108–153,155–208,219–247].
The count is a finite quotient count of deduplicated PositiveAt paths. A strict count drop permits child mass growth; mass or ordinary height alone is not the general recursion measure [S5:20–72,123–143,S4:238–247].

## Smallest genuine missing numeric producer

The concrete candidate is C(budget,n,m,seed), with seed=(guardAlphabet,Profile), returning work and an output seed, plus an accumulated lower-fuel maximum if domination is not proved. Recurse on Lex(n,m); seed is an additional argument, not part of the decreasing measure.
At the initial node request, n=count(request.inherited.payload.getD [],request.value) and m=mass(request.value); both are initial data.
At a child slot, enumerate all (n',m') with n'≤n, m'≤CURRENTseed.profile.mass, and (n',m') Lex-smaller than (n,m). This is finite even when count decreases and mass grows.
Join the recursive output profiles with the existing finite cover, join output alphabets by finite list union, and take the maximum recursive work. Retain the entry seed in that join.
Iterate that slot transformer through a fixed child-list bound obtained immediately after Parent, carrying the joined seed through earlier siblings. Iterate row work at most owner mass times, then apply the existing raw constructor forecast.
This is a concrete arithmetic candidate, not an implemented recurrence or an approved public interface. The accompanying contract notes list the exact obligations before a theorem can claim adequacy.

## Unresolved proof obligations

Prove finite smaller-rank coverage from ActualChildRank and SAME-cut Fits; do not use unknown future profiles as a premise.
Prove that each finite seed join covers every selected recursive output and retains the input seed, then that the sequential folds cover the actual later sibling entries. parent_ge alone is retention, not arbitrary seed monotonicity.
Either prove the needed concrete seed monotonicity, or use joins at EACH current slot so no unproved global monotonicity of C is assumed. Finite list enumeration must retain full guard syntax and alphabet membership.
Prove cumulative work arithmetic against literal body/rows/walk fuel consumption. A depth bound alone does not cover sequential row and child decrements. Also prove controlled Parent fuel domination or retain its initial-only maximum L and require each lower fuel ≥max(phaseNeed(F),L).
C is still undefined and unproved. No initial-only work bound F has been constructed, and no standalone public adequacy header is justified by this survey.

## Circularity and capacity boundary

C must be defined using only initial budget/rank/seed data. Compute F=C.work BEFORE asking for Room of Schedule.node F budget seed and all nine phaseNeed(F) bounds. Those are explicit initial-data resource checks, not adequate-fuel or future-entry oracles [S7:39–74,S8:21–74].
Initial Room at Schedule.node F supports Prefix/rank, but does not automatically reserve Parent at the CONTROLLED seed. Prove controlled forecast domination by that root schedule, or check Room at an initial finite join of Schedule.node F and C.output, with a proved bound on every controlled Parent forecast.
Only after these initial checks and coverage proofs may the physical proof use rank and local completion. Defining C from actual run length, successful call graph, per-future Room, or an unknown adequate fuel would be circular.
A fixed-width caller may fail the computed capacity check. The survey proves neither a nonvacuous general capacity instance nor a theorem that changes the width of an existing state [S6:105–115].
NativeWidthTrace bounds an ALREADY supplied trace and instruction count. It neither constructs general outer completion nor widens state [S9:31–69,111–137].
FiniteOrdinaryOuterResourceRoot.finite already constructs StableRun with domain/Stored/ActiveAbove, shape/guard/height bounds, and explicit initial Headroom. Its finite ordinary scope does not supply the general Mu/union/reference theorem [S10:46–87].
