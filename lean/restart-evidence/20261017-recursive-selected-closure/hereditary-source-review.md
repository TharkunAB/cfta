# Hereditary unconstrained source condition

The new module reuses `SourceEqualityAnnotationLanguage.Annotated`. It adds no traversal predicate. `Annotated` checks every ordinary edge, every union member, and only the stored Mu body. Both Mu probes remain unrestricted. Bare references carry no guard check.

`annotated_visit` proves that the literal `InternedSourceCrush.visit` returns true for every initial visited set. The proof follows the existing annotation derivation. Its private list lemmas pass the actual returned visited set from each earlier child to the next child. A repeated identity returns true without inspecting descendants. No cache validity, physical availability, result law, or execution premise is needed for this sufficient direction. `unconstrained` specializes it to the actual `SourceMemoGate.plain` test and empty initial visited set. This is not a converse for arbitrary records.

`node_edge`, `source_child`, `union_member`, and `mu_body` project the same annotation predicate at literal source positions. `source_child` uses `InternedSourceCrush.sourceChildren`, not a probe-inclusive traversal. `annotated_mono` transports a proved implication between edge predicates.

The concrete source plain test has two parts: effective source equalities must be `some []`, and `positiveNormalized` must have a result. `plain_equalities` and `plain_positive` expose these exact parts. Neither theorem replaces them with arbitrary Boolean guard meaning. A reflexive `Same [0] [0]` is a concrete boundary: its effective equalities and physical own payload are empty, but its residual syntax makes `plain` false. No solver law is needed to establish this boundary.

`plain_physical` derives the actual `.ok (some [])` own-payload read from effective equalities. `to_plain_region` additionally requires actual `Facts`, `Available`, and cached closedness. It maps the annotation to the existing `NoEqualities` predicate and applies `SourceEqualityPartialPlainAnnotations.annotated`. The existing Region stops at Mu and union. It does not assert that their bodies are finite ordinary syntax. An annotated bare reference is unconstrained but does not itself provide a closed caller Region.

The source anchors agree with this scope. `Enumeration.hs:533–537` reads empty equalities and no residual at ordinary nodes. `Interned/Operations.hs:111–126` shares a visited identity set and visits only the stored Mu body. `Constraint.hs:129–136` performs effective equality extraction, and `Constraint.hs:160–175` defines the residual syntax test, including the reflexive-Same exception. The Lean natural-path model remains distinct from the Haskell signed path representation. This component proves no signed conversion or host execution correspondence.

The component is a hereditary source-condition foundation. It does not prove general selected recursive progress, a completion bound, native intersection closure, or whole-library correctness. Those tasks must still derive and retain the annotation at their own actual returned records.
