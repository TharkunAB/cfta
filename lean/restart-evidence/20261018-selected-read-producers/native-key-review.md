## Result and source route

`SourceCurrentNativeKeyAdmission.node_prefix` takes an actual raw
`NativeDemand.Steps` prefix of an empty-domain node request. It derives
`PhysicalTraceCompletion.Trace` for that same count, control and complete
returned state. It also derives current strong physical `Good`, reached
field checks, causal stored mass, node and edge credit, and domain count.
The API takes no checked trace, reached input certificate, `WordRanges`,
future store bound, or native result law.

The initial operands must be available and closed in the query-entry heap.
This concerns the two request operands, not the whole captured forest.
`OriginalOutput.closed_original` derives complete source syntax from these
facts and record coherence. It does not restrict the roots to ordinary
nodes, finite Cap profiles, or syntax without nested Mu.

The initial headroom is explicit. If `N`, `E` and `D` are the query-entry
node, edge and domain counters, the conditions are:

- `N < 2^bits`.
- `E <= 2^(bits+2)`.
- `D + 2^(N + N*N) < 2^(bits+1)`.

The existing `RecursivePrefixAdmission.prefixes` induction supplies the
noncircular part. Its `Resources` contains only the fixed query-entry
source inventory and initial domain supply. Its local `Certified` code
certificate is derived here from the request operands and source scope.
It derives current key safety before it checks an actual instruction.
Protected finish frames receive result residency from a shorter actual
body prefix. The resulting receipt contains the checked trace. The new
module then applies `NativeWidthTrace.node_prefix` to that produced trace.
It does not apply the width theorem before the trace has been admitted.

`node_done` starts from a literal `execute fuel ... = .done result after`
observation. It extracts its own raw trace with `count < fuel`, then uses
`node_prefix`. Result availability, current strong physical validity and
numeric mass/counter bounds refer to exactly the observed full state.
The numeric schedules remain symbolic. Existing schedule monotonicity can
lift the count bounds to the supplied execution fuel.

## Initial validity and remaining boundary

Initial `PhysicalCompletion.Good` is a real premise. Its native tables
retain the complete `NodeKey` and `EdgeKeyOf` relations, including encoded
request equality and key safety. This differs from the weak
`NativeOperationInvariants.Cells` relations, whose key predicate is `True`.
The new theorem does not upgrade arbitrary weak populated tables. Initial
headroom cannot repair a table linked to an unrelated captured request.
The strong invariant contains physical residency, not a desired semantic
native result law or earlier body completion oracle.

The existing raw admission theorem was already public behind generic
source certificates. The new module instantiates that theorem from
closed available query operands and combines it with the numeric width
producer. It removes explicit `Original`, future word ranges and supplied
checked traces from these two public query endpoints. It does not replace
the general raw admission induction or prove a new universal word bound.

Arbitrary open generated operands still need a complete-reference and
source-scope producer or a more general numeric admission induction.
A bare Depth or ordinary probe reference does not satisfy `Original`.
The new closed-operand API makes no claim about such requests. It does
not establish general worker completion, a fresh-request bound, active
owner exclusion, or termination of the outer recursion.

## Own constructed check

`NativeKeyAdmissionCheck.recursive_source` has no theorem inputs. It builds
a nonempty ordinary source that contains a used recursive Mu with base
and self-recursive rows. Covered actual guard allocations derive the
initial full checked state, exact-key native validity, loaded fields,
semantic heap, and operand availability. Source construction and the
actual cached root derive closedness. The fixture checks its initial
headroom at `bits = 64` and executes the actual four-fuel root self-query.
`node_done` then produces the checked trace and all numeric conclusions.
No future trace, key-range certificate or result law is a theorem input.

The query uses the root self branch. The fixture verifies a recursive
source and the raw-to-checked handoff. It is not a fresh optional-binder
publication test. The public theorem aliases the checked private proof
with the same complete statement.
