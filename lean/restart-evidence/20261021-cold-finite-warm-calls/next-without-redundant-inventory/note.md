This is a source-only gap assessment. It proposes the next actual-execution bridge. It proves no new theorem and authorizes no implementation or check.
The public source pass is withoutRedundantEdges, not only dropRedundantEdges. It recursively maps ordinary children, Mu bodies, union members and references before a local rewrite. It uses a global type-indexed memo table. [S01:77–101,739–770]
At a closed ordinary node it reduces symbol clusters. At a closed Mu with an ordinary stored body it compares the unfolded rows, retains the corresponding original body rows, then conditionally rebinds the Mu. A node with free references keeps its alternatives. Both traversal and the Mu correspondence matter. [S01:739–770]
The comparison is stateful: intersectEdgeSameSymbol orders operands, rejects unequal arities with an actual empty edge, otherwise intersects zipped children and conjoins guards. Both row and node intersections use memo tables. A discarded comparison can still allocate or update these tables. [S01:340–370,387–409]

The smallest useful next slice is a source-shaped, state-threaded ruleOut scan for one closed same-symbol cluster. Execute actual native edge requests and the literal equality tests in source order. Preserve the returned full checked state on every deletion, promotion and neither-equal branch. Return the optional dominating pivot, surviving tail, joint actual trace and language preservation of pivot-plus-tail.
This slice must use concrete native receipts rather than a supplied total meet function. Its producer obligations are the current cluster input/model/readback packet, compatible contextual cache laws, source scope/closedness for transformed operands, and real word/capacity and carrier transport for each reached comparison. Derive or retain those at the same states; do not take the desired intersection law or future scan success as a premise.
The equality branches then use the actual completed result: common=other justifies removing other; common=pivot justifies replacing the pivot by other. The neither-equal branch retains other. Prove the appropriate physical/source-language readback once from existing contextual receipts, then induct on the literal remaining list. This is narrower than the whole pass but does not restrict child values to ordinary trees.
No concrete stateful ruleOut/dropRedundantEdges/mapNodesStep control or execution relation was found in the current Lean source-name/content search; only RedundantEdges contains ruleOut, and the new finite-call module only states that withoutRedundantEdges is excluded. Intersection mu_body proves a different optional-binder construction from a supplied actual child trace and law; it does not prove this filter correspondence. [S09:21–63]
