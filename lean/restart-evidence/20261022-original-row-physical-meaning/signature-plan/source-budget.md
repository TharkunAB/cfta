# Ordinary source budget
The proposed context is9 lines, optional private statement8 lines and public statement16 lines:33 lines before bodies, separators and namespace close.
A later source should use90–150 ordinary lines. The approved hard stop is180 total rendered lines, including comments, local facts and every helper.
Allow about10–15 lines for the optional readback helper,25–40 for actual child provenance/admission/closedness,10–15 for child language equality and15–25 for the ordered forest equality.
These bounds leave room for explicit case analysis and ordinary formatting. They are an untested estimate, not body or compiler authorization.
Use default declaration limits and all linters. Stop with the complete partial source before exceeding180 lines; do not compress or split to evade the bound.
