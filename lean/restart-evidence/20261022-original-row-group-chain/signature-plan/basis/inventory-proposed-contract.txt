Proposed narrow contract: actual all-symbol group-run chain
This text is a design proposal. It is not a Lean header, implementation or checked theorem.
1. Fix the same source heap and Facts, formulas/solver, admitted InputMeaning and RankedInput, original available closed parent and its complete literal original row list. Keep width bits+2 fixed.
2. Supply a finite keyed Iteration of the H21 prepend table built from exactly those rows with key edge.entry.key.symbol. Keep the supplied iterator order; do not choose a canonical outer order or replace it by an unrelated pair list.
3. Supply the same H20 initial current packet: Stable, Good, Contextual, SemanticReady, source Grows and issued-history extension, native Idle, one valid initial domain cache and a Trace from that cache to the actual before-state domain cache.
4. Supply exactly the H20 initial Room tuple: source.nodes.next, source.edges.next, initialDomains.next plus the length of the fixed source domain inventory, and mass zero. Add no future/current-after Room, reset cache, completion callback or desired semantic law premise.
5. Derive for every iterator entry that its raw bucket reversed is the exact original-parent filter for that entry’s literal symbol. Use H21 iteration_reverse and reverse_fromRows, then the existing Iteration.lookup and append-table lookup_some. This is the only missing small pure readback projection.
6. Derive an indexed chain with one more full Wrapper state than entries, one concrete H16 fuel and one kept list per entry. State zero is the supplied before state. The H16 group execution starts with that exact reversed bucket and an empty kept accumulator, and returns that kept list with the next full Wrapper state. Derive each step from H20, not from assumed completed runs.
7. Retain the full current packet at every state under the same source/model/ranks/holds/width/initialDomains/inventory. Derive current source growth/history using the previous Extension.heap/history. Reuse the previous globally anchored Trace unchanged as the next call premise.
8. Return cumulative native Extension, pair-table Extends and Returned-cell retention from the original before state to the final state. Keep the final globally anchored domain Trace, Stable and native Idle.
9. Concatenate the per-entry kept lists in the supplied iterator order. Derive original-row membership, total output length at most original row length, and every-ambient/every-term physical union iff with the complete original row list.
10. H21 iterator permutation and Sized.groups_perm justify coverage of all original occurrences. Do not assert uniqueness, maximal pruning, heap identity, state equality across iterator permutations or a single common execution fuel.
11. An empty iterator gives the unchanged state and empty output. Singleton groups require no comparison. Repeated rows and arbitrary iterator order remain permitted by the generic grouping bridge.
12. This chain is a compositional boundary for actual existing H16 executions. A future outer Control/execute or Haskell concatMap traversal refinement is a separate statement and must retain these exact evolving-state equations.
