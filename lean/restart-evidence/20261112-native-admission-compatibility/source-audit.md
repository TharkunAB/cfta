## Identity/rank hazards and remaining operation seam

1. Canonical sharing is deliberate. The same leaf can be copied at two remaining heights and return the same native identity. A graph with paths of different lengths can request both keys in one copy run. Therefore a native identity does not have an inverse returning one original `(height,node)` key. Use scoped runtime `encode`; do not impose `decode (encode key)=key` on the physical IDs.
2. `InternedConstructorTemplates.Value.depth:43` counts Mu depth, not constructor height. `identifyNode:242–246` takes maximum CHILD cached depth without adding one. Ordinary trees can have cached depth zero at every constructor. This metadata cannot supply the required strict ordinary-child rank.
3. Native cache IDs start at zero (`Cache.emptyState:221`), while the abstract bounded row reader uses zero as empty. A realization must give an explicit reference/identity encoding (or retain tagged references). Raw native Nat identities cannot be copied blindly into the abstract rows. Do not claim an alias between the two caches merely because both have Nat IDs.
4. The actual final heap also contains the old source graph and unrelated allocations. A rank for the returned copied component is not an acyclicity theorem for the whole final heap.
5. `SymbolicGraphView.OperationRows:120–132` additionally needs SAME graph identities for intersection, template restriction, condition, and projection. `SymbolicProductRows.ClosedOperationRows:132–142` also needs the closed self-intersection shortcut and normalized rejection cases. Bounded native copying alone proves none of these operation correspondences.
6. `SymbolicAllocatedGraph.ConstructorHistory:24` and `allocated_rank:57` already turn actual-permitted constructor histories into a numeric child rank. But `AllocatedRows:51` is itself a supplier until connected to the SAME native operation histories. It cannot be asserted for the whole native heap containing Mu. Guard compiler score correspondence is also separate from a height bound. No new compiled-row supplier should be introduced.

The source-depth rank bounds finite copied constructor paths before guard evaluation. It does not bound all native cache mass, total exposed sibling rows, guard-path work, recursive intersection work, or the fuel of earlier enumeration hooks. A common bound for the native copier is also not a common bound for the full parent/pruning/enumeration driver. All original-input, all-alternative, runtime, and Haskell-correspondence boundaries remain explicit. No defect or Haskell fix was established by this audit.
