# Scope of the shared assignment witness

The appended observer returns one assignment that satisfies both the full old semantic conclusions and the new origin conclusion. The resource bounds, native result, Caller, full Memos and cache are the same fixed operational witnesses as the retained packet.

The result does not state that every assignment admitted by the old existential observer has origins. Empty equality classes show why that statement would be false: their old Holds premise constrains no path. The origin-aware witness construction chooses the current accepted term for those classes. It retains the old variables and the actual allocation count. No runtime result depends on this choice of semantic witness.

The traversal proof uses that same origin-aware assignment for its actual tail model. It then returns the tail assignment with both the complete old semantic conclusions and all final allocated-variable origins. The final selected-edge residual write retains this same assignment and counter.
