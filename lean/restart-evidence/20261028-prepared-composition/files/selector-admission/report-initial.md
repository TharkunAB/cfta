# Selector and earlier projection support

The native selector bridge already exists. No duplicate selector theorem is needed. This review is OPEN. The new CheckedProjection v2 is an untested owner draft until Root supplies its actual check.

`SelectorLanguage.selected_accepting_of_perm` derives an actual selected resident accepting edge from acceptance of an available native ordinary parent. `List.mem_iff_getElem?` gives its actual index. `interned_accepting` covers raw interned row selection. `canonical_accepting` keeps its explicit row-map/fallback permutation premise. `SelectedEdgeAdmission.selected_admission` derives that chosen edge's actual projection, inherited arity check, ordered child models, own equality satisfaction and residual satisfaction. These lemmas can be applied to the actual prepared parent. They do not identify that parent with the original stored handle. Existing NativeParentCoverage demonstrates this index composition; Root owns the new prepared-parent wrapper.

Parent acceptance is existential over rows. It supplies a model for some selected accepting row. It does not give a model to each earlier row. A none projection excludes every accepted guard term by Constraint.project_complete, but an unsatisfiable earlier row can coexist with a different accepting row. The operational CachedOwn.prepare returns none when its arity check passes and project returns none. SelectedEdge.run then returns unhandled. NativeBranches.advance does not continue that result, so the suffix is omitted. Thus the old earlier-prefix support obligation cannot be discharged merely from the chosen accepted term.

Native Ready tracks semantic cache structure, coverage and depth. The annotation Heap in Context supplies Cached equality payloads. Cached none holds vacuously. The projected arity predicate ArityOrigins.Fits is conditional on a successful projection, so it is also vacuous when projection is none. Neither definition encodes checked edge construction provenance. Raw makeEdge retains the supplied constraint. Raw makeNode removes edges only for Empty children. SelectedValue.run leaves an ordinary input unchanged. These facts prevent readiness or the act of normalization alone from establishing all earlier projection support.
