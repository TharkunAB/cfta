# Selected physical rows of actual open native queries

Date: 2026-10-18 CEST.

## Public contract

The module has four public heads: Reference, Resolved, returned and request.
The request endpoint takes initial physical Good, native edge-writer History,
source publication History, an actual successful checked request trace,
and an indexed physical row of its returned value.
It derives final History, Good, constructor-heap growth, final publication
History and Resolved at the exact returned checked state.
It takes no closedness, Original, BinderFree, finite ordinary Cap or
caller-supplied operand codec premises.

RowKeyable.selected derives both codecs and the actual complete request key
from that same actual trace and selected row. The exact key excludes the
direct-none result alternative. SharedLeafNativeLineage supplies final
native history and physical effects. PublicationTrace.from_history derives
publication history at the exact returned heap. Neither history is a
caller-supplied future result law.

The lower returned endpoint takes explicit input codec witnesses, current
returned cell, final native History and publication History. It normalizes
actual swap/reset forwarding through NativeOpenQueryForwarding.normalize.
Resolved retains the existing Route, terminal codec witnesses, exact
terminal returned cell and its protected earlier writer.

## All terminal branches

Self retains the selected indexed row of its literal left input.
Ordinary uses NativeOpenRowOrigins.ordinary on the captured compileRows
body. Joined retains both indexed input rows, full conjoined guard, symbol,
actual edge writer, ordered zipped child-query Walk, Good at both child
walk boundaries and both child-writer-to-reader growth facts.

Mu uses NativeMuWriterSourceRows.returned_mu for the same terminal cell,
handle, request and result. MuRow retains the entered domain, actual body
request, optional-binder outcome and an indexed original transition of
that generated body result. Its Anchor retains full fields and actual
ordered lexical child calls. The body result can be generated.
This is not an initial query-operand anchor.

Union reuses the existing Union predicate. That predicate itself has no
closedness premise. The proof derives each literal union shape from the
chosen writer body, then applies the new Good-based open union inverse.
It does not reuse the older closed/Original union producer.
The receipt retains the full captured owner/body/finish, ordered member
Walk, exact selected member/result indices, prefix/call/suffix states and
fuel decomposition, and the same-reader epsilon row origin of that child.
No Original premise is needed to obtain child result availability.

Reference retains the chosen writer entry and its exact read.
The left/right inverse derives the interned source name and domain
membership from that actual successful compiler body. Its child request
uses the same complete checked entry and the correct operand order.
Forwarded retains the actual direct-unkeyed compiler trace or final-reader
returned cell with its protected earlier writer. No History at an internal
evaluating owner state is assumed.

Reference and union receipts are built from the chosen writer body.
MuRow can recover a separate actual writer witness for the same cell.
The predicate does not assert equality between independently existential
writer boundary states. It does not infer source chronology from identity.

Swap and reset cannot remain terminal by normalization.
Empty and repeated-pair pure returns have no selected physical row.
Unsupported compiler bodies cannot have the supplied successful trace.
There is no unsupported residual branch in Resolved.

## Remaining boundaries

The conclusion classifies an actual completed checked query.
It does not produce general query completion from raw syntax.
It does not supply initial physical key bounds for arbitrary raw Steps.
Reference resolution can continue through another actual open request.
The theorem retains that call instead of claiming it reaches an original
public input occurrence in finitely many source steps.
Generated Mu body anchors, epsilon union origins and paired conjoined rows
need further composition for global initial-source ancestry.
Retained used-Mu alignment, all-active-owner exclusion, finite fresh-call
bounds and general outer completion remain separate obligations.
No Haskell mutation, executable defect or public execution correspondence
is claimed.
