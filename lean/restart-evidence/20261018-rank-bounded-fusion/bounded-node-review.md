# Rank-bounded actual node fusion

The new module proves `row` and `node` for `SourceCurrentBoundedFilteredFusion.Fusion bound`. The strict source-child hypotheses use the SAME bound as the parent. Both actual raw parent results must have physical `Value.depth` at most that bound. These are bounds on the original raw source values. No bound is imposed on replacement values or reconstructed outputs.

The proof retains both historical source contexts, exact source calls and return heaps, growth to the common reader, initial replacement availability, actual warm root filters, and actual warm stored calls. Actual parent decomposition and indexed `RowCall` receipts identify the same original row and ordered child syntax on both sides. The stored-call receipts identify each reconstructed ordered child list. The two source outputs of that row are physical surviving raw rows. Coherent available raw nodes bound every selected raw child by its own raw parent's depth, using `InternedUnionSeparation.child_depth`. Transitivity gives each child the supplied bound before the bounded IH is applied.

`row` derives an actual opposite surviving stored row. It retains the complete symbol, full guard, and ordered child Empty-test pairing. The reverse direction swaps both actual raw-parent depth bounds. `node` applies both row directions to derive physical Empty agreement. Dead raw rows never invoke the child IH. Child source expressions may contain arbitrary nested and open Mu. No unbounded child Fusion, whole parent output law, `BinderFree`, finite ordinary domain, or future schedule oracle is assumed.

The old node proof's helper declarations are private. Its public row and node endpoints require unbounded child Fusion. This additive module copies the actual schedule proof and changes the child IH, the selected-call bounds, and the two public contracts. It does not edit the old proof or invoke its unbounded endpoints.

The constructed witness builds a cold ordinary node from empty tables. A dead row contains an Empty child. A surviving row contains an actual closed nested USED Mu source expression. A nullary row also survives. The raw node's physical depth is exactly one and it has two surviving rows. The fixture derives initial context, Ready, raw availability, actual source calls, actual warm root filters, and actual stored execution. It invokes BOTH new public heads at bound one. The selected row contains the positive-depth Mu child. The child binder law is derived locally from its actual closed source support and `FilteredSourceFusion.nonempty_maps`; it is not an assumed parent or binder output equation. This fixture does not test arbitrary changing captures or assert finite language inhabitation of the Mu.

Full probes use all eight required print/lint options and the standard three axioms only, without printer elision or diagnostics.

This proves the node closure needed by a rank-bounded induction. It does not prove the general binder step, the earlier-writer symbolic rebind comparison, all-source Fusion, or termination.
