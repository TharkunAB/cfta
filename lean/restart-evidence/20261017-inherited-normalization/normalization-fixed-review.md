normalize_idempotent theorem derives Fixed output from an actual successful
normalization of arbitrary input. It does not assume a future normalized
result or replace literal equality with set or semantic equivalence.

sorting retains their order. A one-step mkEqConstraints receipt therefore
returns the same ordered payload. The existing array_eq theorem identifies
