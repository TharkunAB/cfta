# Selected rows in actual Mu callback nodes

The node theorem starts with two actual builds of the same node source.
Both calls use the same captured values and their own supplied reference.
Each context is derived at that call's actual entry. Children can contain
nested Mu syntax. No BinderFree, Cap or unused-local premise is added.

Physical normalization recovers a surviving original row and its source
index. Actual paired row calls have the same ordered child Empty tests.
The paired row therefore survives the other node normalization. Both
complete symbols and guards agree. The conclusion retains both actual
buildEdges and makeNode outcomes and both indexed RowCall receipts.
Canonical output positions can differ from their common source position.

The publication theorem inverts the same event's actual raw callbacks.
Both root self-filters are identities because each result is an ordinary
node or Empty. It then applies the node theorem to the actual stored body
row. The theorem keeps the same publication and both captured schedules.

This proves surviving row alignment for the node branch. It does not
relate nonempty child values or prove general common-replacement alignment.
The proof does not establish recursive termination or Haskell refinement.

Strict direct-3 has a zero-byte log. Canonical-1 has no warning. Public-1
prints all three complete statements, proofs and standard axiom reports.
The two failed elaboration attempts remain in this package.
