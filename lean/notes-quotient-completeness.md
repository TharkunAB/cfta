# Current guard refutation and pruning completeness

`SourceKnownHoldsTransport` extends the reverse known-actual environment to
positional Holds contracts. It fixes every contract name, including names
absent from literal requirements. It transports repeated-target aliases,
actual assumptions, positional domains, and actual declaration domains.
The source No gate supplies the known-scope premise. The theorem does not
require the whole guard's actual table to be unambiguous.

`SourceQuotientRefutations.worker_no` proves that a repaired sparse No refutes
the complete logical judgment. It covers every guard constructor and both
polarities. A negative Entails No comes from a positive entailment Yes; its
proof uses forward identification. Other query No cases use the reverse map
forced by known active identity flags. `public_supports` combines the Yes and
No theorems for the actual public Boolean dispatcher. `decided_iff` identifies
each decided public verdict with complete mathematical guard validity.

`CurrentGuardLogicalComplete.prune_contains` proves that a completed candidate
pass retains every original logically valid term. If the source restores the
original edge after an ambiguous Unknown, the theorem requires a complete
backend Yes for that term. `confirmed_retained` needs no extra backend
adequacy premise: every original term already confirmed Yes survives every
successful prune. The companion `CurrentGuardLogicalPrune.prune_sound` proves
that all returned terms are original and logically valid.

`prune_exact_logical` proves equality with the logical language under an
explicit `FallbackAdequate` premise for the original guarded edge. This premise
requires the complete backend to return Yes on each original logically valid
term. It is not a consequence of solver soundness. `prune_contains` states the
more precise condition only when the actual result restores that edge.
`compile_exact_logical` proves logical validity iff successful compilation
retains the cell. It requires no fallback-adequacy premise, because successful
classification excludes Unknown.

The planned-read adapters retain the existing lossless spelling-stability
contract. The identity-quotient proofs require only solver soundness and the
stated formula interpretation laws. `SourceQuotientExample` still demonstrates
the separate backend limit: sparse Yes, complete Unknown, and complete logical
validity all hold for the same proved sound callback. The new completeness
theorems do not assert exact backend-language equality for that callback.
